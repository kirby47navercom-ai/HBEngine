# 속성·능력 세트 제작과 실행

콘텐츠 브라우저의 속성·능력 세트(.hbabilityset.json)를 AbilitySystem 컴포넌트에 지정한다. 기존 단일 세트와 Health/Mana 기본값은 유지한다.

## 부모와 합성

부모 세트 → 합성 세트의 목록 순서 → 로컬 속성 순서로 적용한다. 같은 이름의 속성은 뒤의 정의가 우선한다. 같은 조상 세트는 한 번 적용한다. 능력 경로와 태그는 중복 없이 합친다. 부모와 포함 목록의 순환·누락 참조는 저장과 패키징에서 거부한다.

편집기에서 부모·합성 순서를 고르고 합성 결과를 열면 속성/능력/태그/세트와 출처를 조회할 수 있다. 상속 속성의 재정의는 로컬 행을 만들며 일반 Undo를 공유한다. 속성·시작 능력은 검색과 25행 페이지를 쓴다. 문서의 이전 256개 속성/능력과 32개 시작 태그 제한은 제거했으며 저장 묶음의 기존 8MB 예산과 AI 응답 페이지 제한은 유지한다. 에셋 선택 드롭다운은 아직 전체 후보를 나열한다.

## 종속 속성과 커브

속성의 계산을 펼쳐 원본 속성, 현재값/기본값/보너스 정책, 계수, 전후 덧셈, 선택적인 실수 커브 에셋과 트랙 ID를 지정한다. 계산은 다음과 같다.

`기본값 = clamp(계수 × (전 덧셈 + 원본 또는 커브[원본]) + 후 덧셈, 최소, 최대)`

현재값은 그 기본값에 활성 지속 효과를 적용한 결과다. 커브는 기존 Timeline의 실수 트랙과 보간/접선·끝값 고정을 재사용한다. 계산 순서는 의존 그래프로 정하며 순환·없는 원본·없는 실수 트랙을 거부한다. 종속 속성 자체의 SetAttribute, 비용 차감, 순간·주기 효과 쓰기는 거부한다. 원본을 바꾸거나 지속 집계 효과를 사용한다. 큰 값/비유한 결과를 만드는 변경은 현재 상태를 보존하며 실패한다. 수식 문자열을 eval하지 않는다.

곡선·세트 저장은 변경되지 않은 자식 세트까지 검증한다. 여러 문서의 참조 이름을 함께 바꿀 때는 files.apply 원자 저장 묶음을 쓴다. 기존 사람 모두 저장은 부모 우선 저장 순서를 사용하지만 전체 문서 원자 저장은 아니다.

## 실행 중 재적용

AbilitySystem 실행 Inspector의 세트 재적용, BP 능력 세트 재적용 노드, C++ `hb::Abilities::ApplySet(actor, asset, preserveBase, retainEffects)`는 같은 런타임을 사용한다. 두 옵션 기본값은 true다. 편집기 재적용은 열린 문서의 미저장 초안 대신 저장 파일을 새로 읽는다. 게임에서는 패키징한 콘텐츠를 읽는다. C++ 호출은 다른 능력 변경 함수처럼 명령 경계를 거치며 뒤의 C++ 호출에서 갱신된 스냅샷을 읽는다.

기본값 유지 시 같은 직접 속성의 소모한 값을 새 범위로 제한하여 유지한다. 동적 등록 속성/능력과 수동 태그는 보존한다. 유지되는 시작 능력은 쿨다운·활성 종료 시간을 보존한다. 효과 유지 시 핸들·주기·종료 시간을 보존한다. 새 세트에서 제거한 속성을 기존 효과가 요구하면 재적용 전체를 거부한다. 효과를 유지하지 않으면 제거 Cue를 한 번 보낸다. 제거한 활성 시작 능력은 종료 이벤트를 한 번 보낸다. 다른 소유자는 바꾸지 않고, 제거/풀 반환한 소유자의 늦은 로딩은 설치하지 않는다.

## AI 조회와 편집

- abilityset.read: summary/attributes/abilities/tags/sources, offset/limit(최대256), 루트 expectedRevision. 참조 세트·곡선의 읽기 revision을 재확인한다.
- files.get/apply/undo: 세트·곡선·C++·BP의 원자 변경과 Undo. 세트/커브 참조에는 자동 SHA 읽기 가드를 적용한다.
- runtime.abilities: 속성·능력·효과 페이지. 화면도 25행씩 표시한다.
- runtime.abilitySet.apply: target/asset/preserveBase/retainEffects. 실행 프레임 경계에서 검증 후 적용하며 문서·장면은 수정하지 않는다.

정의는 불변 템플릿으로 공유하고 각 소유자의 수치·효과는 분리한다. 세트 캐시는 64항목/32MiB 예산의 LRU이며 예산은 작성 데이터 수 제한이 아니다. 종속 집계는 변경 시 무효화하고 유휴 프레임에는 재계산하지 않는다.

## 별도 잔여

HB의 JSON 세트 합성은 Unreal UAttributeSet/네트워크 예측의 동일 구현이 아니다. GameplayEffect의 source/target 캡처·스냅샷 정책/레벨별 크기·커스텀 실행 계산, 네트워크 예측/복제, 자동 Cue VFX/오디오 자산, 대규모 에셋 선택기와 태그 전용 제작 UI는 별도 잔여다.
