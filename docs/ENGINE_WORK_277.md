# 277 · 불변 타일 레이어 검증 재사용

- 검증한 frozen JSON 타일 배열은 같은 경계 안에서 다시 순회하지 않아요. 메타데이터·레이어 ID·변경된 배열·경계 변경은 계속 검사해요.
- mutable 행·accessor·상속 값은 캐시하지 않아요. WeakMap에는 경계 숫자만 두고 이전 월드/배열의 강한 이력을 만들지 않아요.
- 16×8192타일·변경 맵12개 Node 표본의 반복 검증206.78→100.36ms, 에셋 SHA가 같아요.

검증 근거: [기계 판독 기록](research/ENGINE_WORK_277.json).

검증 범위와 잔여:

- 캐시 최초 검증을 제외한 한 순서 CPU 표본이에요. 전체 렌더/물리/FPS/장시간 RAM 측정으로 환산하지 않아요.
