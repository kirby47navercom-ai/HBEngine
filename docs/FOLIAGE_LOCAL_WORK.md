# 폴리지 편집의 국소 작업

산포·소거·선택 편집과 표시에서 필요한 임시 자료를 줄였어요. 자산 형식, 브러시 입력, 시드, 최소 거리, 생성 ID, 변환 순서와 저장 형식은 유지해요. JSON 데이터에 캐시 표시를 붙이거나 수정 가능한 문서를 전역 캐시하지 않아요.

- 산포는 브러시 반경에 최소 거리를 더한 사각 영역의 기존 점만 임시 그리드에 넣어요. 그 밖의 점은 어떤 생성 후보도 막을 수 없어요. 생성 ID 충돌 검사는 전체 기존 ID를 유지하며 난수 소비·높이·크기·회전 순서도 같아요.
- 선택 표시는 요청한 ID를 모두 찾으면 순회를 마쳐요. 빈 선택은 인스턴스 목록을 읽지 않아요. 변환·복제는 선택 인덱스를 사용하고, 문서 순서에 따른 복제 ID 규칙을 유지해요.
- 소거는 사각 경계 밖을 먼저 통과시키고 근처에만 기존 `Math.hypot` 판정을 사용해요. 원 경계와 반경 0의 동작을 유지해요.

검증·불변 복사·Undo·마지막 공개·삭제 필터는 기존 흐름이에요. 이 비용과 대규모 렌더/충돌 비용은 남아 있어요. 선택 대상이 끝에 있거나 찾을 수 없으면 순회도 끝까지 필요해요. 브러시가 큰 월드 전체를 덮으면 임시 그리드도 커져요. GPU 계산 브러시나 지속되는 공간 인덱스 구현을 뜻하지 않아요.

`tools/check-foliage-local-work-2694.mjs`는 공간 그리드가 없는 독립 전수 거리 계산과 여러 시드·밀도·음수/큰 좌표의 산포 결과를 대조해요. 인접 경계, ID 충돌, 지형 높이, 소거·선택·불변성·실제 편집기 메서드·저장/재열기를 포함한 14개 검사예요. 소유 표본에서는 먼 10,000개 점을 그리드에서 제외하고, 소거의 거리 계산은 근처 3개에만 했어요. 실제 선택 시 앞의 두 ID를 찾은 뒤 무관 10,000개 ID의 접근을 금지해 조기 종료를 확인했어요.

지형 브러시 8종·20,003개 인스턴스의 기존 draft 소유/복사 규칙, 부분 시각 갱신·큐/단축키·월드 액터 자원 수명도 별도 회귀 검사로 유지해요. 과거 검사 보고서는 덮어쓰지 않고 이번 실행의 별도 경로에 남겨요. GUI·GPU·힙·실기기·FPS 성능 측정이나 설치 갱신은 수행하지 않았어요.
