# 거친 유리·반사 샘플링·광원 계산

거친 유리에서 반사와 굴절 방향을 표면의 GGX 분포로 뽑고, 정확한 유전체 Fresnel과 굴절 방향의 확률 변환을 계산해요. 직접 광원·발광 면·HDRI와 경로의 다음 방향에 같은 반사·굴절 혼합 BSDF/PDF를 사용해요. 기존 `Roughness`, `IOR`, `Transmission`, `ClosedVolume`과 C++ 머테리얼 함수로 조절하며 별도 에셋이나 라이브러리가 필요하지 않아요.

기본·비등방성·코팅 GGX 반사는 시선에 보이는 미세 표면을 샘플링하도록 바꿨어요. 분포에 맞춰 반사 PDF도 함께 바꿨어요. 시선에서 보이지 않는 코팅과 기하학적 표면을 잘못 통과하는 노멀 반사는 거부해요. 매질 진입·이탈의 밝기 계수와 경로 종료 확률을 분리해서 높은 IOR의 경로가 불필요하게 일찍 종료되는 문제도 줄여요. 실제 프레임 향상 수치를 뜻하지 않아요.

거친 유전체가 있는 셰이더만 관련 코드를 활성화해요. 불투명 표면의 거칠기 그래프만으로 굴절 코드를 켜지 않으며, 동적 투과 그래프는 지원해요. 일반 머테리얼은 기존 5필드, 115의 확장 표면은 10필드를 그대로 사용해요. 새 광선 데이터 블록·추가 렌더 타깃·자동 GPU 읽기·텍스처 파일은 만들지 않아요. 동적 거칠기·IOR 변경은 기존 셰이더 캐시·부분 전송·경로 누적 초기화에 연결돼요.

WebGL의 디노이저 가이드·필터 셰이더에서는 실행하지 않는 조명 적분기를 제외해요. 카메라 광선 폭 계산은 원본과 공유하며 네이티브 알고리즘 문자열은 그대로 유지해요. 전체 장면 전환 검사에서 발견한 지연을 보완한 뒤 기존 분산 감소·강도 0의 원본 유지 조건을 그대로 검증해요.

독립 수치 적분으로 시선 분포 정규화를 확인하고 4만 개 샘플의 유한성·방향을 확인해요. 네이티브 픽셀 검사에서는 거친 유리·매끄러운 유리·같은 IOR·폐곡면 매질·강하게 기울어진 노멀을 비교해요. 기존 검사와 실제 C++ 변경을 세 실행 경로에서 묶어서 검증하며, 설치 증거는 별도로 기록해요.

수식·변환은 [PBRT 거친 유전체](https://www.pbr-book.org/4ed/Reflection_Models/Rough_Dielectric_BSDF)의 해당 BSDF/PDF·샘플링 구역과 [미세 표면의 가시 법선 분포](https://www.pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory)의 해당 구역을 읽고 대조했어요. 전체 문서·API·링크의 분석 완료를 뜻하지 않아요.

거칠기 0.05 미만과 동일 IOR은 기존 델타 경로를 유지해요. 폐곡면은 매질 스택과 radiance 계수를 사용하고, 얇은 표면은 기존 단일 경계·틴트 관례를 유지해요. 이중 코팅과 유전체의 완전한 결합·다중 미세 표면 산란·별도 코스틱 추적·이차 반사 디노이징까지 포함한 모델은 아니에요. 다음 원장의 계층 BVH·코스틱·이차 반사 처리 항목은 그대로 유지해요.

설치 갱신 뒤 사용하지 않는 이전 `Versions` 사본과 검사 패키지·프로필을 정리해요. 실행 중인 버전·사용자 프로젝트·수정 파일은 보호하며 전체 설치를 백업으로 누적하지 않아요.
