# 애니메이션 지면 높이·경사 보정

Two Bone IK 노드의 접힌 **지면 보정** 속성에서 켜요. 기존 그래프 JSON과 편집기의 검증·Undo를 그대로 사용해요. 속성이 없거나 꺼져 있으면 이전 IK 경로를 유지해요.

| 필드 | 기본값 | 동작 |
|---|---|---|
| enabled / parameter | false / 빈 문자열 | 켜짐·양의 IK alpha·선택한 Bool이 true일 때 평가해요. Bool은 기존 C++ `hb::AnimationGraph::SetBool`로 제어해요. |
| source | pose | 입력 포즈의 발 위치에서 시작해요. target은 기존 가중치가 적용된 유효 목표를 사용해요. 발 고정 중이면 잠긴 목표를 사용해요. |
| dimension / direction | 3 / [0,-1,0] | 월드 방향의 준비된 동기 물리 광선이에요. 2D는 XY 방향이며 표시용 Z를 유지해요. |
| lift / distance | .5 / 1m | 시작점은 원본 위치에서 반대 방향으로 lift, 끝점은 원본 위치에서 direction으로 distance만큼 떨어져요. |
| offset / maxSlope | .02m / 60도 | 표면 법선 방향 오프셋과 허용 경사예요. 경사는 광선 반대 방향을 기준으로 계산해요. |
| rotationWeight / upAxis | 1 / [0,1,0] | 발의 지정 로컬 축을 지면 법선으로 최소 회전해 정렬해요. 기존 회전·alpha 가중치도 적용해요. |
| mask | -1 | 기존 물리 질의 레이어 마스크예요. 자기 오브젝트와 실제 트리거는 제외하고 질의 전용 콜라이더는 포함해요. |

게임 서비스는 기존 Rapier 2D/3D 월드를 준비하고 같은 `physicsRaycast` 질의를 연결해요. 별도 물리 월드·C++ SDK·입자 전송을 추가하지 않아요. 독립적으로 `AnimationGraphPlayer.load`를 호출할 때는 `groundQuery(args)`를 주입해요. 준비되지 않은 비동기 콜백·잘못된 결과는 오류예요. dispose는 질의 참조도 해제해요.

허용 지면을 찾지 못하거나 Bool이 꺼지면 입력 포즈를 통과시켜요. 작성한 발 고정을 함께 사용할 때 지면을 잃으면 해당 평가 문맥의 잠금을 해제하고, 다시 접촉하면 현재 위치에서 잡아요. 다른 문맥의 잠금은 지우지 않아요. 자동 보행 접촉 단계 검출·Stride·골반 보정은 별도 기능이에요.

위치는 부모 월드 행렬의 역변환으로 풀어요. 회전 정렬은 양의 균일 크기·전단 없는 월드 프레임을 요구해요. 회전 정렬을 0으로 두면 기존 아핀 위치 변환을 사용할 수 있어요. 도달할 수 없는 목표는 기존 길이·늘이기·관절 제약을 지키고 잔여 오차를 표시해요.

미리보기는 선택 리그·목표·힌트·리타게팅 소스·발판·Full Body effector의 시각 오브젝트만 복사해요. 지면은 차원·레이어·활성 상태에 맞는 콜라이더와 부모 변환만 복사하며, 메시·소리·사용자 코드를 복제하지 않아요. 생성된 타일 콜라이더도 별도 필드로 유지해요. 원본에 components가 없는 구형 오브젝트도 읽기 중에 변경하지 않아요. parentId 우선순위는 공용 월드 변환과 같아요.

활성 평가 문맥당 광선 한 번이며, 예산상 평가를 건너뛴 프레임은 질의하지 않아요. 질의는 기존 선형 콜라이더 후보 검사이므로 대규모 리그·콜라이더의 전체 비용을 보장하지 않아요. 사용하지 않는 큰 필드를 넣은 합성 fixture의 100630→351byte는 소유 JSON payload만 비교한 값이에요. 전체 RAM·GPU 메모리·FPS 측정값이 아니에요.

WORK2920 근거: 실제 Three 골격·공용 VM/Rapier 2D/3D 지면 검사 16개, 미리보기 선택·원본 보존·실행 11개, 공용 질의 센서 구분 6개, 기존 발 고정 14개. 기존 동일 C++/SDK 캐시의 Set/GetBool 2메서드·4호출·4읽기·4쓰기로 두 차원의 실제 발 포즈까지 확인했어요. GUI·실기기·설치 검증은 포함하지 않아요.
