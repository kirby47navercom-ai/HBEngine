# 편집기 거리장 사전 생성

레벨 뷰포트나 아웃라이너의 오브젝트를 우클릭해 **거리장 사전 생성**을 선택해요. 명령 검색에서도 같은 이름을 사용할 수 있어요. 8–64 해상도를 선택하고 생성하면 현재 불러온 정적 기하를 프로젝트 `Library/CookCache`에 저장해요. 취소하면 진행 중인 작업을 중단해요. 이미 저장한 유효한 캐시는 유지돼요.

원본 에셋과 장면, Undo 기록을 변경하지 않아요. 기하의 로컬 정점·인덱스·drawRange와 생성 알고리즘의 지문을 사용하므로 이동·회전·인스턴스마다 사본을 만들지 않아요. 불러온 월드 LOD의 숨겨진 단계도 준비해요. 정점이 변경되면 다른 지문이 되어 이전 자료를 적용하지 않아요. 골격·모프 등 변형체와 마스크·투명 재질은 기존 거리장 제외 정책을 따라요.

현재 로더가 실제 장면에 만든 정적 기하를 사용하므로 로드된 OBJ·FBX 등에도 적용할 수 있어요. 이것은 화면 없는 FBX 자동 쿠킹이나 전용 지형 높이장 구현을 뜻하지 않아요. 불러오지 않은 에셋과 현재 실제 기하 트리에 없는 LOD는 준비하지 않아요.

편집기 실행과 다시 연 편집기에서 같은 캐시를 조회해요. 누락·손상·다른 해상도·메모리 부족이면 기존 Worker 경로로 돌아가요. 캐시 파일은 공용 쿠킹 예산 128 MiB 안에서 정리하며 기하 입력은 한 번에 8 MiB, 부피는 최대 64³ float예요. 해상도를 몰래 낮추지 않아요. 패키징에서 이미 지원하는 기하 소스는 같은 캐시와 알고리즘 지문을 사용하며, 해석적 상자·평면의 해상도 0 캐시도 공유해요. 패키지에 프로젝트 캐시 폴더 전체를 복사하지 않아요.

## AI 계약

`distanceFields.prepare`는 사람의 대화상자와 같은 실행 경로예요.

```json
{"method":"distanceFields.prepare","params":{"path":"Assets/Maps/Main.hbscene.json","expectedRevision":"document.get의 revision","resolution":24,"dryRun":true}}
```

활성 레벨에서 실행을 종료한 뒤 호출해요. `dryRun`은 기하와 입력 예산만 점검하고 Worker나 디스크 쓰기를 시작하지 않아요. 실제 생성 중에도 장면 revision과 활성 레벨을 확인해 편집 충돌 시 중단해요. 결과의 `geometries`, `baked`, `reused`, `stored`, `bytes`, `skipped`를 확인할 수 있어요. 캐시 작업이므로 에셋 revision은 그대로예요. 취소·충돌 이전에 저장된 콘텐츠 지문별 캐시는 유효한 자료로 남아요.

서버 `/api/distance-fields/cache`는 경로 대신 검증한 기하 SHA-256와 해상도만 받아요. 체크섬·코덱·기하·해상도·바이트 한도를 확인하고 임시 파일을 원자적으로 전환해요. 사용자 프로필과 엔진 설치 폴더에는 저장하지 않아요. 셰이더 드라이버 캐시·FPS 향상과는 다른 기능이에요.
