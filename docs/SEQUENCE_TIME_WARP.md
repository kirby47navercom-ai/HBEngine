# 하위 시퀀스 시간 리매핑

Shot 또는 Sub-Sequence 구간을 선택하고 속성의 **시간 리매핑 → 사용**을 켜요. 구간 시간과 원본 시간을 숫자로 편집하고 시간 키를 추가하거나 삭제할 수 있어요. 같은 원본 시간을 연속 키에 지정하면 그 사이에서 하위 시퀀스가 멈춰요. 작은 곡선에서 속도 변화와 정지 구간을 볼 수 있어요. 끄면 기존 소스 시작·시간 배율만 사용해요.

구간 시간은 증가하고 원본 시간은 감소하지 않아야 해요. 첫 키는 `(0,0)`이고 키는 2~256개예요. 각 값은 초 단위 0~86400이고 구간 기울기와 지원 시간·배율 범위의 양 끝 연장이 유한한 수여야 해요. 값이 너무 가파라 무한대가 되는 입력은 거절해요. 양 끝에서는 마지막 구간의 기울기로 연장해요. 실제 하위 시간은 `sourceStart + remap(parentTime-start) * rate`이며 기존 반복 또는 끝 유지가 뒤에 적용돼요. 키가 없는 기존 파일은 그대로 동작해요. 같은 시간에 머무는 동안 이벤트를 다시 발동하지 않고, 실제 통과한 곡선·Shot·반복 경계로 나눠 이벤트를 전달해요. Pause·Seek의 이벤트 억제 규칙도 유지해요.

왼쪽 가장자리를 잘라내면 소스 시작과 시간 키를 함께 이동해 남은 부분의 원본 시점을 보존해요. 다시 왼쪽으로 확장할 수도 있지만 원본 시작 이전으로 나가는 리매핑은 거절해요. 오류는 문서·Undo를 바꾸지 않아요. 일반 구간 이동은 곡선을 그대로 옮겨요. 중첩 구간도 같은 매핑을 재귀적으로 적용해요.

AI는 `sequence.section.edit`의 `section.timeWarp:[{time,value},...]`를 사용해요. `timeWarp:null`은 곡선 제거예요. `operation:trimStart, section:{start}`는 남는 소스 시점을 보존하는 앞부분 자르기예요. 일반 update의 start 변경은 구간 이동이에요. 기존 expectedRevision·dryRun·한 번의 Undo·저장 계약을 공유하고 `schema.sequenceTimeWarp`에서 형식과 한계를 조회해요. Blueprint 및 C++ LevelSequence Play/Seek/Stop도 같은 저장된 구간을 평가해요.

시점 조회는 정렬된 불변 키를 이진 탐색하며 매 프레임 키를 복사하거나 정렬하지 않아요. 이벤트를 평가할 때 실제로 지나간 경계만 나눠요. 새 워커·타이머·GPU 자원·영구 캐시는 없어요. 역방향·불연속·삼차 시간 곡선과 경쟁 레이어의 정규화 혼합, 외부 장치 동기화는 이 구현에 포함되지 않아요. 근거는 ENGINE_WORK_1949와 USER_INSTALL_1951에 기록해요.
