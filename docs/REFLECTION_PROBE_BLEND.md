# 반사 프로브 혼합과 현재 포즈

기존 ReflectionProbe 컴포넌트를 배치하고 크기·블렌드 거리·중요도·밝기·간접 확산·박스 투영을 편집해요. C++ ReflectionProbes/Components 함수와 같은 블루프린트 노드, AI document.patch/CAS가 같은 값을 사용해요. 추가 셰이더 코드를 작성할 필요는 없어요.

후보가 두 개 이하면 브라우저는 메시 경계의 직접 두 맵을 사용하고, 각 픽셀의 실제 월드 좌표에서 영향도를 계산해요. 인스턴스도 인스턴스 행렬을 반영해요. 경계에서 안쪽으로 blendDistance만큼 들어가며 영향도가 올라가고, 두 영향도의 합이1보다 크면 정규화해요. 합이1보다 작으면 남은 비율에 원래 머테리얼 환경 맵 또는 씬 환경을 적용해요. 원래 환경의 밝기와 회전도 보존해요.

intensity를0으로 해도 프로브 영역의 점유율은 유지돼요. 영역을 벗어난 픽셀과 같은 기준으로 비교하려면 영향 영역을 줄이거나 프로브를 끄세요. diffuseIntensity의 기본값은0이며 프로브의 간접 확산과 물리 모델의 관련 다중 산란 기여를 별도로 조절해요. 머테리얼의 기본 조명·코팅·비등방성 경로가 같은 혼합을 사용하고 GPU 굴절 환경 샘플도 같은 함수를 사용해요. 모든 광학 그래프/실기기의 검증을 뜻하지는 않아요.

스킨과 모프는 현재 CPU 포즈의 경계를 계산해요. 음수 모프 가중치·위치 자료·본·바인드 자료의 변경을 반영하고, 그대로인 포즈는 정점을 다시 읽지 않아요. 이 경계를 후보 선택과 프러스텀 검사에 사용하므로 오브젝트 원점이 프로브 밖이어도 실제 변형된 표면이 영향을 받을 수 있어요. 지원되는 CPU 포즈가 달라지면 전체 정점 경계를 다시 계산하는 비용이 있어요.

서로 다른 캡처 해상도를 각 맵의 CubeUV 배치로 샘플해요. GL에서 프로브를 바꿀 때 맵 크기 때문에 프로그램을 다시 만들지 않도록 활성 렌더러마다172032B의 작은 half-float 앵커 자료를 사용해요. 이 수치는 CPU 텍스처 페이로드이고 전체 GPU 메모리 측정이 아니에요. 원래 환경이 이미 필터링된 맵이면 그대로 사용하고, 원본 큐브/등거리 맵이면 사용 중인 원본별로 필터 타깃 하나를 보관해요. 버전 변경·미사용·소유자 해제 때 교체/정리해요. 추가 조명 패스나 운영용 GPU 읽기는 없어요.

공유 머테리얼은 독립 프로브 상태를 유지해요. 사용자가 복제본의 머테리얼을 교체하면 그 교체를 보존하고, 프로브 해제 시 원래 환경·셰이더 훅·굴절 소유자를 복원해요. GL의 약한 머테리얼별 uniform 저장소는 켜기/끄기 후 프로그램 재사용에도 연결을 유지하며, 해제 때 텍스처 참조를 비워요.

UV가 없는 모델과 면적이0인 UV에서는 유효하지 않은 접선을 정규화하지 않고 기하 노멀을 사용해요. 중립 노멀·음수Z·0과 큰 유한 노멀값도 안전하게 처리하며, 기본 면과 코팅 면에 같은 공용 처리를 적용해요. 현재 CPU 포즈의 컬링 경계는 캡처 카메라가 그리기 전에 갱신해요.

AI는 schema.reflectionProbeBlending과 renderer.probes의 blendedMeshes/globalMeshes/atlas/baseMaps/baseFilters/anchorBytes/captures를 읽을 수 있어요. 세 영역 이상에 걸친 큰 메시·배치는 [전역 아틀라스](REFLECTION_PROBE_ATLAS.md)에서 각 픽셀의 두 후보를 골라요. 공간 가속·픽셀 우선 점유·구형 캡처·lightmap 혼합, 임의 셰이더 변형·인스턴스별 모프 텍스처는 별도 잔여예요. 전체 Unreal/Unity와의 동등성을 뜻하지 않아요.
