# 사용자 설치본 C++ 캐시 자동 정리

C++ 빌드가 성공하면 개발 환경과 사용자 설치본 모두 자신의 컴파일 캐시를 정리해요. 캐시를 다시 사용할 때도 사용 시간을 갱신해 최근 32개를 유지해요. 같은 호스트가 참조하는 모듈과 다른 창에서 실행·컴파일 중인 경로는 보존하므로 보호 중인 항목만큼 더 남을 수 있어요. 사용자 코드와 게임 빌드·세이브·설정은 정리 대상에 포함하지 않아요.

기존 검사 캐시 정리 도구의 경로·파일 종류·링크·실행 프로세스 검사를 재사용해요. 자동 빌드 정리는 공용 C++ 캐시만 살펴보고, 검사 프로젝트와 브라우저 프로필은 각 검사의 종료 처리에 맡겨요. 정리할 게 없으면 빈 폴더나 기록을 만들지 않아요. 동시에 정리할 때 기록 경로가 겹치지 않으며 이미 정리된 항목은 다시 삭제로 계산하지 않아요.

검사는 별도 도구 인스턴스에 캐시 35개를 만들고 최근 32개·참조한 오래된 모듈·실행 중인 경로의 보존, 미사용 항목 삭제와 빈 기록 미생성을 확인해요. 실제 C++ 빌드의 취소·재시도·동시 빌드와 반환값, 정리 중 취소 시 미반환 세션 제거, 기존 호스트 진단과 검사 패키지 정리도 확인해요. 경로를 나눠 만든 검사 폴더의 정리 인식도 보완해요.

렌더링 112의 검증된 실행 파일과 렌더링 소스를 그대로 사용하고 이 도구 변경을 설치본에 갱신해요. C++ 빌드 뒤 한 번 수행하며 게임 프레임마다 실행하지 않아요. [검증 기록](research/BUILD_CACHE_113.json)과 [설치 영수증](research/USER_INSTALL_113.json)에 실제 결과를 남겨요.

이 설정은 Windows C++ 캐시에 적용해요. 원본 프로젝트 에셋과 사용자가 보관하는 게임 내보내기 결과의 크기는 제한하지 않아요. 캐시가 정리된 소스는 다음 사용 때 다시 컴파일할 수 있어요.
