# 큰 월드의 UV 밉 선택

삼각형 UV의 변화량을 상대 모서리에서 직접 계산해요. 월드 위치에 작은 픽셀 폭을 더한 뒤 다시 빼는 계산을 피하므로 큰 좌표에서 폭이 반올림으로 사라지는 문제를 줄여요. 기본 UV 보간과 머테리얼 그래프·샘플러·저장 형식은 유지해요.

좌표1천만·폭0.3125인 실제 검사에서 기존 GL/GPU 경로는 넓은 표본도 0번 밉의 방향을 반환했어요. 수정 후 GL·GPU·DirectX 모두 넓은 밉에서는 평균된 중립 노멀, 좁은 밉에서는 원래 방향을 반환했어요. 이전 포즈의 UV에도 같은 계산을 사용해요. 추가 GPU 버퍼·타깃·uniform·지속적인 읽기 회수는 없어요.

스킨·모프·인스턴스·스무스 노멀을 포함한17조건에서 이전 기하 기준을 대조했어요. 128개의 독립적인 affine UV 항등식 검사도 함께 있어요. AI는 기존 `engineSchema().raySurfaceHistory.uvFootprint`에서 같은 불변 계약과 한계를 조회해요.

월드 위치를 UV로 사용하는 그래프는 [상대 좌표 전달](COORDINATE_DIFFERENCES_420.md), 비선형 연산과 스무스 노멀은 [후속 밉 폭 계산](MATERIAL_FOOTPRINT_425.md)으로 이어져요. 매우 큰 작성 UV나 시간 자체의 정밀도 문제는 별도예요. 텍스처로부터 생성한 좌표의 미분은 기존과 같이 근사해요. 전역 곡면 역대응·참여 매질 footprint도 이 변경의 완료 범위가 아니에요.

한 번의 GL 준비 비교는2664.9→2576.6ms, 소스122B 감소였어요. 부하와 드라이버 캐시를 통제한 속도 개선 근거로 사용하지 않아요. 실제 C++/블루프린트 게임에서도 복잡 노멀 그래프·변형·해제를 확인하며 초기 컴파일은 계속 줄여야 해요.
