# UV·충돌·리타게팅·오디오 제작 명령

기존 단축키 설정과 AI 단축키 get/set 계약으로 새 명령도 재지정해요. 충돌 검사·이전 사용자 프로필 이행·IME/입력칸/게임 실행 격리를 그대로 사용해요. 도구 화면에 긴 설명을 추가하지 않고 기존 버튼의 툴팁에 현재 키를 표시해요.

## 메시 UV

UV 캔버스에 포커스가 있을 때 별도 `uv` 문맥을 사용해요. F는 선택 프레이밍, Home은 전체 프레이밍, Ctrl+A는 전체 선택, Ctrl+Shift+A는 선택 해제예요. 분리·섬 펼치기·경계 맞추기·섬 패킹·채널 복사·XZ 투영도 등록되어 있어요. 이 여섯 편집 명령은 기본 키를 비워 두었으므로 설정에서 지정해요. 기존 `WorldAssetEditor.action`/`editMesh`·Undo·저장을 사용하고 UV 0/1 선택을 유지해요. 재지정한 F·Ctrl+A가 캔버스의 이전 고정 키로 우회되지 않아요. Escape는 진행 중인 포인터 동작을 취소해요.

## 충돌 형상

모달의 독립 `collision` 문맥에서 F/Home 프레이밍, Ctrl+Z/Ctrl+Shift+Z/Ctrl+Y의 초안 Undo/Redo를 제공해요. 2D 캔버스에서는 Insert 점 추가, Delete/Backspace 점 삭제, 화살표 격자 이동과 Shift+화살표 큰 이동을 재지정할 수 있어요. 3D 창과 좌표 입력칸에는 2D 점 명령을 적용하지 않아요. 포인터 드래그 중에는 초안 명령을 실행하지 않고 전역 Save·Play·장면 Undo도 모달로 넘기지 않아요. 실제 적용 전에는 컴포넌트 원본이 바뀌지 않아요.

## 리타게팅

기존 미리보기·매핑 명령에 포즈 추가/삭제/초기화, 체인 삭제, 프로필 추가/복제/삭제/기본 지정, 매핑 지우기/삭제, 모프 추가, 클립 베이크, 골격 클립 커브 추가를 더했어요. 각 명령은 해당 리그·리타게터·클립 문맥에서만 기존 버튼을 호출해요. 새 명령의 기본 키는 비워 두었어요. 기존 검증·Undo·베이크 생성 경로를 공유해요.

## 오디오 버스

하위 버스의 복제 버튼과 Ctrl+D, 삭제의 Delete/Backspace를 제공해요. 음소거·솔로·DSP 우회 전환도 재지정할 수 있어요. Master는 복제·삭제하지 않아요.

`editMixerBus(data,{operation:'duplicate'|'remove',bus,id?})`는 원본을 바꾸지 않고 검증된 `{data,selected}`를 반환해요. 복제는 같은 부모 아래 한 버스의 DSP·Send·사이드체인과 각 스냅샷의 값·전환, 노출 파라미터를 독립 복사해요. 자식 트리 전체 복제는 아니에요. 이름은 중복을 피하고 최대 개수 초과는 원본 변경 없이 거절해요.

삭제는 자식을 기존 부모로 연결하고 들어오는 Send·해당 신호를 쓰는 사이드체인·스냅샷/전환·노출을 정리해요. 들어오는 Send를 부모로 돌려 소리가 두 번 합쳐지게 하지 않아요. 편집기는 기존 한 번의 Undo와 그래프 재구성으로 반영하고 저장한 결과는 기존 `AudioRouting`/BP/C++ 믹서 API로 실행해요.

실제 창의 픽셀·화면 읽기·실기기 음질은 별도 검증 대상이에요. 포인터 조합 전체의 사용자 재지정은 아직 포함하지 않아요.
