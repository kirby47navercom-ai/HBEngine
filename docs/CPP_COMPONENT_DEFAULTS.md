# 기존 프로젝트의 C++ 컴포넌트 읽기

엔진에 새 속성이 추가되기 전에 저장한 프로젝트는 해당 속성의 값이 없을 수 있어요. `hb::Components::GetBool`·`GetFloat`·`GetString`·`GetText`·`GetVector`·`GetColor`는 이때 현재 컴포넌트 정의의 기본값을 읽어요. 등록되지 않은 컴포넌트나 속성은 계속 거부해요.

빠진 기본값의 첫 읽기만 `componentDefaultJson` 내부 질의로 타입·속성명을 보내고, 같은 C++ 호출의 반복 읽기는 로컬 값으로 처리해요. 이 질의는 월드 스냅샷·렌더러·물리 월드를 만들거나 기존 물리 질의 예산을 사용하지 않아요. 다른 호출까지 영구 캐시하지 않으므로 컴포넌트 정의 변경이나 새 요청의 실제 값이 반영돼요. 읽기는 컴포넌트 저장·게임 명령을 만들지 않아요.

Transform의 위치·회전·크기는 직렬화된 컴포넌트의 예전 값 대신 오브젝트의 실제 로컬 변환을 읽어요. 같은 호출에서 `SetVector` 뒤의 `GetVector`도 새 값을 읽고, 기존 공용 컴포넌트 명령으로 실행에 반영해요. 실제 월드 변환이 필요한 경우에는 기존 Transform 월드 API를 사용해요.
