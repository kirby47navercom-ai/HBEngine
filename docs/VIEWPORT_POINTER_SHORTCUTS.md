# 뷰포트 명령의 마우스 조합

단축키 설정에서 뷰포트에서 사용하는 명령의 입력 슬롯을 누르고 마우스 버튼을 눌러 지정해요. Ctrl/Command·Shift·Alt를 함께 누를 수 있고, 왼쪽·가운데·오른쪽·뒤로·앞으로 버튼을 지원해요. 프로필 JSON은 기존 버전 1이며 `Primary+Shift+Mouse4` 같은 조합을 사용해요. Mouse1은 왼쪽, Mouse2는 가운데, Mouse3은 오른쪽, Mouse4는 뒤로, Mouse5는 앞으로예요.

충돌 확인·덮어쓰기·기본값 복원·프로필 가져오기/내보내기·AI의 `editor.shortcuts.get/set` revision 처리는 기존 단축키 경로와 같아요. 뷰포트에서 실행 경로가 없는 그래프 전용 등의 명령에는 마우스 조합을 지정하지 못하게 검증해요. 키보드 단축키는 그대로 사용할 수 있어요.

명시적으로 지정한 조합만 장면·추가 뷰포트의 캔버스에서 처리해요. 누른 뷰포트를 활성화하고 카메라·선택 조작보다 먼저 명령을 실행해요. 기본 프로필에는 마우스 조합을 추가하지 않으며, 지정하지 않은 입력은 기존 조작을 따라가요. 이미 진행 중인 드래그·여러 버튼을 함께 누르는 카메라 조작·터치·펜·게임 실행 중 입력은 이 경로로 가로채지 않아요. 분리된 캔버스의 소유 문서에 열린 대화상자도 확인해요.

이는 저장·프레이밍·도구 선택 등의 단발 편집기 명령 지정이에요. 연속 카메라 드래그 축 전체의 재지정이나 게임·모바일 입력 설정을 바꾸는 기능은 별개예요. 마우스 조합이 없는 프로필과 휠 입력에서는 추가 명령 조회·대화상자 탐색을 건너뛰어요.
