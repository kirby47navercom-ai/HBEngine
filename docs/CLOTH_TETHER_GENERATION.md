# 고정점에서 거리 연결 생성

천·2D/3D 로프의 **입자 최대 거리**에서 길이 여유를 정하고 **고정점에서 생성**을 눌러요. 기존 고정 영역과 입자 고정 재정의를 기준으로 자유 입자마다 연결 하나를 작성해요. 고정점이 없으면 변경하지 않고 알려줘요. 생성은 기존 컴포넌트 필드 변경 한 번으로 적용되어 Undo·검증·저장을 함께 사용해요.

천에서는 작성 격자의 가로·세로 연결을 따르는 최단 경로, 로프에서는 이웃 입자 체인을 따르는 최단 경로를 계산해요. 직선거리로 가장 가까운 고정점을 고르는 방식과 달라요. 경로 거리가 같으면 번호가 가장 작은 고정점을 선택해요. 최대 거리는 경로 길이 × 길이 여유이며 기본 배율은 1.1이에요. 고정 입자에는 연결을 만들지 않아요.

장면에서는 현재 부모 계층을 포함한 실제 월드 변환으로 축 길이를 계산해요. 비균일 크기·전단·반사도 거리 계산에 반영하고, Rope2D는 물리와 같은 XY 투영 길이를 사용해요. 블루프린트 정의는 기준 크기의 형상에서 생성해요. 생성 뒤에는 기존 거리 제약에 저장된 월드 미터 값을 사용하며, 실행 중 고정점이 바뀌어도 자동으로 다시 생성하지 않아요.

AI는 `scene.cloth.tethers` 또는 `blueprint.cloth.tethers`에 문서 경로·`expectedRevision`·컴포넌트와 선택한 `stretch`를 보내요. 장면은 `target` 오브젝트 ID가 필요해요. `dryRun`은 문서를 바꾸지 않고 검증·요약을 반환하고, 전체 제안 데이터는 `includeData:true`일 때만 반환해요. 기존 문서 CAS·Undo 경로를 사용해요.

규칙적인 격자/로프 저작 도구이며 임의 메시·구멍·절단된 표면의 지오데식 계산을 추가하지 않아요. 물리 계산은 기존 엔진의 거리 투영 경로를 사용하고, 생성기가 물리 몸체나 런타임 검색 작업을 만들지는 않아요.
