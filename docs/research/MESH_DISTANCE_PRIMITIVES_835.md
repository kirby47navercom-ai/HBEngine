# 큰 기본 도형의 거리장 정밀도·페이로드

2026-10-19. [810–825 메시 거리장 AO](MESH_DISTANCE_FIELD_AO_821.md)에 이어 기본 도형의 복셀 손실과 자기 차폐 편향을 줄였어요. 새로운 임의 메시를 bounding box로 바꾸는 기능이 아니에요.

## 판별·계산

닫힌 메시의 삼각형 12개가 실제 여섯 축 정렬 면을 이루고 각 면의 두 삼각형이 네 모서리와 대각선을 공유할 때만 상자로 판별해요. 일관된 edge topology도 필요해요. 열린 두 삼각형이 한 축 정렬 평면의 네 모서리를 대각선으로 채울 때만 직사각형으로 판별해요. 메시 이름·Geometry 타입·AABB 크기만으로 판별하지 않아요.

이 두 경우에는 정확한 로컬 거리식과 기존 강체 역변환/BVH를 사용해요. 복셀·보간 오차·그에 따른 자기 차폐 오프셋이 없어져요. 월드 비균일 크기는 기존 보수적 거리 하한을 유지해요. Float32 월드 정밀도·곡면 및 큰 일반 모델의 제약이 모두 해소되는 것은 아니에요.

생성 API의 기본 동작은 여전히 볼륨이고 `preferAnalytic:true`를 요청하면 판별된 도형만 이 경로를 사용해요. 장면 AO는 이를 요청해요. 동일 atlas의 field header에 종류를 담아서 GL·TSL·HLSL이 식/볼륨을 분기해요. 추가 sampler·GPU buffer·디스크 파일은 없어요. `analyticFields/voxelFields`로 진단할 수 있어요. `ready`는 현재 일부 차폐체라도 사용할 수 있음을 뜻하며 전체 준비 확인에는 `pending===0`도 필요해요.

변경한 예산으로 이전 작업과 decoded 볼륨을 유지하지 않아요. 새 생성은 남은 로컬 볼륨 예약량과 입력 예산 안에서 진행하고, 일반 볼륨이 맞지 않아도 식으로 처리하는 도형은 준비할 수 있어요. 실패 수와 최대 세 개의 `failureExamples`를 제공해요. 이는 진단 출력 제한이며 오브젝트 수 제한이 아니에요. BVH 오브젝트 경계는 CPU 변환 결과를 Float32로 저장할 때 바깥 방향으로 반올림해 그 과정의 잘못된 가지 생략을 막아요. 이 처리는 월드 전체 정밀도를 무한하게 만드는 기능은 아니에요.

## 검증

- 830: 실제 삼각형 BVH/winding을 독립 기준으로 상자·역방향 상자·큰 직사각형 3,000점 대조. 최대 오차 2.28e-13, scalar 볼륨 0B, 오브젝트 하나의 전체 atlas 208B. 모서리 변형·열린 상자·중복/겹친 면·비축 정렬 사각형·일반 구면은 이 경로를 거절하고 볼륨으로 남겼어요. 명시적 일반 볼륨 생성도 보존했어요.
- 831-bHCwre: 제작용 GL/WebGPU에서 2,000×2,000 평면과 상자 모두 식으로 처리해 atlas 352B·scalar 0B. 간접광 픽셀 132→109, 직접광 픽셀 67 유지, 이동/비활성 수명 확인.
- 814-1Su5Ql: 실제 GL/WebGPU에서 두 상자와 일반 구면 볼륨을 섞어 각 36점 대조. 최대 오차 4.76e-7, 차폐 0.5301428·빈 공간 0이 일치했어요. 일반 볼륨 분기도 같은 atlas에 남아 있어요.
- 818-VSbbsw: 새 D3D 패키지 C++·키보드 블프의 차폐 `[201,211,180]` 일치, 비활성 `[216,224,201]`, 직접광 `[118,122,75]` 일치. 강체 이동 시 CPU 볼륨 재포장 0도 유지했어요.
- 837-rHbkWh: 실제 worker에서 해상도 64, 예산 1MB에 일반 구면은 명확한 실패 진단·상자는 식으로 준비; 2MB로 올리면 일반 볼륨 1,048,576B와 상자 모두 준비; 1MB로 내리면 이전 decoded 볼륨 0B; 삭제 뒤 유휴 worker·대기 입력 0.
- 812-JhWRbs: 명시적 일반 볼륨의 기존 취소 3종·다음 작업 바이트 동일·유휴 스레드 0. 838의 12 CPU/TSL/이력/설정 회귀가 통과했고, 뒤이은 813에서 Float32 경계가 변환한 여덟 모서리를 포함함을 독립 확인했어요.

해당 수치는 소형 정확성 장면의 페이로드/픽셀이에요. 전체 게임 FPS·GPU heap·드라이버 메모리·모든 모델 최적화의 증거로 사용하지 않아요. 전역 클립맵·시간 신뢰도·방향별 하늘·변형체·일반 모델 세부 정밀도 등 누적 원장은 유지해요.
