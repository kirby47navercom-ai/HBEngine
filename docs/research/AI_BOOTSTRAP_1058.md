# 1058 — AI 첫 탐색 비용 줄이기

사용자 요청에 따라 렌더링 후속 구현은 멈추고 AI가 저장소를 처음 다루는 경로를 정리했어요. 엔진 실행 성능 변경이나 전체 기능 완료를 뜻하지 않아요.

기존 현재 인계는 77,515B이고 과거 작업·현재 설치·다음 지시가 누적되어 있었어요. AI 안내는 약 91KB, 상태 Markdown은 약 133KB예요. 이를 매번 전체 선행 독서할 필요가 없도록 현재 인계를 짧게 바꾸고 과거 원문은 `docs/archive/CODEX_HANDOFF_THROUGH_1049.md`로 이동했어요. 원본은 보존했으며 현재 작업 지시를 과거의 계속 지시와 구분했어요.

## 동작

- Codex `AGENTS.md`와 Claude `CLAUDE.md`에서 공통 `docs/AI_START.md`로 진입해요.
- `node tools/hb.mjs context`는 현재 Git·확정 원장·설치 기록·간단한 구조·26개 분야를 반환해요. 별도 CWD에서도 자신의 엔진 루트를 조회해요.
- 작업명/분야 ID/파일명으로 관련 소스와 최근 근거·검사 후보를 좁혀요. `--symbol`은 실제 코드의 파일/줄/열/짧은 발췌를 반환해요. 무효 옵션·없는 검색은 명시해요.
- 조회 때 현재 파일과 원장을 읽고 영구 대형 색인/캐시/벡터 DB/프로세스는 추가하지 않아요. 생성 헤더·검사·예제·빌드·사용자 데이터는 심볼 검색에서 제외해요. 파일당 2MiB 초과/결과 잘림을 명시해요.
- `hb schema --section blueprint.nodes`처럼 필요한 점 경로만 반환해 AI 입력량을 줄여요. 서버는 기존 전체 응답을 만들며 서버 비용 개선을 주장하지 않아요. 기존 전체 응답과 문서 편집 명령은 유지해요.
- 배포 빌드에 시작 규칙/Claude 안내/현재 인계를 포함해요. 이번에 사용자 설치본이나 이전 렌더링 미커밋 소스는 갱신하지 않아요.

## 확인 범위

`npm run test:ai-context`에서 무관 CWD·한글 블루프린트·2D·정확한 원장 ID·실제 심볼 위치·없는 검색·입력 거부·출력 크기를 함께 확인해요. HTTP는 현재 엔진을 접속하지 않는 격리 stub으로 선택 응답/기존 전체 응답/없는 항목 오류를 확인해요. 원본 측정은 `native/build/ai-context-1058.json`, 보존 요약은 이 문서 옆 `AI_BOOTSTRAP_1058.json`이에요.

실제 Claude/Codex 새 세션의 해석 시간·정확도는 측정하지 않았어요. 로컬 조회 시간과 출력량만 기록해요. 모델의 처리 속도나 전체 엔진 이해가 자동으로 보장된다고 표현하지 않아요.
