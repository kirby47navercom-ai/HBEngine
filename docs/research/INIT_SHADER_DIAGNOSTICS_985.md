# 실제 Complex141 초기 셰이더 준비 비용

기존 엔진 소유 Complex141 장면과 실제 참조 파일만 10개·36635바이트의 독립 재현 레시피로 보존했어요. 사용자 게임이나 프로필은 사용하지 않아요. 새 SDK 게임을 숨겨 실행해 경로 추적·디노이즈·곡면·시간 이력·morph 421채널 및 해제 검사를 함께 수행해요.

980-Bg3Fvd의 최초 경로 준비/화면 획득 구간은 8103.76ms, 실제 파이프라인 구간은 7841.10ms였어요. 제출은 약 1ms이고 대부분은 제출 후 드라이버 준비였어요. 시간 가이드 파이프라인도 5986.7ms였어요. 980-sLKAfd 재실행에서도 비슷한 지연을 확인했고 실제 생성 GLSL/번역 HLSL을 보존했어요. 원문 분석 뒤 드라이버가 사용하지 않는 함수를 이미 제거하는지도 확인했어요.

실제 캡처된 셰이더를 대상으로 서로 독립인 GL 컨텍스트에서 ABBA 순서로 비교했어요. 아래 수치는 게임 FPS가 아니라 해당 원문 하나의 compile/link 시간 평균이에요. 전역 드라이버 캐시·사용자 부하는 통제하지 못했으므로 완전한 cold-start 수치도 아니에요.
