# 052 GPU 2D 스프라이트·마스크·픽셀 정렬

2026-10-07. [설치 순서](../WORK_ORDER_051.md)를 유지해요. 선행 목표 묶음을 완료한 뒤 설치하고, 추가 조사 목표를 이어가요.

## 구현

기존 SpriteRenderer·TilemapRenderer의 에셋/UV/색상/혼합/법선과 카메라·정렬 그룹·범위·마스크 합성 경로를 GPU 노드 머테리얼에 연결했어요. 스프라이트/타일맵의 픽셀 정렬·발광, 기존 `hb::Sprites::Flash`와 같은 BP 실행 서비스를 사용하며 사용자 코드가 GPU 명령을 직접 작성할 필요는 없어요. 타일 레이어에도 기존 스프라이트 효과 갱신을 공유해요. GPU 입자의 살아 있는 위치를 CPU로 가져오지 않고 기존 마스크를 적용해요.

마스크는 RGB 색에 영향받지 않고 알파로 범위를 만들어요. 기본 GL 경로의 색상 의존 문제도 같은 소유 함수에서 고쳤어요. 컷오프와 같은 알파도 기존 GL과 같이 포함해요. 사용한 조합에만 타겟을 만들고 같은 범위를 공유하며, 사용하지 않는 타겟과 장면/머테리얼별 기본 텍스처를 해제해요. 기본 WebGL2는 GPU 모듈을 불러오지 않아요.

## 실제 실행 증거

- `node tools/check-gpu-scene.mjs --2d`: `native/build/gpu-scene-BkkAjH/acceptance.json`.
- `node tools/check-gpu-scene.mjs --2d --webgl`: `native/build/gpu-scene-HBMYkk/acceptance.json`.
- 실제 숨은 Win32/WebView2 release Player에서 파란색 마스크의 비대칭 알파, 안/밖/없음/숨김, 컷오프1, 그룹 범위 분리/공유, 정렬 범위 제외/포함, 입자 안/밖 픽셀 PASS.
- 컴파일한 C++ Flash의 흰 실루엣, 발광, .007 이동의 동일 화면과 .05 이동의 화면 변화, 픽셀 카메라 검정 여백, 픽셀 카메라+마스크, 타일맵 마스크/발광 PASS. 정확한 픽셀 값·장면 상태·원본 SHA는 각 결과에 있어요.
- 반복 장면 전환 뒤 처음의 지오메트리/텍스처 수 복귀, GPU 오류0, Player/서버 종료, 분리 프로젝트 에셋/Source byte 보존 PASS. 기존 2D 확장·엔진 통합 검사 PASS. 장시간 전체 메모리 또는 기존 게임 목표 FPS 증명은 아니에요.

## 읽은 근거와 추가 대조

[Unity SpriteMask API](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/SpriteMask.html)의 자체 설명/속성 표는 스프라이트·입자와 그룹 내부 범위를 다뤄요. 연결된 개별 API 본문까지 읽은 것은 아니에요. [Sprite Mask reference](https://docs.unity3d.com/6000.0/Documentation/Manual/sprite/mask/sprite-mask-reference.html)의 자체 본문/표는 알파·소스·정렬/렌더링 레이어를 설명해요. Supported Renderer 소스, 마스크 피벗과 Rendering Layer Mask가 추가 대조 대상이에요. 현재 HB의 기존 양끝 포함 범위는 유지했으며, 최신 Unity 매뉴얼의 Back 제외 설명과 동일하다고 주장하지 않아요.

[Unity 2D Pixel Perfect 5.1.1](https://docs.unity3d.com/Packages/com.unity.2d.pixel-perfect@5.1/manual/index.html)의 자체 본문/표는 PPU·필터·피벗·렌더 시 스냅·크롭·확대 타겟·카메라 확장을 설명해요. 기존 HB 스냅/뷰포트를 GPU에 연결했으며 모든 확대 타겟·Cinemachine 옵션을 구현했다는 뜻은 아니에요. URP17 페이지 접근 실패는 읽기 완료로 세지 않아요.

[Unreal Paper 2D Sprite Material](https://dev.epicgames.com/documentation/en-us/unreal-engine/paper-2d-sprite-material-in-unreal-engine)의 자체 본문/표는 Lit/Unlit과 Opaque/Masked/Translucent 및 사용자 머테리얼을 구분해요. 비교 이미지와 연결된 전체 머테리얼 편집기 문서는 읽기 완료가 아니에요. 설치된 Three0.180.0 NodeMaterial 위치/마스크/출력, Position/Model·ConditionalNode·ScreenNode·ReferenceNode의 관련 코드를 대조했어요. 읽기 범위와 캐시/SHA는 `native/build/gpu-2d-research-052/manifest.json`에 있어요.
