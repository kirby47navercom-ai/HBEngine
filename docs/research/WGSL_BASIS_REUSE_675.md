# WebGPU 좌표·노멀 수식 재사용 674–675

현재·이전 노멀 수식에서 같은 좌표 함수의 x/y를 따로 읽으며 호출 표현이 반복됐어요. 공용 면 노멀/유효성 함수는 명시 layout과 기존 builder별 `gpuFn` 캐시를 사용하고, barycentric·offset·UV 차분·픽셀 기저에서 반복 결과와 중간 수식을 함수 내부 변수로 재사용하도록 바꿨어요. 전역에 프레임 변수나 uniform을 보관하지 않아요.

`ray-basis675-comparison.json`은 같은 IR 키 세 개의 이전 기본/코팅 노멀 그래프를 대조해요. 생성 WGSL은 62,499B에서 61,592B로 줄었어요. 좌표 함수의 정적 호출 위치는 13→5, 단위 벡터 함수는 14→5예요. 런타임 실행 횟수나 FPS·초기 컴파일 시간의 개선율을 뜻하지 않아요. 복잡한 GL 초기 준비 지연은 별도 잔여예요.

실제 GPU의 `normal-scale-645-hgM5Qy`, `triangle-coordinates-643-6AP3KS`, `pixel-footprint-659-ibTogO` 보고서에서 이전 기본/코팅 노멀·공유 로컬 작은 메시·UV/offset·렌즈 기저를 기존 `4e-5`로 대조했어요. 미사용 코팅 decoder 제외와 기능 플래그도 유지해요. 새 텍스처·타깃·uniform·운영 readback은 없어요.

후속 변경은 TSL뿐이에요. Player668 바이너리 안에 현재 생성 네이티브 shader 본문이 바이트 그대로 있는 것을 확인해서 동일한 C++ 재빌드를 반복하지 않았어요. 이 증거와 정확한 지문은 비교 JSON에 있어요. 실제 게임·설치본 대조는 후속 원장에 연결해요.
