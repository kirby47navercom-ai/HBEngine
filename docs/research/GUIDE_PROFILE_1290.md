# 꺼진 곡면 가이드의 WebGL 준비 비용

2026-10-22. 대상은 엔진 소유 Complex141 10파일 재현 장면이에요. 실제 머테리얼은 6노드이고 전체 GLSL 약120kB예요. 보존된980 HLSL은 초기 출력과 컴파일 입력을 각각 포함해 같은 함수를 두 번 세면 안 돼요. 1086의 74B SSA 실험은 다시 수행하지 않았어요.

## 원인과 변경

보조 가이드의 `curved=auxiliary&&hbGeometryRecords.w>.5&&…`는 기능을 꺼도 런타임 조건이어서 드라이버가 이전 표면·차분 광선 분기까지 준비했어요. 확정된 false 설정만 컴파일 상수로 만들고 켜짐/기본 호출은 원래 소스를 유지해요. 렌즈의 평면 차분, 현재 노멀, 이전 점의 투영·거부는 유지해요. 공용 GLSL/HLSL/TSL 수식은 그대로이며 WebGL의 알려진 설정 특화만 바뀌어요.

패스 준비 키와 진단에 곡면·렌즈 상태를 연결했어요. 설정 전환은 오래된 대기를 취소하고 시간 이력을 무효화해요. 곡면만 바뀌면 보조 머테리얼만 재생성하며 노멀 머테리얼·타깃 UUID는 같아요. 해제하면 변형 노멀 스냅샷도 해제돼요. 새 타깃·작업자·주기 타이머·영구 캐시는 없어요.

## 근거

- `guide-profile-1288-ty5hao/acceptance.json`: pure 7그룹, 16조합의 기본 소스 호환·타입·재사용·준비 키·취소·선택 진단. GPU 성능 검사는 아니에요.
- `guide-profile-1287-QLNCoo/acceptance.json`: 사설 후보 비교. 카메라/거울을 둘러싼 확산 수신벽을 추가해 출력이 실제로 관측돼요. 전체320×240 raw-half 307200성분에서 차이0이에요. 원래 거울만 있는 장면의 전부0 출력으로는 동일성 근거를 세지 않았어요.
- `guide-profile-1289-IKzoLx/acceptance.json`: 현재 제품 생성기를 수정하지 않은 실제 패키지 WebGL2. 기존 비특화 기준과 전체 가이드가 정확히 같고, C++ 설정으로 on/morph/off를 전환했어요. 변형 후119451성분 변화, 노멀/타깃 재사용, 끈 뒤 스냅샷 해제, 정상 종료를 확인했어요.
