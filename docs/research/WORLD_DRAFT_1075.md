# 월드 편집 중복 복사 절감

2026-10-20. 위젯/AI 설치1072 이후 남아 있던 WLD-03/PER-03의 큰 에셋 편집 비용을 이어서 줄였어요.

기존 사람 편집기는 문서를 깊게 복사한 다음 순수 브러시/폴리지 함수가 같은 큰 문서를 다시 복사했어요. AI의 `automationAuthoringEdit`도 같은 중복이 있었어요. 새 `withWorldDraft`는 동기 트랜잭션 안에서만 깊은 복사본의 소유권을 표시해요. 해당 함수는 이미 소유한 복사본을 사용하고 트랜잭션 밖에서는 기존처럼 순수 복사를 해요. JSON 필드로 소유권을 부여하거나 검증을 우회할 수 없어요.

지형 평활화는 이웃의 원래 높이만 별도 배열로 보존해서 순서에 따라 결과가 바뀌지 않게 했어요. 폴리지의 변환/복제/삭제/산포/소거도 원본·ID·결과를 보존해요. 콜백/결과 검증이 실패해도 원본 문서와 Undo 기록을 먼저 바꾸지 않아요. 사람과 AI의 기존 명령·CAS/dryRun·Undo/저장을 그대로 사용해요.

`native/build/world-draft-1074.json`에서 지형 8개 모드를 순수 함수 결과와 대조했고 20,003개 폴리지의 5개 연산도 대조했어요. 큰 문서 전체 복사가 각 연산의 편집+함수 경로에서 2회→1회로 줄었어요. 한 번의 CPU 관찰은 기존 약64–79ms, 소유 복사본 경로 약23–34ms였어요. 이는 해당 연산의 검증 포함 샘플이며 전체 편집기·Undo 비용이나 게임 FPS 측정이 아니에요.

기존1059의 부분 위치/노멀/색·인스턴스 전송·격자 광선·최신 미리보기 검사도 다시 통과했어요. 설치본의 실제 사람/AI/Undo·GPU 부분 업로드는1077 영수증에서 따로 확인해요. UI1072 증거와 네이티브 실행 파일은 소유 지문이 같으면 재사용해요.

문서 최초 복사 한 번, Undo 스냅샷, 전체 검증·변경 비교/일부 선택 스캔은 남아 있어요. 소유하지 않은 순수 함수의 불변성이나 검증을 없애는 최적화는 적용하지 않았어요.
