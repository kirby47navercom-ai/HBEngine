# 큐브맵의 사용자 지정 밉

큐브맵도 `images`에 기본 여섯 면, `mips`의 각 원소에 다음 여섯 면을 지정해요. 면 순서는 기존 +X, −X, +Y, −Y, +Z, −Z예요. 모든 면은 같은 정사각형 크기이며 하위 레벨은 절반을 내림해1×1까지 이어져요. 기존 에셋 편집기의 밉·면 선택, 픽셀 조회, Undo/저장을 사용해요. 같은 descriptor를 머테리얼, C++의 기존 `Materials::SetTexture/SetFloat`, 블루프린트와 AI가 사용해요.

고정된 Three 소스의 큐브 업로드는 하위 `mipmaps[j]`를 레벨j+1에 올려요. 반면 공통 할당은 그 배열 길이만 세고 있어 필요한 마지막 레벨이 빠져요. WebGPU는 기존 생성/업로드 훅에서 기본 레벨을 포함한 실제 개수를 사용해요. WebGL은 해당 에셋의 동기 `initTexture` 동안 그 큐브의 저장 할당 개수만 맞추고 `finally`에서 원래 컨텍스트 메서드를 복원해요. 자동 생성이나 매 프레임 보정은 하지 않아요. 외부 라이브러리 파일도 바꾸지 않아요.

연속된 여섯 면은 같은 RGBA8 버퍼의 view를 공유해요. clone, 네이티브 패킹, 광선의 현재·이전 샘플과 CPU 베이크도 같은 레벨 배열을 읽어요. 큐브가 광선 자료로 들어갈 때 작성된 기본 버퍼를 JavaScript 숫자 배열로 펼치지 않아요. 캐시는 텍스처 버전이 바뀌면 교체하며 과거 버전을 누적하지 않아요.

- 705 CPU: 세 레벨/여섯 면의 바이트·504B 자료량·공유 버퍼·clone·버전 무효화·광선/베이크·잘못된 면/크기/개수 거부.
- 694 6HPzdY: 실제 GL/TSL 그래프의 여섯 면×세 레벨×두 API36표본, 제작 미리보기와 Undo/저장.
- 695 xvWz7B: 실제 D3D의18표본과 잘못된 체인5개 거부.
- 696 SZ96GZ: 실제49에셋 패키지, C++ LOD0/1/2와 큐브 타입 교체, 키보드 블루프린트 복원·유휴 업로드 안정.
- 697 FAMb1i/gLuKxY: 실제 GL/TSL/HLSL의 현재 시각과 이전 기하·시각의 독립 RGBA8 노멀 정답, 기존4e-5·이전 재현/GL-GPU 차이0.

읽은 로컬1차 소스는 Three의 `WebGLTextures` 큐브 업로드, `WebGPUTextureUtils._copyCubeMapToTexture`, 공통 `Textures.getMipLevels` 구역이에요. 전체 라이브러리나 UE/Unity 문서의 분석 완료로 세지 않아요. 이 결과도 압축·스트리밍·전체 곡면 대응이나 엔진 전체 완료를 뜻하지 않으며 다음 구현을 이어가요.
