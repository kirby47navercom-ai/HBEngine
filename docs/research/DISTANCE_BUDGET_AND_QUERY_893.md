# 거리장 예산 적합화·조회·주소 정밀도 (880–902)

## 제작과 실행의 변경

- PostProcessVolume의 기존 거리장 해상도 설정은 **최대 해상도**예요. 저장 키·범위·기본값과 C++/블루프린트/AI의 같은 컴포넌트 수정 경로를 유지해요.
- 일반 메시마다 현재 로컬 페이로드 예산에 들어가는 가장 높은 8..요청 해상도를 선택해요. 실제로 선택한 격자에서 원본 삼각형 거리를 계산하고 그 격자의 보수적 보간 오차를 유지해요. 임의의 오브젝트 수 제한을 추가하지 않아요.
- 최소 격자도 들어가지 않으면 예산 보류로 표시해요. 다른 기하가 제거되어 공간이 생기면 재시도해요. 로컬 예약이 0이어도 정확한 상자·사각형은 스칼라 볼륨 0바이트로 처리할 수 있어요.
- `qualityReducedFields`, `effectiveResolutionRange`, `resolutionExamples`, `budgetDeferredFields`, `deferredExamples`, `pendingVolumeBytes`, `volumeBudgetBytes`로 사람과 AI가 같은 상태를 읽어요. 예제 목록만 3개로 제한하며 실제 오브젝트 처리 수를 제한하지 않아요.
- 저수준 베이크 API는 `minimumResolution`을 명시한 경우에만 해상도를 줄여요. 기존 호출의 엄격한 해상도·예산 실패 동작은 유지해요. 워커 오류의 코드·필요 바이트·최소 바이트를 전달해요. 잘못된 옵션은 워커 생성 전에 거부해요.
- 장면의 로컬 볼륨 예약은 총 페이로드 예산의 65%, 대기 기하 입력은 8MiB예요. 이 수치는 워커 BVH·임시 힙·드라이버 GPU 힙을 포함하지 않아요. 이미 캐시된 저해상도 필드를 이웃 제거 후 자동으로 고해상도로 교체하는 기능과 카메라 클립맵은 이번 변경에 포함되지 않아요.

## 조회와 주소

거리 하한은 `max(월드 bbox 하한, 변환한 필드 하한)`이며 음수가 되지 않아요. 기존 교체 조건이 엄격한 `< best`이므로 bbox 하한이 현재 최선과 같으면 건너뛰고, 최선이 0이면 더 찾지 않아도 첫 번째 동률 오브젝트와 오차가 보존돼요. CPU·GLSL·TSL·생성 HLSL에 동일하게 적용했어요. DirectX의 수치 atlas는 정수 좌표 `Texture2D.Load`로 읽어요. 머테리얼 텍스처의 필터·밉·리소스 슬롯은 바꾸지 않아요.

스칼라 주소를 먼저 float로 곱하면 2²⁴ 위에서 RGBA 성분의 하위 비트가 사라질 수 있어요. 좌표 곱과 4로 나눈 그룹·성분 계산을 정수로 마친 뒤 texel 주소를 float로 바꿔요. 기존 2²⁶ 스칼라 주소 범위를 줄이지 않아요. 기존 float helper 이름도 호환용으로 유지하되 현재 거리 조회는 정수 helper를 사용해요.
