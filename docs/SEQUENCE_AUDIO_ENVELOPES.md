# 시퀀스 오디오 음량과 페이드

오디오 클립을 선택하면 음량(0–1), 페이드 인·아웃(클립 길이 이내), 음량 곡선을 편집해요. 기본값은 음량1·페이드 없음이에요. 시작·종료 페이드가 겹치면 두 선형 램프의 작은 값을 사용해요. 음량 곡선은 기존 선형·계단 단위 곡선 형식이며 32개 키씩 편집하고 같은 시퀀스 키 예산에 포함해요. 키 추가·삭제·프리셋·시간/값/보간 변경과 Undo/Redo/저장은 기존 문서 검증을 통과해야 해요.

음량은 **클립이 놓인 시퀀스 시각**을 따라가요. PCM의 원본 시작·배속·역방향과 별개이고, 부모 시간 매핑이 뒤로 움직이면 페이드도 뒤로 움직여요. `hb::LevelSequence::Seek/Pause`와 블루프린트 시퀀스 제어도 같은 평가 경로를 써요. 음량은 기존 오디오 에셋 볼륨·믹서·더킹·공간 감쇠와 곱해져요. 시퀀스 레이어 가중치는 오디오 음량을 대신하지 않아요.

기존 PCM 출력 GainNode 하나를 사용해요. 일정한 부모 속도의 선형 페이드와 단독 선형 음량 곡선은 다음 경계까지만 AudioParam 램프를 예약해요. 예약 창은 최대60초이며 긴 페이드의 실제 기울기는 유지해요. 무페이드 상수 클립은 계획을 재사용하고 같은 음량을 반복 쓰지 않아요. 곡선 준비는 약한 참조와 이진 탐색을 사용하고, 매 프레임 모든 키를 검증·복사하지 않아요. 실제 출력 음량은 real/virtual 음성 선택에도 반영해요.

일시정지·수동 시계에서는 평가된 음량에 고정하고, 탐색·방향 변경은 기존 예약을 취소하고 현재 값부터 다시 예약해요. 계단 곡선, 페이드와 곡선의 곱, 비선형 시간 매핑은 VM 샘플에서 다시 맞춰요. 일반적인 표본 단위 비선형 시계·피치 유지·장치 genlock을 보장하는 기능은 아니에요.

Take 큐 녹화는 관찰된 클립 음량을 선형 키로 줄여 저장해요. 상수 음량은 `volume`만, 기본1은 필드를 생략해요. 방향·속도 변경과 반복 분할은 각 클립 구간에 맞춰 음량 곡선을 잘라요. 녹화 시각은 기존 Take의 프레임 시각이며, 오디오 장치 표본 시각과 동기화됐다는 뜻은 아니에요. 실제 믹스 PCM 캡처는 라우팅 뒤 출력을 그대로 받아요.

AI는 `sequenceAudio.envelope` 계약과 기존 `document.patch/transaction`을 사용해 `tracks[i].clips[j]`의 선택 필드를 수정해요. 애니메이션·몽타주 클립에는 오디오 전용 필드를 넣을 수 없어요. `sequenceAudioEnvelope`, `editSequenceAudioGain`, `recordTakeAudioGain`은 집중 소유자 조회를 지원해요.
