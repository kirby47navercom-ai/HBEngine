# 반복 곡선의 부분 베이크

곡선 편집기의 베이크 도구에서 범위와 FPS를 지정하면 원래 키 범위 밖의 반복·반복+오프셋·왕복 구간도 베이크할 수 있어요. 범위 안에는 기존 형식의 선형 키를 만들고, 범위 밖은 원래 주기와 현재 기준 곡선을 사용해요. 이 키는 목록과 그래프에서 그대로 편집할 수 있어요. 숨겨진 원본 곡선 사본을 별도로 저장하지 않아요.

예를 들어 원래2~4초 곡선의5~6초를 베이크해도 주기는2초로 남아요. 새 키가6초에 생겼다고 주기가4초로 늘어나지 않아요. 여러 부분 베이크는 구간을 합치고, 겹치지 않는 기존 베이크는 보존해요. 원래 주기 안의 값도 베이크하거나 편집하면 그 변경된 기준 곡선이 반복되므로 다른 반복의 값에도 반영돼요. 베이크는 지정 FPS로 근사하며, 샘플 사이의 원래 비선형 모양까지 정확히 보존한다는 뜻은 아니에요.

파일에는 선택 필드 하나만 추가해요. 모든 값은 기존 `keys`에 있어요.

```json
{"infinityDomain":{"start":2,"end":4,"ranges":[{"start":5,"end":6}]}}
```

두 원래 주기 경계와 각 베이크 구간의 경계는 키로 남겨야 해요. 그 경계를 지우거나 일부만 이동해서 형식을 깨뜨리는 편집은 원자적으로 거부해요. 곡선 도구 막대의 **주기 2–4초** 버튼을 누르면 고정을 해제할 수 있고 Undo로 복원할 수 있어요. 해제 후에는 현재 전체 키 범위가 일반 반복 주기가 돼요. 전체 키의 시간 변환은 주기·구간도 함께 옮기고, 축약은 이 경계 키를 유지해요. 전체 베이크는 새 범위를 사용하고 고정 정보를 제거해요.

AI는 기존 `sequence.curve.tool`의 `operation:"bake",rangeOnly:true,start,end,fps`를 사용해요. revision·dryRun·Undo·전체 키 예산은 기존 계약을 유지해요. `sequence.curve.edit`의 `resetDomain:true`는 같은 고정을 해제해요. JSON 문서 편집도 동일한 검증을 거쳐요. C++·BP Play/Pause/Seek와 애니메이션·Timeline은 공용 샘플러를 사용해요.

런타임에는 키 배열별 약한 준비 캐시에서 원래 주기 안의 키 참조만 한 번 선별해요. 값·키 전체를 매 프레임 복사하지 않고, 베이크 구간은 이진 검색해요. 타이머·worker·GPU 자원은 추가하지 않아요. 실제 프레임 시간이나 전체 heap 절감을 측정한 수치는 아니에요.

쿼터니언 회전과 이산 값의 주기 고정 메타데이터는 지원하지 않아요. 기존 이산 값의 반복과 첫 키 이전 유지 규칙은 그대로 지원해요. 참조를 캐시에 보관하기 위한 `stable` 읽기도 이 규칙을 따르며, 별도의 `reference` 모드가 가진 첫 키 이전 미정의 규칙을 대신 적용하지 않아요. 독립 축별 키 시간·보간·삭제 저장은 별도의 잔여 범위예요.
