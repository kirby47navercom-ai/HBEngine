# 다중 목표 IK의 제한된 늘이기

Full Body IK 노드에 **늘이기 허용**과 **최대 길이 배율**을 추가해요. 기본은 끄기이며, 예전 그래프에 필드가 없어도 길이를 유지해요. 최대 배율은 1~10, 생략 시 1.5예요. 그래프 편집기·JSON 저장·AI 문서 검증과 실행기가 같은 검증을 사용해요.

활성 목표가 현재 체인 길이 밖에 있으면 공유 CCD 회전 평가 전에 필요한 길이를 구해요. 여러 목표가 한 뼈 구간을 공유하면 가장 큰 요청을 한 번 적용하고, 목표 수나 프레임마다 곱하지 않아요. 원본/참조 포즈는 수정하지 않아요. **뼈 설정 → 늘이기 위치 강성**이 0이면 허용하고 1이면 그 구간 길이를 유지하며 중간값은 길이 변화를 줄여요. 제외 뼈도 해당 구간 길이를 유지해요. 루트 위치 강성은 기존 루트 이동 제어에 계속 사용해요.

```cpp
hb::AnimationGraph::SetIKStretchSettings(actor, "Full", true, 1.5f);
```

BP **다중 IK 늘이기 설정**도 같은 실행 명령이에요. 이 명령은 활성 노드 override에만 적용하고 저장된 그래프는 수정하지 않아요. 목표별 가중치, 노드 Alpha, 루트 pin/이동과 기존 관절 회전 제한을 함께 적용해요. 진단에 `stretchedBones`, `maxStretchFactor`, 목표별 잔여 오차를 보여줘요. 설정을 끄거나 Alpha가 0이면 입력 길이로 돌아가요.

제한된 운동학적 늘이기이며 늘이기/압축을 결합해 에너지를 최소화하는 해법은 아니에요. 여러 목표의 충돌, 고정 구간이나 강한 관절 제한으로 도달할 수 없으면 기존 잔여 거리 진단을 유지해요. 전용 리그 stage·컨트롤/기즈모·일반 압축 해법·복잡 리그 품질 검증은 별도예요. `schema.fullBodyStretch`에서 계약을 조회해요.
