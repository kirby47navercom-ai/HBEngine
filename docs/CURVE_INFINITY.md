# 곡선의 키 범위 밖 재생

공용 커브 편집기의 **이전·이후**에서 첫 키 앞과 마지막 키 뒤를 따로 설정해요. 키가 없거나 하나이면 기존 유지 동작이에요. 설정이 없거나 `constant`이면 기존 샘플링 경로를 그대로 사용해요.

|설정|동작|
|---|---|
|유지 `constant`|가장 가까운 끝값 유지|
|선형 `linear`|끝 키의 진입/진출 기울기로 연장; 계단/상수 끝은 기울기0|
|반복 `cycle`|첫 키와 마지막 키 사이의 시간으로 반복|
|반복+오프셋 `cycleOffset`|반복마다 마지막 값−첫 값 누적|
|왕복 `oscillate`|홀수 주기를 반대로 샘플링|

반복 길이는 전체 에셋 길이가 아닌 첫/마지막 키 사이예요. 원래 키 구간과 정확한 끝 키는 기존 값을 유지해요. 그 밖의 정확한 반복 배수는 첫 키로 매핑하고, 오프셋 반복은 주기 수에 따른 값을 더해요. 음수 시간도 같은 규칙이며 왕복은 음수 홀수 주기도 반대로 읽어요. 가중 Bézier는 매핑된 시간에서 평가해요. 키 복제·베이크·주기별 캐시는 만들지 않아요.

범위 설정은 트랙의 선택 필드 `preInfinity`, `postInfinity`예요. 기존 `sequence.curve.edit`에서 범위만 바꿀 때 `key`를 생략할 수 있어요. `null`은 기본 유지로 복원해요. 키의 가중치/기울기를 바꾸려면 여전히 키 인덱스가 필요하고 잘못된 자료형·모드·revision은 원자적으로 거부해요. 기존 document.patch·Undo·저장도 같은 검증을 써요.

블루프린트 타임라인·커브/트랜스폼 애니메이션·연속 시퀀스 트랙은 같은 계산을 써요. 골격 클립의 속성/모프/머테리얼 구동 곡선도 같은 가중치·보간·범위 검증과 AnimationGraph 샘플러에 연결돼 있어요. 골격 클립의 숫자 메타데이터 곡선은 현재 공용 그래픽 곡선 편집기·키/핸들·주파수 필터와 JSON/AI 편집을 사용해요. 자세한 현재 조작은 [CURVE_TOOLS](CURVE_TOOLS.md)를 봐요. 시퀀스 크기는 기존 역변환 가능한 최솟값으로 보호해요.

시퀀스의 **쿼터니언 회전**은 유지·각속도 유지·반복·회전 누적·왕복을 선택해요. **이산 값**(표시, 변수·C++ 속성, 컴포넌트 속성)은 트랙 속성의 이전/이후 범위에서 유지·반복·왕복을 선택해요. `sequence.curve.edit`도 같은 필드를 사용하며 이산 값의 범위만 바꿀 때 키 인덱스가 필요하지 않아요. 쿼터니언은 매핑한 시간에서 기존 최단 회전 구간의 slerp를 사용해요. 이산 값은 이전 키의 값을 유지하며 배열/레코드 결과의 복사 소유권을 보존해요. 음수 시간·정확한 끝값·단일/빈 키도 기존 규칙을 따르고 키를 복제하지 않아요.

이 값 반복은 이벤트 발화, 클립, 부모·생성 참조, 골격 상태 트랙의 실행 시계를 바꾸지 않아요. 이 종류는 기본 유지 계약을 사용해요. 이산 값의 `linear`·`cycleOffset`은 거절해요. 쿼터니언은 아래의 각속도 유지·회전 누적 계약을 사용해요. 이산 값에는 숫자 탄젠트를 추가할 수 없어요. 잘못된 범위 변경은 기존 데이터·revision을 보존하며 Undo/Redo·저장·패키지 재생은 같은 시퀀스 샘플러를 사용해요.

공용 편집기의 전체 맞춤은 명시 범위 모드일 때 에셋 내32구간의 값도 포함해 연장된 선이 잘리지 않게 해요. 안쪽/기본 유지 샘플은 새 배열·작업자·타이머·GPU 자원을 만들지 않아요. 범위 밖 명시 반복만 추가 시간 계산과 기존 키 이진 탐색을 사용해요.

## 근거와 검증

[Unreal5.8 Curve Editor의 Pre and Post Infinity](https://dev.epicgames.com/documentation/unreal-engine/animation-curve-editor-in-unreal-engine)의 다섯 모드/키 구간 규칙을 읽고 대조했어요. [Unity WrapMode](https://docs.unity.com/en-us/engine/6000.7/script-reference/unityengine/wrapmode)의 API 정의/필드 발췌에서 Loop·PingPong·ClampForever와 구분을 확인했어요. Unity의 Once/Default 상속이나 클립 전체 반복을 HB의 개별 곡선 설정과 동일하다고 주장하지 않아요. 연결 API·엔진 전체 분석 완료로 세지 않아요.

`check-curve-infinity-1310.mjs`는 독립 시간/값 표·음수/정확한 경계·가중 벡터+두 오프셋 주기·기존 유지·공용 샘플러·자료 검증/원자성·실제 외부 골격 AnimationGraph를 대조해요. 기존 가중240표본/9그룹·시퀀스17·리타게팅 검사도 보존해요. `check-curve-infinity-1311-window.mjs`는 기존 실제 핸들/Undo/AI/게임 검사를 재사용해 범위 UI와 키 없는 AI 편집, Blueprint 중첩 재생을 확인해요. 가중 매개변수1/4·오프셋2주기·회전된 기준점의 독립 예상 위치는[10,44.125,0]이에요. 설치본은 `--player --executable`로 같은 게임 경로를 확인해요.

쿼터니언 각속도 유지·회전 누적의 새 경계 의미와 공용 실행은 [쿼터니언 범위 밖 회전](QUATERNION_INFINITY.md)을 봐요. 이산 값의 제한은 유지해요.
