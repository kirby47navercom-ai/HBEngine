# 정확한 곡선 제어점

키 사이에서 부분 베이크할 때 수직 핸들이나 1보다 큰 시간 핸들이 생겨도 구간 밖의 원래 Bézier 모양을 보존해요. 같은 샘플러를 쓰는 BP 타임라인·Sequence·골격 커브와 C++ 시퀀스 재생에 적용해요. 첫 키 밖·마지막 키 밖의 부분 베이크는 여전히 별도예요.

선택 필드 `arriveControl`·`leaveControl`은 **키 값에서 제어점까지의 부호 있는 값 축 오프셋**이에요. 스칼라면 숫자, 벡터면 같은 길이 배열이고 각 성분은 유한한 ±1e12 범위예요. `arriveWeight`·`leaveWeight`는 인접 키 시간 간격에 대한 수평 비율이에요. 각 비율은 0~4/3이고, 양 끝의 조합이 구간 전체에서 시간 역행을 만들면 거절해요. 두 가중치가 각각 범위 안이라는 이유만으로 허용하지 않아요.

```json
{"time":0.5,"value":0.5,"interpolation":"break",
 "arriveWeight":0,"arriveControl":-0.25,"arriveTangent":0}
```

위 키의 진입 제어점은 같은 시각 0.5, 값 0.25에 있어요. 시간 가중치 0에 값 오프셋이 있어도 정확히 평가해요. 제어점이 있으면 저장된 유한 탄젠트보다 우선해요. 수직 핸들의 탄젠트 필드는 유한한 호환 값일 뿐 실제 무한 기울기라고 표시하지 않아요. Clamped Auto는 기존처럼 명시적 제어점과 시간 가중치를 무시하고 이웃 기반 기울기를 사용해요.

편집기는 수직 탄젠트 칸에 **수직**을 표시하고, 수직으로 드래그하면 시간 가중치 0을 유지해요. 선형으로 베이크된 키도 이전 구간이 곡선이면 진입 핸들을 보여줘요. 그 진입 핸들을 수정해도 나가는 선형 구간의 보간 방식은 바꾸지 않아요. 숫자 탄젠트를 입력하면 해당 방향의 제어점을 유한 기울기로 변환해요. 명시적 제어점의 가중치 입력은 X만 바꾸고 Y는 유지해요. 한쪽 핸들의 기울기가 수직이라 정의되지 않을 때 선형 infinity는 저장된 유한 호환 탄젠트를 사용해요.

시간·값 변환, 키별 채널 도구, 클립보드, 저장·Undo·AI 검증이 오프셋을 보존해요. 값 배율은 오프셋에도 적용하고, 시간 배율은 오프셋을 바꾸지 않아요. 자동 보간·평탄화·숫자 탄젠트 같은 명시적 편집은 선택한 핸들을 해당 편집 결과로 바꿔요. 시간 역행·자료형·범위·예산 오류는 문서 전체 편집을 거절해요.

AI는 `schema.curveExplicitControls`와 `curveControlValue`·`curveTimeMonotone`·`subdivideCurve` 소유자를 읽어요. `sequence.curve.edit`와 기존 `document.patch`에서 선택 필드를 설정할 수 있고 revision·dryRun·Undo·저장을 공유해요. `hb.curve.keys` 클립보드 버전 1은 선택 필드 두 개를 함께 보존해요. 기존 필드를 생략한 키는 그대로 평가하며 파일을 일괄 변환하지 않아요. 새 제어점이 담긴 파일에는 업데이트된 엔진이 필요해요.

추가 런타임 테이블·워커·타이머·GPU 자원은 없어요. 분할한 경계 주변 키에만 제어점을 기록하며, 기존 키의 기본 Hermite·가중 샘플링 경로를 유지해요. 문서 검증 때 구간의 시간 단조성을 확인하는 선형 순회가 추가돼요. 기존 1378의 Curve Editor 베이크 읽기 근거를 재사용하며 새 전체 문서 분석으로 계산하지 않아요.
