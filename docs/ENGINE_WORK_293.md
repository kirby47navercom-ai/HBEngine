# 293 · C++ SDK 간접·생성 헤더의 캐시 무효화

- 대표9개 헤더 목록 대신 전체 SDK include와 JSON 의존 헤더의 경로/내용 SHA를 빌드 키에 포함해요. 생성 헤더 준비 뒤 계산하며 persistent digest cache와 프레임 작업은 추가하지 않아요.
- 빌드 응답의 sdk.fingerprint/files/bytes로 실제 SDK 기준을 AI와 사람 모두 확인할 수 있어요. 같은 내용의 timestamp 변경은 캐시를 유지하고 내용·경로·추가/삭제·의존 파일 변경은 무효화해요.
- 별도 SDK의 실제 GCC worker에서 사용자 C++를 고정한 채 간접 헤더만17→31로 고쳤어요. 첫 빌드 miss/두 번째 hit/헤더 변경 miss와 실제 반환17/17/31을 확인했어요.

범위와 한계:

- 첫 새 버전에서는 구형 키 캐시를 한 번 재빌드해요. 매 빌드의 SDK 내용 읽기는 추가되지만 매 프레임 검사나 SDK 전체 복사/영속 이력은 추가하지 않아요.
- 모바일 AOT는 원래 매번 SDK를 복사/컴파일하는 경로예요.293은 새 Android 캐시 기능이나 기기 검증으로 세지 않아요.
