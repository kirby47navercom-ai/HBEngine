# 292 · 불완전 검사 런타임 복사본의 안전한 회수

- 메타 파일이 빠진 private Engine/runtime/node.exe도 실행 중 원본 Node의 크기/SHA/버전과 planner PID를 확인한 경우만 회수해요. 대상과 원본을 PowerShell에서 다시 검증해요.
- 같은 크기의 수정본·다른 런타임·실행 중 사본·원본 소스를 보존하는 실제 프로세스 검사를 통과했어요. 단일 private 표본91694408바이트를 제거했어요.
- 전역 정리는 생성 후1시간이 안 된 작업 루트를 제외해 새 작업과의 경합을 줄여요. 완료한 소유 작업의 개별 정리는 즉시 가능해요.

범위와 한계:

- 실행 중인 다른 Node/C++ 빌드가 있어 전역 정리는 보류했어요. 그 프로세스를 종료하지 않았고 전체 디스크를 정리했다고 표시하지 않아요.
- 사용자 SDK/프로젝트/User 프로필을 삭제하거나 전체 백업을 생성하지 않아요. 시간/PID 검사만으로 임의 경로를 삭제하지 않아요.
