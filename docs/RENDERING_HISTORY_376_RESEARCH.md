# 이전 매질과 필터 폭의 대조

2026-10-18에 지정 본문을 읽고 기존 HB 방사휘도 적분기와 가이드의 차이를 대조했어요. 원문 스냅샷·SHA·미독 범위는 supplemental376에 기록해요. 전체 엔진 문서나 API 분석 완료로 계산하지 않아요.

[PBRT4 Dielectric BSDF](https://pbr-book.org/4ed/Reflection_Models/Dielectric_BSDF)의 도입·완전 정반사/투과 본문을 대조했어요. 양쪽 매질의 상대 굴절률과 투과 가능 여부가 경로를 결정하므로, 이전 경로에 현재 매질 스택을 사용하는 것은 맞지 않아요. HB는 기존 경계 탐색을 이전 세계 BVH·이전 시간으로 실행하고, 이전 IOR와 투과/전반사 분기를 독립적으로 계산해요. 불확실한 경로는 이력을 거부해요. 이것은 PBRT의 거친 BSDF·파장 분산·방사휘도 가중치를 전부 도입한 작업이 아니에요.

[Texture Sampling and Antialiasing](https://pbr-book.org/4ed/Textures_and_Materials/Texture_Sampling_and_Antialiasing)의 선택 구간에서 표면의 국소 평면 근사, 정반사/투과 뒤 차분 광선과 변화하는 법선, 비정반사 경로의 별도 근사 필요성을 확인했어요. HB 방사휘도 적분기는 이미 굴절률과 입출사 코사인으로 국소 광선 퍼짐을 갱신하지만, 가이드의 현재·이전 폭에는 그 갱신이 빠져 있었어요. 같은 모델을 가이드에 연결했어요. PBRT의 전체 법선 미분식이나 타원 필터를 구현했다고 해석하지 않아요.

검사에서는 독립적인 카메라 역투영·Snell 계산과 명시적인 스택 전이 표를 기준으로 사용해요. 세 GPU 경로에서 49개 퍼짐 조건과 18개 경계 전이를 대조하고, 실제 전체 가이드의 폭과 노멀맵 밉 샘플을 확인해요. 정적인 중첩 매질은 이력을 유지하고 이전 카메라가 다른 매질에 있던 경우에는 잘못된 이력을 거부해요. 현재 RGB 소광 스택의 실제 값도 별도로 보존되는지 검사해요.

이전 IOR 스택은 스칼라 16개와 ID 16개예요. 기존 GPU 이미지·버퍼·uniform 필드·자동 readback은 추가하지 않아요. 전역 곡면 역해, 변경된 복합 경로의 대응 탐색, 거친 로브·참여 매질 산란 footprint는 해당 구현과 검증이 필요한 상태로 원장에 남겨요.
