# 텍스처 2D 가져오기와 밉

콘텐츠 브라우저에서 **텍스처 2D**를 만들고 오른쪽 속성에서 원본 이미지를 지정해요. `.hbtexture2d.json`은 이미지 경로와 가져오기 설정을 저장해요. 기존 이미지 참조도 유지해요.

용도는 색상·노멀·마스크·자료이며 자동 색 공간은 색상에 sRGB, 나머지에 선형을 사용해요. 가져오기 단계에서 밉 생성, 상위 밉 제외, 최대 크기, 녹색 채널 반전, 하위 노멀 밉 정규화, 알파 커버리지와 기준값을 설정해요. 최대 크기 0은 제한하지 않는다는 뜻이에요. 샘플러의 필터 설정과 가져올 밉 제한은 별개예요.

중앙 창에서 밉과 채널을 고르고 픽셀을 검사해요. 밉 이름은 원본의 레벨을 표시해요. 화면 아래의 크기·밉 수·저장 바이트는 가져온 RGBA8 자원 기준이에요. 보기 변경은 에셋을 수정하지 않아요. 속성 변경은 기존 저장·Undo에 연결돼요.

밉은 선형 색 공간의 영역 가중치로 축소해요. 알파 커버리지는 원본의 목표 비율을 기준으로 각 밉의 알파를 양자화 전에 조정해요. 조정한 알파를 다음 밉의 원본으로 다시 사용하지 않아요. 작은 밉에서는 목표를 정확히 표현하지 못할 수 있어 `importReport.coverage`에 실제 비율·잔차·표현 간격을 반환해요. 노멀 정규화는 선택한 하위 밉에 적용하고 원본 이미지 파일은 바꾸지 않아요.

GL·WebGPU·DirectX 11·광선 패킷은 같은 생성 결과를 사용해요. sRGB 자원은 래스터에서 하드웨어 변환과 선형 보간을 사용하며, 광선용 데이터는 같은 바이트를 선형 값으로 변환해요. DirectX C++에서는 `SceneRenderer::TextureMipLevel` 배열을 `createTexture`의 마지막 인수로 전달할 수 있어요. 배열에는 기본 레벨을 제외한 하위 레벨을 순서대로 넣어요. 크기·바이트 수·레벨 수와 자동 생성의 중복을 검사해요.

AI는 `engineSchema().textureImport`에서 정책을 조회하고 `document.patch`의 `expectedRevision`, `document.save`, `editor.undo`로 사람이 쓰는 문서를 편집해요. `texture.view`의 `settings.mip`는 가져온 체인의 0부터 시작하는 인덱스예요. 반환값의 `importReport.topMip`가 원본 레벨과의 차이를 알려줘요. 바이트 배열은 편집기 상태 API에 노출하지 않아요.

큰 이미지는 지연 생성한 워커 하나의 대기열에서 처리하고 유휴 상태에서 종료해요. 업로드·생성은 자원 변경 때 수행해요. DirectX 포장 과정에서는 행 반전이 필요 없는 자료의 전체 사본을 만들지 않아요.

이 경로의 지원 범위는 2D RGBA8이에요. HDR·압축 컨테이너, 배열·볼륨의 사용자 정의 밉, 스트리밍, 샘플러 LOD bias, 노멀 분산의 거칠기 합성은 별도 잔여 항목이에요. 기존 raw 이미지로 시작한 sRGB 수동 변환 셰이더에 선형 가져오기 자원을 교체하는 요청은 색 공간 불일치로 거절해요. 해당 머테리얼을 새 자원으로 다시 구성하면 올바른 형식으로 준비해요.
