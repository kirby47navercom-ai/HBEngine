# 천·로프 질량 브러시

기존 장면/BP 컴포넌트의 **입자 질량 가중치 → 질량 브러시**를 열어 사용해요. Cloth 격자는 2차원, Cloth의 3D 로프와 Rope2D는 한 줄로 표시해요. 기존 입자 번호·숫자 지정·기본값·전체 초기화도 유지해요.

반경은 입자 간격 단위이며 .5~128, 강도는 0~1, 목표 가중치는 .001~1000이에요. 감쇠는 부드럽게·선형·일정을 선택해요. 기본값은 반경2·강도1·가중치2·부드럽게예요. 파랑은 1보다 가벼운 상대 질량, 주황은 무거운 상대 질량이에요. 목표1·강도1로 칠하면 해당 희소 재정의를 지워요. 실제 총질량은 컴포넌트 mass로 다시 정규화해요.

주 포인터로 드래그하고 놓으면 기존 검증·상속 기본값·Undo를 거쳐 한 번 적용해요. 드래그 중에는 브러시 그림만 바뀌고 문서·물리 월드에는 쓰지 않아요. 빠른 움직임도 선분 전체와 입자 사이의 거리를 계산해 빈틈 없이 칠해요. 같은 자리에 많은 이동 이벤트가 와도 한 획의 시작 가중치와 최대 영향만 사용하므로 중복해서 누적하지 않아요.

그리드에 포커스를 두고 방향키·Home·End로 입자를 선택하고 Enter/Space로 한 번 칠할 수 있어요. 반복 키는 중복 적용하지 않아요. Escape·pointercancel·캡처 상실·창 blur·문서 숨김은 미적용 상태로 취소해요. 칠하는 중 컴포넌트 입력이 바뀌거나 분리·비활성화되면 오래된 결과를 쓰지 않아요. 적용 후에는 바뀐 인스펙터의 같은 소유자에 포커스와 브러시 설정을 복원해요. 실행 중에는 비활성화해요.

저장 데이터는 기존 `massWeights:[{index,weight}]`예요. 새 런타임 페인트 단계·worker·타이머·C++ SDK를 만들지 않아요. AI 스키마의 clothMassBrush와 정확한 소유자 경로를 제공하며, 기존 componentSetJson과 `hb::Components::SetText`로 같은 데이터를 사용해요. 질량 분포 변경은 기존의 명시적 cold rebuild이며 현재 물리 상태를 초기화해요. 물성만 바꾸는 hot 경로와 구분해요.

희소 행과 현재 획의 영향을 편집 중에만 보유해요. SVG는 입자마다 DOM을 만들지 않고 색상별 path와 패턴을 사용해요. 65536입자 표본의 색상 path는 2개이며, 이는 DOM 구조 확인이에요. 실제 브라우저 그리기·전체 메모리·FPS를 측정했다는 뜻은 아니에요.

이 브러시는 질량 분포를 칠해요. 이동 반경·거리 tether·부분 고정 가중치·임의 스키닝 의복을 구현한 것으로 계산하지 않아요.

WORK2920: 신규13개에서 선분 감쇠·중복 이벤트·희소 지우기·실제 장면/BP 변경/Undo 분기·취소·충돌·키보드·직렬화 후 공용 native-operation/VM/Rapier 실행을 확인했어요. 천과 2D/3D 로프 모두 실제 입자 질량과 전체 질량3을 대조했어요. 관련 기존 질량 UI5개·분포14개도 통과했어요. 브라우저 픽셀·실제 터치·설치 검증은 보류 상태예요.
