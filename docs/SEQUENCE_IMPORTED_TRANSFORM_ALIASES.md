# 가져온 액터 루트·모델 하위 노드의 변환 소유권

가져온 애니메이션의 전체 `position`·`quaternion`·`rotation`·`scale` 바인딩을 실제 Object3D와 필드로 연결해요. 이름과 UUID처럼 다른 경로가 같은 노드를 가리켜도 같은 채널이에요. quaternion과 Euler 회전은 하나의 회전 필드로 중재하고 XYZ 각도와 단위 쿼터니언을 변환해요. 가져오기에서 만든 보간기와 원본 키 배열은 그대로 사용해요.

바인딩이 액터의 바깥 Group을 가리키면 기존 액터 Transform·직접 위치/회전/크기·HB 변환 클립과 같은 필드예요. 기존 C++ `hb::Scene` 조회도 같은 값을 읽어요. 일반 모델 하위 노드는 자체 로컬 변환을 유지해요. 시퀀스 기준점은 액터 루트에만 적용하고, 하위 모델에 중복 적용하지 않아요. 가져온 모델의 루트 노드가 액터 Group의 자식이면 그 노드도 모델 로컬 노드예요. 경로 해석은 기존 THREE PropertyBinding과 같아요.

필드별 우선순위·시작 순서·정규화 가중치·회전 혼합·공백·0 가중치·재활성화·keep/restore·forceRestore를 공용 채널에서 처리해요. 한 시퀀스에서는 트랙 작성 순서가 같거나 겹치는 필드의 마지막 값을 결정해요. 대상별 마지막 활성 애니메이션 트랙을 선택하는 규칙도 유지해요. 클립에 없는 하위 노드 속성을 다른 클립의 높은 우선순위 때문에 함께 잃지 않아요.

공용 필드로 옮긴 트랙만 제어된 믹서에서 제외해요. 비변환 속성은 기존 믹서에서 평가해요. 일반 믹서가 재생하는 액터 루트는 실제 Group 값과 액터 상태를 동기화해요. 공용 채널이 덮은 속성만 그 아래의 일반 믹서 presentation을 보관해서, THREE가 같은 값의 쓰기를 생략해도 다음 프레임과 최종 Stop에서 올바른 값을 보여줘요. 중간에 보관되는 오래된 재생기는 약한 재생기별 기록을 사용해요. 새 외부 재생기를 이전 시퀀스가 다시 빼앗지 않아요.

보관할 재생기의 presentation은 공용 포즈 아래의 값을 캡처해요. 직접 Transform을 쓰고 아직 다음 프레임이 오기 전에 다른 클립을 시작해도 기존 시각·fade·반복 이력을 유지하며 복원해요. 루트·일반 노드와 기존 골격 포즈의 실제 객체 수명을 검사해요. 같은 이름의 새 노드에는 이전 노드 값을 되돌리지 않아요.

기존 시퀀스의 애니메이션·컴포넌트 트랙, 가중치·우선순위 편집, Undo/Redo·저장을 사용해요. AI도 기존 `document.patch` revision·dryRun·Undo 계약을 사용해요. `runtime.animationPlayback`의 각 행에 `transformChannels`가 있어요. `total`, 최대 요청 limit개의 `items`, `truncated`를 반환하고 각 항목은 node 이름·uuid·field·현재 값·제어 여부를 담아요. 값을 복사해서 반환하므로 조회 결과로 숨은 샘플이나 기준값을 변형할 수 없어요. 별도의 공개 C++ 함수나 에셋 필드는 추가하지 않아요.

AI 소유자: `node tools/hb.mjs context "가져온 모델 변환" --symbol ImportedSequenceTransformProgram`. `SequenceImportedTransforms`는 활성 하위 필드와 일반 믹서 presentation만 관리해요. 원본 모델 전체를 프레임마다 순회하거나 변환 키를 베이크하지 않아요. 하위 필드의 행렬 갱신은 액터 루트별로 모으고, 골격 전용 클립처럼 이 경로의 변환이 없는 경우는 즉시 기존 평가로 넘겨요.

인덱스 단위 변환은 [부분 키 바인딩](SEQUENCE_INDEXED_TRANSFORMS.md)에 연결돼 있어요. 위치·크기와 호환되는 부분 Euler 회전은 작성 성분별로 중재해요([Euler 축 레이어](SEQUENCE_EULER_LAYERS.md)). 경계: 서로 다른 Euler 순서·회전 원점 축 투영, 렌더 속성 별칭, 임의 외부 추가 액션·게임 시뮬레이션·비동기 setter·notify 부수효과 롤백은 남아 있어요. 이 변경만으로 전체 FPS·힙·모바일 실기기 성능을 주장하지 않아요.
