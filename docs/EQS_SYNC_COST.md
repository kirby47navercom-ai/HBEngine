# EQS 액터 동기화의 임시 비용

질의마다 가변 월드를 다시 확인해 직접 이동·부모 이동·풀 반환·태그·순서·교체를 즉시 반영해요. 변경이 없는 액터의 행·위치 사본은 다시 만들지 않고, 부모가 있는 액터를 처음 만날 때만 그 질의의 행렬 색인을 준비해요. 삭제·이동·태그 참조·순서가 바뀐 항목만 준비해 모든 계층 검증이 끝난 뒤 게시해요. 계층 오류가 나면 기존 공간 색인은 유지하고 임시 오브젝트 참조를 비워요.

기존 BP/C++ EQS와 정지 편집기 질의가 같은 색인을 사용해요. 진단의 `actorSync`는 `scanned`·`parented`·`staged`·`removed`·`matrixPass`를 보여줘요. 기존 `actorSearch` 후보 수와 구분해요. 이 수치는 구조적 작업량이고 FPS·OS RAM 측정이 아니에요. 가변 월드의 전체 O(N) 확인은 남아 있어요. 안전한 변경 추적 없이 프레임 번호만으로 결과를 재사용하지 않아요.
