# 실행 중 고정점 자동 연결

Cloth·Rope2D의 **자동 고정점 연결**을 켜면 현재 완전 고정 입자와 실제 강체 연결에서 자유 입자까지 규칙 격자·로프의 최단 경로로 최대 거리 연결을 만들어요. **자동 연결 길이 여유**는 원래 물리 형상의 경로 길이에 곱하며 기본값은 1.1이에요. 기본 설정은 꺼짐이고 기존 프로젝트의 동작을 바꾸지 않아요.

실행 중 고정·해제·강체 연결·연결 대상 삭제는 다음 고정 물리 단계에 모아 반영해요. 고정점이 모두 사라지면 자동 연결만 비우고 직접 작성한 거리 제한과 부분 고정은 유지해요. 자동 연결과 수동 연결이 같은 입자 쌍이면 더 짧은 제한을 사용해요. 켜기·끄기·여유 변경은 몸체 세대나 기존 부분 고정의 이동 이력을 초기화하지 않아요. 생성된 행은 실행 몸체가 소유하고 장면/BP 문서에 저장하지 않아요.

고정점 버전·강체 연결 수·여유가 같으면 고정점 순회나 최단 경로 계산을 다시 하지 않아요. 고정점 번호가 같고 연결 강체만 바뀌면 경로도 재사용해요. 몸체를 제거하면 생성 행과 참조를 함께 해제해요. 임의 메시·절단·소성에 따라 변하는 연결 경로를 계산하는 기능은 포함하지 않아요.

사람은 기존 상세 창의 자동 거리 상태에서 갱신 대기·고정점 없음·연결 수·잔여 오차를 확인해요. 기존 상태 갱신을 공유하고 별도 타이머나 연속 화면 읽기 알림을 만들지 않아요. AI는 `runtime.cloth`·`runtime.rope`의 `view:'tethers'`로 실제 적용 행을 페이지 단위로 읽어요. `particle`·`anchor`·`distance`·현재 `length`·`error`·`source`·`generatedPair`와 `constraintVersion`·`autoTethers.pending`을 반환해요. 한 페이지는 최대 256행이고 각 행의 두 입자만 조회해요. 대기 중에는 직전 적용 행과 대기 상태를 함께 반환해요.

BP·C++는 기존 `componentSetBool`/`componentSetFloat`, `hb::Components::SetBool`/`SetFloat`로 `autoTethers`·`tetherStretch`를 바꿔요. 스키마·검증·핫 편집 경로를 공유해요. 물리 처리는 기존 Rapier 계산 뒤의 거리 투영이며, 접촉·강체 반력을 동시에 푸는 솔버나 성능 보장을 뜻하지 않아요.
