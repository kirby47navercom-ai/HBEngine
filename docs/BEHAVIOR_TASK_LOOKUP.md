# 태스크 핸들 조회 비용

태스크 메모리·완료·실행/중단 상태·중단 완료는 핸들의 실행 소유자와 현재 활성화를 바로 찾아요. 예전처럼 노드 메모리 전체나 모든 하위 트리를 순회하지 않아요. 루트 트리별 소유자 표와 활성화별 항목을 쓰고, 현재 노드 메모리의 정체성과 호출한 트리의 하위 범위를 확인해요. 자식 트리는 형제·상위 트리에 접근할 수 없고 서로 다른 오브젝트는 표를 공유하지 않아요.

시작 콜백 전에 등록하고 완료 콜백 뒤에 해제해요. 지연 중단은 정리 기간 동안 유지하며 중단이 끝나면 해당 노드의 티켓을 바로 찾아 제거해요. 자식 태스크를 완료하면 소유 트리와 조상들을 깨워 다음 평가가 진행되도록 해요. 오류·리셋·강제 종료·자식 트리 종료에서도 항목과 메모리를 정리해요. 매 프레임 표를 다시 만들지는 않아요.

기존 BP·C++ 함수와 저장 형식은 같아요. AI 스키마의 `behaviorTaskIndex`가 소유 범위와 비용을 설명해요. 이것은 핸들 기반 요청의 조회 비용 개선이에요. 노드 이름·경로로 핸들을 찾는 작업, 일반 행동트리 스케줄링·관찰자·서비스·진단 상태 구성 비용까지 제거한 것으로 표시하지 않아요.
