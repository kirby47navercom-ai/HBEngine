# 125 — 곡면 이차 필터

PostProcessVolume의 `pathTracingCurvedFilter`는 기본 꺼짐이다. 사람용 속성·C++ `Components::SetBool`·블루프린트 공용 속성·AI schema가 같은 이름/타입을 사용한다. AI는 기존 문서 ID와 revision을 확인한 `document.patch/files.apply`로 변경한다. 긴 설명은 이 도움말에 두며 편집기에는 이름과 체크박스만 추가한다.

렌즈/시간 필터에서 켜면 주변 광선을 실제 기하와 교차시켜 곡면 발자국을 구한다. 렌즈는4개, 렌즈가 없는 시간 필터는2개 주변 광선을 사용한다. 같은 표면 소유자·앞뒷면·유전체/거울 분류·IOR·전반사 분기가 맞는지 검사하고 실패한 발자국은 원본을 유지한다. 다른 오브젝트·재질 경계·실루엣을 접평면처럼 외삽하지 않는다. 주변 픽셀의 유효하지 않은 가이드도 공간 필터에 섞지 않는다. 기존32픽셀 반경 제한을 유지한다.

이차 반사 가이드의 현재/이전 법선을 곡면의 표면 법선으로 사용한다. 이전 삼각형의 접선 쌍으로 법선을 되돌리는 fallback은 강체 회전과 접선 방향 변환에서 독립 대조했다. GPU 가이드의 교차 결과·위치·앞뒷면·물리 속성은 진행 방향을 갱신하기 전에 고정한다. 표시 필터의 결과는 Monte Carlo 원본 누적에 넣지 않으며 필터 변경은 원본 샘플을 유지한다.

기본 꺼짐에서 추가 교차나 행렬 이력을 만들지 않는다. 켠 품질 모드는 추가 광선 교차 비용이 있으므로 전체 게임 FPS 개선 기능으로 설명하지 않는다. 거친 표면의 단일 대표 경로·전역 곡면 재투영·이상적인 전 경로 역해를 구현했다고 주장하지 않는다. 실패/경계 거부와 실제 지원 범위의 검증을 사용한다.

대조 범위는 [PBRT4 Texture Sampling and Antialiasing](https://www.pbr-book.org/4ed/Textures_and_Materials/Texture_Sampling_and_Antialiasing)의 미분 광선·표면 미분 구역이다. 추가 주변 기하 교차는 HB의 구현 결정이며 전체 원서나 연결 API 완료로 승격하지 않는다.
