# 182 — 열린/불균등 경계 연결·영역 인셋/재삼각화

경계 연결은 정점 수가 다른 폐곡선과 두 열린 경로도 받는다. 정규화한 경계 길이를 따라 선형 삼각 스트립을 만들고 폐곡선의 시작 오프셋을 바꾼다. 기존 정점/UV·방향을 보존하고 분기·잘못된 선택·퇴화를 검사한다.

영역 인셋은 선택한 삼각형의 평면 영역을 처리한다. 오목한 외곽·구멍을 유지하고 원본 삼각형에서 UV/정점 색을 보간한다. 영역 재삼각화도 제공한다. 교차·소실·비평면·비다양체와 결과의 새 열린 간선/방향 오류를 거부한다. 실패해도 사람의 선택을 보존한다.

기존 메시 창과 world.mesh.edit의 revision/dryRun/Undo/저장에 연결했다. 실제 DirectX/WebGPU 게임에 배치하고 C++ RaycastAll로 인셋 면z=0/연결 메시z=2를 확인했다. 7500간선/15000삼각형 CPU 편집 표본은 약26ms다.

[검증 근거](research/ENGINE_WORK_182.json).

평면 영역만 지원하며 곡면 재투영/softness·진짜 edge bevel/edge loop는 별도다. 3D 스트립의 모든 꼬임/교차 자동 복구를 보장하지 않는다.

교차/속성 보간의 편집 비교 예산은200만/1000만이다. 초과하면 영역을 나누도록 거부하며 씬 객체 수 제한이 아니다.

인덱스 경계이므로 동일 위치 UV seam을 자동 용접하지 않는다. 사용하지 않는 원본 정점은 안정 ID를 위해 유지한다.

CPU 편집 표본은 게임 FPS나 모든 DCC 파일 품질 보장이 아니다.
