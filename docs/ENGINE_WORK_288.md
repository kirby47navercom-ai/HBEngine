# 288 · 텍스처 샘플러 인수분해 실험과 회귀 기준

- 샘플러 주소 계산 공유 실험을 GL48변형×6좌표의 실제 부동 RGBA288개로 대조해 최대오차0을 확인했어요. 네이티브 생성자 문제를 고친 실험도 HLSL/CubeLOD 기준을 통과했어요.
- 모든 변형의 생성 소스가76476→88311바이트로 늘고 Complex141 준비 시간 개선이 입증되지 않아 제품 변경을 전부 되돌렸어요. 실제 픽셀 대조 도구만 보존해요.

범위와 한계:

- 완료 기능/최적화 성과로 세지 않아요. 실행 기록은 당시 실험 소스에 대한 근거이며 최종 설치 소스가 그 실험을 포함한다는 뜻이 아니에요.
