# EQS 검사 단계 보기

환경 질의 편집기의 **표시 단계**에서 최종 결과, 투영 후, 실행된 각 검사를 선택해요. 검사 요약 버튼으로도 해당 단계로 이동해요. 질의 대상·점수·실패 후보 선택은 문서의 보기 상태이며 에셋 값·Undo·저장 revision을 바꾸지 않아요.

단계 전환은 이미 만들어진 진단 표본을 읽어요. 투영·트레이스·질의를 다시 실행하거나 게임이 사용하는 최종 EQS 결과를 바꾸지 않아요. 선택한 단계까지의 실패·누적 점수만 보여주며 이후 검사에서 탈락한 후보도 그 단계에서 통과했다면 통과로 표시해요. 표시된 시간은 질의 전체 실행 시간이에요.

`runtime.eqs.read`와 `runtime.eqs.view`의 `stage`는 `final`(기본), `projection`, 실행된 검사 번호(0부터)예요. 없거나 실행되지 않은 검사·잘못된 형식은 거절해요. 조회는 기존 offset/limit·실패 후보 필터·독립 복사 반환을 유지해요. `runtime.eqs.run`은 최종 결과부터 반환하며 `visualize:false`는 새 시각화를 열지 않고 진단을 만들어요.

`generated/matched/failed`는 전체 후보의 선택 단계 집계예요. `finalCounts`는 최종 질의 집계와 구분해요. 진단 예산 때문에 표본 일부만 보관한 경우 중간 단계의 `rankBasis`는 `retained`이며 순위는 보관된 후보 사이의 순위예요. 원래 최종 순위는 전체 결과 기준 `all`을 유지해요. 표본 제한을 질의 결과 제한으로 바꾸지 않아요.

기존 BP/C++ EQS 실행이 만든 같은 진단을 사용해요. 새 노드·C++ ABI·에셋 형식·타이머는 추가하지 않아요. 대상 변경이나 패널 닫기 뒤 늦게 끝난 UI 요청은 해당 패널에 결과를 표시하지 않아요. 새 질의의 검사 수가 줄어 이전 표시 단계가 사라지면 시각화는 최종 결과로 돌아가요.
