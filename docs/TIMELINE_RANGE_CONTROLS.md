# 시퀀스·몽타주 탐색과 표시 비용

타임라인 아래 표시 범위 막대의 가운데는 좌우 이동, 양 끝은 확대 범위를 조절해요. 빈 곳을 누르면 그 위치로 이동하고 두 번 누르면 전체 길이를 보여요. 끝 손잡이는 방향키로 한 프레임, Shift와 함께 열 프레임씩 조절해요. 가운데는 방향키로 현재 폭의10%씩 이동하며 Home/End는 처음/끝으로 옮겨요. 표시 범위는 최소 한 프레임이고 원본 키·구간·재생 길이는 바꾸지 않아요.

시간 눈금에서 Ctrl 또는 Command와 함께 오른쪽으로 드래그하면 그 영역을 확대하고 왼쪽으로 드래그하면 전체 표시로 돌아가요. Esc·포인터 취소·창 포커스 상실은 진행 중인 범위 조작을 취소해요. 기존 Ctrl 휠, Shift 휠, 우클릭/중간 버튼 이동과 Alt+Shift+우클릭 확대를 함께 사용해요. 확대 상태의 일반 클릭·드래그 스크럽은 표시된 시간 범위를 기준으로 계산해요.

터치로 빈 트랙이나 시간 눈금을 끌면 가로 시간·세로 행을 이동해요. 두 손가락은 중간점을 기준으로 확대하면서 좌우로 이동해요. 포인터 취소는 원래 표시 범위와 스크롤로 복원해요. 키·클립에서 시작하는 한 손가락 드래그는 기존 편집 동작에 맡기고, 이미 진행 중인 키 편집을 두 손가락 탐색으로 덮어쓰지 않아요. 실제 휴대폰 검증과 PC의 CDP 터치 검사는 구분해요.

`timeline.view.read/set`와 UI는 같은 문서별 표시 상태를 사용해요. 탐색은 에셋 revision·dirty·Undo를 만들지 않고, 기존 행 탐색·키 번호 이동·가시 범위·실행 커서·키와 구간 편집도 같은 시간 좌표를 써요. 막대의 보조 정보는 접근성 이름·숫자와 툴팁에 두고 작업 영역에 긴 안내를 표시하지 않아요.

## 구간 조회

보이는 행에64개 이상 구간이 있고 일부 시간만 표시할 때, 그 행의 원본 구간으로 interval 색인을 한 번 준비해요. 준비한 뒤의 확대·이동은 전체 배열을 필터링하는 대신 겹치는 구간만 찾고 원래 순서로 제시해요. 이름·표시용 복사는 실제 결과에만 만들어요. 전체 시간 표시와 작은 행은 단순 경로를 유지해요. 문서 편집·Undo·새 render는 색인 소유자를 교체하므로 이전 위치를 재사용하지 않아요. 다른 선택을 하지 않은 동안의 행 포함 검사도 반복하지 않아요.

색인은 해당 화면의 행에만 속하고 전역 캐시·배경 타이머·worker·GPU 자원을 만들지 않아요. 모든 구간이 겹치면 결과도 모두 내보내며 원본 데이터 개수를 잘라내지 않아요. 이 경우 표시 밀도 처리와 런타임 시퀀스 평가의 별도 색인은 다음 비용이에요. 원본 에셋의 기존 예산과 순수 색인 모듈의 대규모 검사는 구분해요.
