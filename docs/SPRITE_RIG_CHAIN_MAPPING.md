# 2D 리그 자동 체인 대응

기존 정확한 이름/계층 대응에 chains 모드를 추가했어요. 먼저 기존 이름·역할 대응으로 기준 뼈를 잡고, 대응된 조상과 끝 뼈 사이의 분기 없는 구간에 중간 뼈를 추가 대응해요. 바인드 월드 행렬의 누적 경로 길이를 정규화하고, 순서를 교차하지 않는 최대 개수의 1:1 대응 중 길이 오차 제곱합이 가장 작은 조합을 선택해요. 뼈 수가 다르면 남는 뼈를 제외해요. 같은 위치의 피벗은 부모 뼈의 바인드 길이를 사용해요.

이미 사용된 대상, 중간 분기, 서로 조상/자손이 아닌 기준 뼈 사이에는 임의 대응을 만들지 않아요. 정확한 기준 뼈를 자동으로 찾지 못한 곳은 사람이 대응표에서 지정해요. Unicode 이름을 빈 역할 이름으로 축약하지 않아요. 원본/대상 데이터·안정 뼈 ID는 그대로예요. 전체 인체/체형 이해나 임의 제약의 정지 발 보정까지 추론하는 기능은 아니에요.

사람용 리타게팅 창의 체인으로 자동 대응 버튼은 대응표를 채우고 포즈 베이크를 선택해요. 가져오기 전 직접 수정할 수 있어요. AI는 rig.clip.retarget에 mapMode:chains, positionMode:pose를 전달해요. mapping을 명시하면 원래 수동 대응을 사용해요. 서로 다른 계층을 로컬 트랙에 그대로 복사하지 않도록 자동 chains의 로컬 모드는 오류로 안내해요. 기존 exact/hierarchy 및 기본 boneLength 동작은 유지해요.

실제 포즈 베이크·동일 클립 저장·재생·Three 스키닝으로 이어져요. 원본/대상 revision, dryRun, 데이터 검증·한 번의 Undo 경계는 기존 공용 제작 명령을 사용해요. 키/뼈/메모리 예산을 넘으면 명시적으로 거절하며 잘라내지 않아요. 새 SDK/별도 렌더러·타이머·캐시를 만들지 않아요.

신규13개 검사에는 작은 체인60조합의 독립 전수 최적값 대조, 뼈 순서·분기·여러 뿌리·스케일·동일 피벗·Unicode·원문 보존, 실제 베이크/메시 재생, 사람 모달 이벤트(격리 DOM), 실제 AI/공용 편집 함수의 CAS/dryRun/Undo hook을 포함해요. 기존 2D 리타게팅·3D/IK 공용 source gate도 통과했어요. 실제 GUI/기기/C++ 바이너리 검사를 새로 수행한 것은 아니에요. 임의 발 접촉·전체 체형/제약 리타게팅 품질은 별도예요.
