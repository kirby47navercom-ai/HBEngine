# 138–140 — 이전 접선 프레임·구름 갱신·하늘 필터 분산

## 이전 노멀맵과 접선

기존 곡면 시간 필터에서 현재의 전체 셰이딩 법선을 현재 UV 접선 기저로 분해하고, 확정된 이전 삼각형의 접선 기저로 재구성한다. 뼈대·위치/법선 모프는 이전 정점 법선을 사용하며 강체는 기존 행렬 이력을 사용한다. 삼각형 접선은 현재/이전 변과 UV로 계산한다. 기본 법선이 그대로인 접선 비틀림, UV 반전, 비균일 강체 변환을 처리한다. 양쪽 기저의 handedness와 기하 법선 방향을 적용하고 퇴화한 표면의 이력을 거부한다.

이전 정점/법선 자료를 재사용하므로 추가 GPU 이미지·읽기·접선 저장은 없다. 변형 삼각형의 선택적 법선 이력48B, 강체 인스턴스의 행렬96B 계약을 유지한다. 옵션 해제와 실패·장면 해제의 수명 규칙도 유지한다.

정적 UV 기반 노멀맵과 상수/파라미터 교란을 복원한다. UV 버퍼의 교체·변경 번호는 시간 이력을 무효화한다. 시간·월드 위치·월드 법선·시점에 의존하는 노멀 그래프는 이전 표본이 현재와 같다고 가정하지 않고 이력을 거부한다. 재질/텍스처·기존 애니메이션 시간 변경은 기존 무효화 경로를 사용한다. 이전 텍스처 전체를 복사해 애니메이션 표본이나 이전 mip footprint까지 보존하는 기능으로 표현하지 않는다.

## 노멀 강도와 셰이더 작업량

직접 노멀 텍스처의 normalScale 변경을 기하 수집·시간 이력 서명에 포함한다. 재질 캐시만 갱신되고 광선 데이터가 그대로 남는 경로를 고친다. WebGL 가이드는 불투명 재질 집합일 때 굴절 분기를 제거하고, 투과율이나 동적 투과 연결이 생기면 다른 변형을 생성한다. WebGPU 렌즈가 꺼진 가이드의 차분 개수는 상수2로 생성한다. 이전 접선 복원 함수는 보간된 현재 법선을 재사용하고 WebGPU의 복원 호출은 한 곳으로 모은다.

초기 컴파일 계측이 필요하면 격리 실행 환경에서 HB_SHADER_TRACE_COLD=1을 사용한다. 기본 실행에서 로그를 만들지 않으며, 지정했을 때만 단계별 소스 길이와 컴파일 시간을 stderr로 기록한다. 복잡한 텍스처 그래프를 한꺼번에 초기 컴파일하는 지연은 별도 남은 목표다. 이번 증거는 Native의 텍스처 노멀맵 장면, WebGL·WebGPU의 균일 접선 교란 장면과 WebGL의 독립90도/반전/퇴화 벡터 검사로 구분한다.

## 실시간 구름 갱신

SkyLight의 기존 `realTimeCapture`가 켜져 있고 실제 구름 바람 위상이 바뀌면 하늘 캡처 요청에 반영한다. 정적 하늘을 불필요하게 다시 계산하지 않으며 최소250ms 간격을 유지한다. 수동 모드는 기존 완성 결과를 유지하고 `captureVersion`이나 편집기의 재캡처 명령으로 갱신한다. Native·WebGL·WebGPU의 공용 환경 상태를 사용한다.

Native 캡처는 시작 시 하늘/구름의 드로 값과 포즈를 보관한다. 한 큐브맵 안에서 각 면의 바람 포즈가 달라지는 것을 막는다. 대기 중에는 현재 준비 중인 큐브 하나와 기존 완성 큐브만 유지하며, 새 요청 때문에 진행 중인 캡처를 매번 버리지 않는다.

## 필터 단계 분산

DirectX 하늘 캡처는 여섯 제출 프레임에 한 면씩 그린 뒤, 별도 프레임에서 원본 mip 복사, 거칠기 mip별 GGX, 마지막 SH9 확산광을 진행한다. 컴퓨트 단계는 프레임당 최대 하나이며 완성 후에만 화면에 공개한다. 64px 캡처는6면과8필터 단계다. 기존 지역 ReflectionProbe/HDRI의 일괄 필터 API는 같은 단계 함수를 재사용해 결과를 유지한다.

`skyFilterSteps`, `skyCaptureFace`, `skyCaptureFilterStage`를 기존 진단에 추가했다. 별도 UI 문구·설정·AI 저장소는 없다. `tools/editor-automation.mjs`의 공용 스키마에 비용·제약·진단 이름을 노출한다. C++/블루프린트의 기존 Components 속성과 AI의 revision 검사 경로로 동일한 SkyLight를 편집한다.

## 지정 자료와 증거

[Epic Sky Lights](https://dev.epicgames.com/documentation/en-us/unreal-engine/sky-lights-in-unreal-engine)의 Real Time Capture·Time Slicing Optimization 구역과 [glTF 노멀 텍스처 규격](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#materials-normaltextureinfo)을 기존 엔진의 좌표·시간 이력 계약과 대조했다. 전체 문서·연결 API를 모두 분석했다는 의미가 아니며 지정 출처와 미독 범위를 corpus 원장에 등록했다.

검사·설치는 `docs/research/RENDERING_138.json`, `USER_INSTALL_138.json`에 기록한다. 실제 실행의 픽셀/자원 증거와 전체 게임 FPS·휴대폰 성능은 구분한다. 전역 곡면 역해·거친 다중 로브·DFAO/Lightmass/HWRT와 기존 비렌더링 목표는 누적 원장에서 계속 관리한다.
