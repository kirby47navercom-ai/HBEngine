# 골격 클립 길이 재조정

골격 클립의 **길이 재조정 → 새 길이(초) → 길이 적용**은 모든 키와 메타데이터의 시간을 같은 양수 비율로 옮겨요. 기존 클립 끝 범위만 바꾸는 길이 필드와 다른 동작이에요. 기존 v1 포맷을 유지하며 모델 안의 클립은 먼저 독립 클립으로 추출해요.

TRS·인덱스 채널·모프 키의 값/보간을 바꾸거나 다시 표본화하지 않아요. 곡선의 수평 가중치는 이웃 시간 간격의 비율, 명시적 control은 Y 오프셋이어서 유지해요. 초당 값인 명시 접선만 시간 배율로 나눠요. 반복/선형 외삽과 infinityDomain의 기준·유한 베이크 구간도 함께 옮겨요. 점/구간 알림·선택적 sync 마커의 시간, 구간 길이, ID/페이로드/확장 속성을 보존해요.

새 길이는 0.000001~86400초예요. 원래/결과 키가 실행기 Float32 시간에서 겹치거나, 미지원 보간·접선/알림 범위 초과가 생기면 전체 변경 전에 거절해요. 같은 길이는 값·배열·Undo를 그대로 두는 no-op이에요. 큰 준비는 4096키마다 양보하고 문서 교체/이름 변경/실행 시작이면 취소해요. 성공한 결과만 한 Undo로 게시하고 이전 미리보기는 정리해요. 새 길이의 같은 정규화 위치로 미리보기 시간을 맞춰요.

AI는 `skeletal.retime`의 `path`, `expectedRevision`, `duration`을 사용해요. `dryRun` 기본 응답은 요약이고 `includeData:true`는 원본에 별칭을 남기지 않는 초안을 반환해요. 최종 일반 문서 CAS/검증/Undo/저장은 기존 경로예요. schema의 `skeletalRetime`에 동일 계약이 있어요.

순수 준비는 바뀐 시간 배열과 곡선 키만 만들고 변하지 않는 값 배열을 내부에서 공유해요. 최종 AI 초안·Undo·전체 자산 검증은 기존 전체 문서 비용이 남아요. 역재생/비균일 시간 워프/모든 DCC 애니메이션 도구를 포함한 완료 주장은 아니에요.

검사: `node tools/check-skeletal-retime-2598.mjs`. 소유 데이터의 실제 Three 보간/곡선·사람/AI 트랜잭션·저장 후 AnimationGraphPlayer를 확인해요. GUI·새 네이티브 바이너리/GPU·실기기·설치 검증과는 구분해요.
