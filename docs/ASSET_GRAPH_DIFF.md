# 노드·연결 시각 비교

기존 에셋 병합 창에 기준/현재/다른 버전을 같은 노드 ID 행으로 나란히 표시해요. 블루프린트의 `nodes[]`, 머테리얼의 `graph.nodes[]`를 지원하고, 머테리얼의 구형 연결 튜플은 기존 `normalizedMaterialEdges`로 해석해요. 노드 위치는 메타데이터로 반환하며 비교 화면에서는 행을 정렬해요. 작성 캔버스의 배치를 바꾸지 않아요.

초록은 추가, 노랑은 변경, `없음`은 해당 버전에서 삭제된 노드예요. 충돌 노드를 클릭하거나 Enter/Space로 버전을 선택해요. 선택은 그 노드 아래의 충돌 필드만 바꾸므로 다른 버전의 독립 변경은 보존해요. 이미 선택한 노드도 다시 선택할 수 있어요. 순서·연결·문서 속성 충돌은 기존 속성 카드에서 해결해요. 모두 해결되고 기존 에셋 검증을 통과해야 문서에 적용할 수 있어요. 실제 쓰기는 기존 document.patch/revision/Undo 경로를 유지해요.

`document.graph.diff`는 열린 문서의 현재 버전을 `ours`로 사용해요. 선택적인 `base`/`theirs`가 없으면 현재 버전과 비교해요. `expectedRevision`을 보내면 불일치를 거절해요. 반환값에는 path/revision, 노드 ID·라벨·종류·위치·변경 키와 연결 끝점만 있고 핀 값/원문 본문은 없어요.

- 노드: offset, limit 1..128(기본24); 사람 화면은12개씩.
- 연결: edgeOffset, edgeLimit 1..512(기본128). 현재 노드 페이지 양 끝이 표시되는 연결만 비교해요. 동일 ID 연결의 다른 버전 끝점이 페이지 밖이면 `outsidePage`로 구분해요.
- 연결 ID가 있으면 그 ID, 없으면 방향/노드/핀과 같은 연결의 발생 순서로 식별해요.

그래프 선택에서 이벤트/포즈, 머테리얼, 함수·매크로를 고를 수 있어요. 함수·매크로는 세 버전에 공통으로 사용할 수 있는 고유 ID 또는 이름으로 대응해요. 순서가 달라도 같은 그래프를 비교하고, 한 버전에 없는 그래프는 존재 상태를 따로 표시해요. 애니메이션 `nodes[].inputs` 포즈 입력도 연결로 표시해요.

AI는 읽기 전용 `document.graph.list`의 offset/limit(기본24, 최대128)으로 그래프 key·안정 경로·버전별 존재/노드 수만 조회해요. `document.graph.diff`의 `graph`에 이 key를 보내면 해당 그래프를 비교해요. `graphOffset/graphLimit`는 선택 목록 페이지예요. 두 명령 모두 선택적 expectedRevision을 검사하고 원문/핀 값 전체를 복사하지 않아요.

같은 노드 ID가 다른 함수에도 있어도 선택한 그래프 아래의 충돌만 고쳐요. 함수 전체 삭제/수정 충돌은 하위 노드 선택으로 자동 해결하지 않아요. 지원 밖의 연결 형식은 시각 비교 오류만 표시하고 기존 속성 병합은 계속 사용할 수 있어요. 상태 머신/BT의 암시적 연결, 임의 깊이의 서브그래프, 3D 장면/메시 시각 비교, Git 충돌 마커 파싱·디스크 저장/스테이징은 별도예요.

검사: `node tools/check-asset-graph-diff-2770.mjs` 15개와 `node tools/check-graph-contexts-2801.mjs` 9개. 실제 병합 패널 SVG·키보드/클릭·그래프 선택·선택 변경과 app AI 명령을 소유 DOM에서 실행해요. 브라우저 배치/픽셀 검증은 아니에요.
