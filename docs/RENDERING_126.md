# 126 — 이전 포즈의 표면 법선

곡면 시간 필터에서 비균일 배율의 법선은 점/방향과 같은 방식으로 옮길 수 없다. 강체 인스턴스마다 현재 forward 선형 행렬3개 float4와 이전 inverse 선형 행렬3개 float4를 포장한다. 현재 월드 법선을 로컬로 되돌린 뒤 이전 inverse transpose로 옮기고 좌표계 handedness를 보정한다. 기존 UV/법선 레코드의 빈 w 성분에 행렬 참조를 담아 삼각형마다 행렬을 복제하지 않는다.

GPU 저장은 강체 인스턴스당96바이트이며 곡면+시간 필터일 때만 만든다. 현재 성공 프레임에만 이전 변환을 확정하고 실패·재질/기하 무효화·비활성에서 이력을 비운다. 행렬 이력의 생성/해제 때문에 Monte Carlo 원본 샘플을 버리지 않는다. 수정 전 포즈로 새 프레임을 확정하지 않는다.

독립 CPU 비교에서 법선 축 배율까지 바꾸고 이전 법선과 최대 오차2.86×10⁻⁸을 확인했다. 꺼짐/실패 해제와 원본 샘플 유지도 대조했다. 스킨/모프처럼 로컬 표면 자체가 변형되면 삼각형 접선 fallback을 사용하며 이전 모든 정점 법선·노멀맵 애니메이션을 별도로 저장하는 기능은 이 범위에 포함하지 않는다. 기존 이전 정점 위치 대응과 프레임 실패 보존을 유지한다.
