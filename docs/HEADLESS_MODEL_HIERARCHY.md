# 화면 없는 모델의 계층 검증

glTF/GLB 입력의 계층 검증에서 재귀적인 128단계 제한을 제거해요. 부모가 하나인 노드 연결을 한 번 검사한 뒤 루트부터 반복 순회하므로 노드/간선 수에 비례하는 작업과 노드 수에 비례하는 임시 저장을 사용해요. 부모 중복·같은 자식 중복·범위 밖 인덱스·루트와 분리된 순환도 기존처럼 거절해요. 바이트·접근자·파일별 노드/자식 예산은 별도 입력 보호로 유지해요.

실제 600단계의 소유한 glTF를 로드하고 월드 위치, 독립 클립 추출, 같은 깊이의 그래프 재생과 원본 파일 보존을 확인해요. 잘못된 계층과 여러 독립 루트도 검사해요. 이것은 입력 검증의 깊이 제한 제거와 그 실행 표본의 근거예요. Three의 모든 계층 연산·모든 렌더러·복잡한 DCC 파일이 임의 깊이에서 동작한다는 뜻은 아니에요.

별도로 glTF 하위 클립에 명시된 원본 인덱스가 없으면 이름으로 추측해 다른 클립을 선택하지 않고 재가져오기를 요구해요. 예전 이름 기반 연결은 인덱스가 없는 경우에만 고유한 이름으로 해석해요.
