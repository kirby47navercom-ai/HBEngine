# 183 — 위젯·메시 단축키 재지정

위젯 복사/잘라내기/붙여넣기/복제/삭제/맞춤·1px/10px 이동, 메시 프레이밍/전체 선택/브리지/인셋/재삼각화/면 복제·삭제·뒤집기를 기존 단축키 설정에 연결했다. 전용22개를 포함해 전체55명령이다.

해당 작업창 포커스에서만 동작하고 입력·IME·대화상자·실행·카메라 비행을 격리한다. 재지정 후 기존 하드코딩 키로 우회 실행하지 못하게 하고 위젯 우클릭도 현재 키를 표시한다.

과거 사용자 명시 키와 충돌하면 해당 새 암묵 기본 키만 해제한다. 프로필을 통째로 초기화하지 않는다. 실제 창에서 I→O 인셋·이동→G·Ctrl+D→Ctrl+L 복제, 이전 키 차단·입력 격리·Undo·메뉴·검사 전 설정 복원을 확인했다.

[검증 근거](research/ENGINE_WORK_183.json).

다른 전용 편집기와 모든 조작의 명령화는 잔여 원장에 유지한다.

기존 키2개/충돌 검사/프로필 계약을 사용하며 명시한 새 키끼리의 충돌은 거부한다.

격리 PC 실제 키 입력 결과이며 다중 모니터·모바일·모든 보조 기술 검증과 구분한다.
