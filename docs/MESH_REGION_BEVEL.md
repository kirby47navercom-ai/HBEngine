# 평면 영역 베벨과 경계 루프

메시 편집기에서 같은 평면의 면 영역을 선택하고 **토폴로지 → 평면 영역 베벨**을 사용해요. 기존 거리 입력이 인셋 폭이고, 높이·분할 수·직선/둥근 모양을 지정해요. 높이의 부호로 올림/파임을 바꿔요. 분할은 1~64이고 둥근 단면은 폭·높이를 반지름으로 하는 사분 타원이에요.

기존 영역 인셋의 평면·구멍·경계 교차 검사와 캡 삼각화를 한 번 재사용하고, 바깥 경계와 캡 사이를 여러 링으로 연결해요. 바깥 정점 ID와 선택하지 않은 삼각형은 유지해요. 안쪽 캡의 UV0·보조 UV·색상은 기존 원본 삼각형 보간을 사용하고, 링에서는 두 경계의 속성을 선형 보간해요. 노멀은 기존 메시 로더에서 새 형상에 맞게 계산해요.

결과의 경계 연결·퇴화 면·중간 링 교차를 검사해요. 너무 큰 폭, 비평면 영역, 뒤집힌 연결, 사라지는 구멍, 기존 정점/삼각형 예산 초과는 문서를 바꾸기 전에 거부해요. 전체 메시 복사·검증·초기 삼각화 비용은 여전히 있고, 새 정점 수는 경계 정점 수 × 분할 수예요. 게임 FPS 개선 기능으로 설명하지 않아요.

간선 모드에서 열린 면의 경계 간선을 선택한 뒤 **경계 루프 선택**을 누르면 해당 닫힌 경계를 한 번에 선택해요. 구멍·분리된 섬의 여러 seed를 함께 사용할 수 있고, 반대 방향·중복 seed는 중복 선택하지 않아요. 이는 보기 선택만 바꾸며 문서·dirty·revision·Undo는 바꾸지 않아요. 일반 내부 quad loop를 추측하는 기능은 아니에요.

AI 편집은 기존 `world.mesh.edit`에서 다음 설정을 사용해요.

```json
{"operation":"bevelRegion","faces":[0,1],"distance":0.2,"height":0.15,"segments":8,"profile":"round"}
```

기존 expectedRevision·dryRun·한 번의 Undo·검증·저장을 공유해요. 경계 읽기는 `world.mesh.boundary.read`의 `edges:[[a,b],...]`, `offset`, `limit:1..256`으로 정확한 개수와 복사한 간선 페이지만 받아요. `hb schema --local --section meshRegionBevel`과 `meshBoundarySelection`에서 계약을 읽어요.

생성 결과는 기존 월드 메시 형식이므로 동일한 Three 로더·메시 콜라이더 흐름을 사용해요. 임의 곡면/솔리드 간선 전체의 베벨·전역 교차 복구·재료/노멀 seam 정책·일반 내부 edge loop는 별도예요. 소스의 실제 Three/Rapier 확인이 실제 창이나 모든 렌더러의 픽셀 품질 검증을 대신하지는 않아요.
