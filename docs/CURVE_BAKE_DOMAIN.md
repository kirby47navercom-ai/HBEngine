# 키 범위 밖의 부분 베이크

시퀀스 곡선 도구의 **시작·끝·FPS**로 첫 키 이전이나 마지막 키 이후까지 부분 베이크할 수 있어요. 이전/이후 범위가 기본값·유지·선형인 숫자/벡터 곡선을 지원해요. 명시한 구간만 선형 샘플 키로 바꾸고 나머지 키와 보간을 보존해요. 기존 곡선 도구·Undo/Redo·문서 저장 흐름을 그대로 사용해요.

입력한 도구 설정과 설정 패널의 펼침 상태는 현재 문서의 편집 화면 상태에 보존해요. Undo/Redo나 속성 재편집 뒤에도 시작·끝·FPS가 사라지지 않아요. 이 값은 게임 에셋이나 재생 설정으로 저장하지 않아요.

예를 들어 2~4초에만 키가 있는 위치 트랙에서 시작 0.5, 끝 2.5, FPS 8을 적용하면 0.5~2.5초를 베이크해요. 2.5~4초의 원래 곡선과 0.5초 전의 선형 기울기는 유지해요. 3.5~5.5초를 다시 적용하면 그 구간만 추가로 바뀌어요. 시퀀스 전체 길이 밖의 키는 기존 문서 검증에서 거절해요.

기존 끝점의 자동·클램프 탄젠트가 새 이웃에 의해 달라지지 않도록 실제 기울기를 고정해요. 가중치·수직 제어점이 있는 구간도 안쪽 분할 도구를 재사용해 보존해요. 저장 기울기 한도를 넘는 내부 탄젠트는 제어점 값으로 보존하고, 표현할 수 없는 외부 선형 기울기는 변경 전에 거절해요. 샘플 수와 남겨둔 외부 키의 합은 공용 키 예산을 지켜요.

AI는 `sequence.curve.tool`의 `operation:'bake'`, `rangeOnly:true`, `start`, `end`, `fps`를 사용해요. `expectedRevision`·`dryRun`·원자적 문서 검증을 그대로 적용해요. `schema.curveBakeDomain`에 지원 범위가 있어요. 생성 결과는 일반 키이므로 Blueprint Timeline·시퀀스·골격 곡선의 기존 샘플러와 C++의 기존 LevelSequence 제어로 실행해요. 런타임 형식·작업자·타이머·GPU 버퍼를 추가하지 않아요.

제한: 이전/이후 범위 중 하나라도 반복·오프셋 반복·왕복이면, 첫/마지막 키를 늘리는 부분 베이크는 원래 주기를 보존할 수 없어 거절해요. 기존 키 안쪽 부분 베이크와 전체 베이크는 계속 사용할 수 있어요. 반복 곡선의 외부 부분 베이크는 별도 잔여 범위로 유지해요.

구현은 `prototype/curve-bake-domain.js`와 기존 `curve-tools.js`·`curve-subdivision.js`를 사용해요. 독립 수치 검사와 실제 편집기·C++·게임 실행 근거는 WORK1933에 기록해요.
