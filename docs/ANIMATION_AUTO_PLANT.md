# 자동 발 접촉과 고정

Two Bone IK에서 **자동 발 접촉**을 켜면 입력 발이 표면 가까이에 머무르고 표면에 대한 이동 속도가 낮을 때 발을 고정해요. 기존 지면 보정의 광선 하나를 재사용하며 새 광선을 추가하지 않아요. 상세 창에서 켜면 입력 포즈를 기준으로 한 지면 보정도 함께 켜지고, 지면 보정을 끄면 자동 접촉도 꺼져요.

진입 높이·속도와 해제 높이·속도를 따로 설정해 경계에서 고정이 빠르게 켜지고 꺼지는 것을 줄여요. 최소 접촉 시간은 그래프 시계로 누적하고, 같은 시각의 반복 평가는 시간을 더하지 않아요. 발 높이는 표면 여유를 더하기 전 실제 표면에서 재고, 이동 속도는 현재 접촉 오브젝트의 이동·회전을 뺀 월드 미터/초로 계산해요. 보폭 보정이 켜져 있으면 보정된 입력 발을 사용해요.

고정될 때 지면 목표 위치와 정렬한 회전을 잡고, 접촉 오브젝트의 움직임을 따라가요. 명시적인 **접촉 표면**이 있으면 그 오브젝트를 우선해요. 그렇지 않으면 광선에 맞은 오브젝트를 따라가며, 해당 오브젝트가 없으면 고정을 만들지 않아요. 발이 높이·속도 해제 조건을 넘거나 사용 Bool이 꺼지면 기존 **해제 전환** 시간으로 현재 지면 목표에 돌아와요. 기존 위치·회전 가중치와 관절·길이·Alpha 제한도 유지해요.

명시적인 **접촉 Bool 파라미터**가 지정된 노드는 기존 작성 Bool 제어를 우선해요. 자동 제어를 사용하려면 그 항목을 비워요. 자동 접촉의 **사용 Bool 파라미터**는 BP의 기존 `animGraphSetBool`, C++의 `hb::AnimationGraph::SetBool`로 제어해요. 새 SDK 함수나 매 프레임 포즈 전송은 필요 없어요.

지면이 없어지거나 접촉 오브젝트가 교체·삭제되면 예전 고정점을 지워요. 시계 되감기·분기 평가 단절·설정한 연속 평가 간격 초과도 접촉 대기를 처음부터 시작해요. 예산으로 포즈 평가를 건너뛴 프레임에는 광선을 쏘지 않아요. 상태는 평가 분기별로 소유하고 그래프를 해제할 때 함께 버려요. 상세 창에는 접촉 대기·이동·높이 초과·고정 상태를 기존 상태 갱신으로 표시해요.

AI는 `autoPlant` 선택 설정과 기존 문서 패치·검증·Undo를 사용해요. 기본값·허용 범위·우선순위는 엔진 스키마의 `autoPlant`에 있어요. 켜진 자동 접촉에는 켜진 `groundProjection`과 `source:'pose'`가 필요해요. 이것은 광선에 기반한 애니메이션 접촉 추론이며, 물리 접촉 솔버·미래 보행 예측·골반 보정이나 실기기 성능 보장은 아니에요.
