# 레이어 이미지 크기 정규화

배열·큐브·볼륨 텍스처의 가져오기 설정에서 **레이어 원본 크기**를 선택해요. 기본 **같은 크기만**은 기존처럼 다른 크기의 원본을 거부해요. 선택한 경우에만 **채우기**로 전체 크기를 바꾸거나, **비율 유지 · 여백**으로 가운데에 맞추고 투명 여백을 넣거나, **비율 유지 · 자르기**로 가운데를 잘라 채워요.

가로·세로를 모두 0으로 두면 첫 원본의 크기를 사용해요. 직접 지정할 때는 둘 다 지정하고, 큐브맵은 정사각형이어야 해요. **가까운 픽셀**은 도트 이미지용 보간 없는 확대, **부드럽게**는 Canvas의 고품질 보간을 사용해요. PNG·JPEG·WebP 등 기존 이미지 디코더가 지원하는 형식을 같은 RGBA8 레이어로 읽어요. JPEG 손실이나 브라우저별 부드러운 보간 결과까지 동일하게 만드는 기능은 아니에요.

정규화한 픽셀은 기존 비동기 밉 생성과 Three 배열·큐브·볼륨 텍스처, 네이티브 밉 직렬화 경로를 사용해요. 직접 지정한 밉 원본도 각 단계의 목표 크기에 맞추며 기존 볼륨 슬라이스 수는 유지해요. 가져오기 보고서의 `layerNormalization`은 방식·목표 크기·필터와 크기가 바뀐 원본 수를 담아요. 원본 파일을 덮어쓰거나 별도 출력 그림·사이드카·워커를 만들지 않아요.

작성 밉 디스크 스트리밍은 원본 크기를 그대로 읽는 흐름이므로 정규화와 함께 켤 수 없어요. 정규화 설정을 바꾸면 기존 스트리밍과 미리보기 크기 기록을 무효화하고, **원본 처리 사용**으로 가져오기를 끄면 정규화 설정도 기존 Undo 경로로 함께 제거해요. 최종 밉의 실제 크기와 슬라이스 수는 기존 장치 한도를 다시 확인해요.

AI는 기존 텍스처 에셋의 선택 `layerNormalization` 객체와 일반 저장·검증을 사용해요. 모드·대상 크기·필터 계약은 엔진 스키마의 `layerNormalization`에 있어요. GPU 압축 포맷 변환·HDR 정규화·플랫폼별 RDO 쿠킹을 구현한 것으로 표시하지 않아요.
