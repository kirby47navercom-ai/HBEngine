# 블루프린트 함수·변수 접근과 소유 클래스

2026-10-22. 함수의 Public/Protected/Private와 변수의 `private`가 편집 메뉴, 해석 검증, 실행, 참조 전달, 네이티브 묶음 실행에 같은 규칙으로 적용돼요. 기존 에셋에서 접근 설정이 없으면 Public이에요. 명시적으로 노출한 C++의 `cppAccess`와는 별개예요.

| 설정 | 호출하는 그래프 |
|---|---|
| Public | 외부를 포함한 호출 허용 |
| Protected | 선언 클래스와 그 자식 클래스 |
| Private | 선언 클래스의 그래프 |

부모 인스턴스 코드를 자식에 복사해서 실행하는 상속 구조에서도, 실행 중인 오브젝트 클래스만으로 판단하지 않아요. 함수의 선언 소유 경로와 각 노드의 원래 소유 경로를 유지해요. 부모 그래프는 부모의 Private 변수·함수를 계속 사용할 수 있고, 자식 노드가 같은 함수를 호출하면 거부돼요. 부모의 Protected 함수가 자식에서 재정의되어도 부모 선언의 접근 범위를 유지하고 가상 호출은 자식 구현으로 이어져요. Private 함수의 재정의는 거부해요. 화면 이름이 같아도 다른 소스/경로의 블루프린트를 같은 클래스로 취급하지 않아요.

`inheritance.memberOrigins`는 해석된 뷰의 파생 정보예요. 부모 구현을 따로 보존할 때도 선언 소유가 유지돼요. 저장하는 자식에는 이 표나 부모 그래프를 복제하지 않아요. 자식이 상속 노드 ID를 자기 그래프에 재사용해 부모 소유로 위장하는 것도 해석 단계에서 거부해요.

사이드바·우클릭 검색에는 현재 클래스에서 접근할 수 있는 함수·매크로·변수만 나와요. 자기 함수의 기존 접근 선택란을 사용할 수 있고, 재정의 함수의 접근은 읽기 전용이에요. 복사한 노드, JSON Patch, AI 편집으로 숨긴 함수를 넣어도 저장/실행 해석에서 검사해요. 실행기의 직접 호출과 변수 get/set, 변경 가능한 참조, 네이티브 함수 래퍼도 같은 검사기를 사용해요. 매크로에는 HB의 기존 접근 필드에 같은 규칙을 적용해요.

인터페이스 메시지는 공개 계약이므로 구현 함수가 Public이어야 하고, 실행 핀을 제외한 입력·출력의 ID·자료형·배열·enum/record 이름이 일치해야 해요. 수신자 프레임으로 전환할 때도 실제 호출자의 클래스 정보를 버리지 않아요. 이 검사는 수신 구현을 실행하기 전에 적용돼요. 인터페이스/디스패처에는 의미 없는 함수 접근 선택란을 표시하지 않아요.

AI는 `blueprint.members.read`로 열린 문서의 멤버를 읽을 수 있어요. `kind`는 `all/functions/macros/variables`, `query`는 이름 검색, `offset`은 0 이상, `limit`는 기본 32·최대 128이에요. 선언 소유 경로·접근·상속·호출 가능·편집 가능·재정의 가능·핀 자료형을 반환하고 그래프 본문·변수 값·큰 기본값은 복제하지 않아요. 수정은 기존 revision/CAS 문서 명령을 사용해요.

새 전역 강참조 인덱스·워커·타이머·GPU 리소스는 없어요. Public의 판정은 즉시 반환하고, Protected의 조상 탐색은 기존 최대 32단계 상속 경로 안에서만 이뤄져요. 인스턴스 기본값 편집·C++의 일반 반환 참조·전용 enum/struct 에셋 및 전역 타입 레지스트리는 별도 제작 기능과 구분해요.

근거: [Unreal Engine 5.8 Functions](https://dev.epicgames.com/documentation/unreal-engine/functions-in-unreal-engine?lang=en-US)의 본문 0–164 중 접근 범위 8–19, 순수/실행 20–30, 상세 편집 65–98, 외부 호출 133–157을 확인했어요. 함수의 접근·핀·순수 호출 설명을 참고했으며, 이 문서나 연결된 API 전체를 구현했다는 뜻은 아니에요.

검증: `tools/check-blueprint-access-1533.mjs`는 상속 3단계·Private 내부/외부·Protected 가상/부모 호출·변수/참조·위조 노드 출처·인터페이스 계약·네이티브 래퍼·AI 페이지를 검사해요. `tools/check-blueprint-access-1534-window.mjs --package`는 숨긴 소유 창에서 실제 상세 편집·Undo·자식 표시 갱신·원자적 거부·얇은 자식 저장·게임 실행과 같은 저장 프로젝트의 Windows D3D11 `[7,25,9]`/exit0를 검사해요. PC의 소유 테스트 창이며 실제 모바일 기기 검사나 FPS 주장은 아니에요.
