# 모델에서 독립 애니메이션 클립 만들기

모델 가져오기 창의 **애니메이션** 하위 에셋을 선택하고 **독립 클립 생성**을 사용해요. 새 이름으로 기존 `.hbskeletalclip.json` 형식의 에셋을 만들어요. 이후 그래프의 클립, 몽타주·시퀀스 등 기존 골격 클립 실행 경로에서 사용해요. 모델이나 지오메트리를 새 에셋 안에 복사하지 않아요.

기본은 원본 키와 Discrete/Linear/Smooth 보간을 보존해요. 원본 pose·키·메타데이터를 수정하지 않아요. UUID에 연결된 트랙은 실제 대상에서 고유한 이름을 찾아 바꾸므로 모델을 다시 로드해 UUID가 바뀌어도 같은 이름으로 연결해요. 비어 있거나 중복된 대상 이름, 없는 뼈/모프·지원하지 않는 바인딩은 파일 생성 전에 거절해요. 원본 노드에 고유하고 바인딩 가능한 이름을 지정해주세요.

glTF CUBICSPLINE 등 사용자 보간은 기존 클립 형식이 그대로 표현하지 못해 기본으로 거절해요. **곡선·사용자 보간 베이크**를 명시적으로 선택한 경우에만 지정한 1~240 FPS로 해당 트랙을 표본화해요. 다른 표준 트랙은 이때도 원본 키를 유지해요. 베이크는 표본 사이의 원래 곡선을 근사하며, 응답의 `sampledTracks`와 `fps`가 이 범위를 알려줘요. 지원하지 않는 보간을 알림 없이 선형으로 바꾸지 않아요.

AI 명령은 `modelimport.extractClip`이에요. 열린 모델 가져오기 문서의 `path`, `expectedRevision`, 애니메이션 `subasset` ID와 새 `name`을 지정해요. `custom` 기본은 `reject`, 명시적인 베이크는 `bake`예요. `dryRun:true`는 검증·요약·원본 provenance만 반환하며 `includeData:true`일 때만 제안 전체 데이터를 포함해요. `schema.modelClipExtraction`에서 계약을 조회해요.

미리보기가 준비되는 동안 문서·에디터 소유자·미리보기가 바뀌거나 원본 스냅샷 검증에 실패하면 생성하지 않아요. 긴 사용자 보간 베이크는 4096표본마다 편집기로 제어를 돌리고 닫힌/교체된 미리보기를 확인해요. 표준 키의 필수 배열 복사/검증 비용은 남아요. 저장은 검증한 전체 클립을 새 파일로 한 번에 게시하고 기존 이름을 덮어쓰지 않아요. `/api/asset/create`의 선택적 `initialData`는 이름이 일치하는 골격 클립에만 허용해요. 기존 일반 에셋 생성은 유지해요. 서버의 요청 크기·기존 클립의 1024트랙/800만 값 검증 예산도 유지해요.

이 경로는 이미 읽은 모델의 완성된 클립을 독립 파일로 복사해요. 완전한 FBX/DCC 파일군 검증·머테리얼/스킨 추출·출처 파일과 새 파일의 다중 파일 원자 변경은 별도예요. 지원되는 이벤트/상태/커브 메타데이터는 복사하고, 임의 플러그인 메타데이터를 실행하지 않아요. 실제 GUI/렌더링 픽셀·실기기·새 네이티브 C++ 바이너리 검증과 구분해요.

## 구간 추출과 메타데이터

선택적인 `start`·`end`는 원본 초 단위이고 기본값은 전체 클립이에요. 사람용 시작·끝 입력칸과 AI 명령이 같은 함수를 사용해요. `end`를 비우면 원본 끝이에요. 결과 길이는 `end-start`, 키 시간은 0부터예요. 선형·스텝·쿼터니언은 내부 원본 키와 정확한 경계 값을 유지해요. Three Smooth의 이웃 키 의존성 때문에 구간 추출에서는 명시적 베이크가 필요하고 `sampledTracks`에 표시해요. 전체 Smooth 추출은 기존 키와 보간을 유지해요. 응답 `sourceRange`가 원본 구간을 알려줘요.

점 알림은 `[start,end)`만 옮기고, 겹치는 구간 알림은 경계에서 자르며 ID와 페이로드를 보존해요. 메타데이터 곡선은 auto 접선을 먼저 고정하고 가중·수직 핸들을 de Casteljau로 분할해요. 기본/선형 외삽도 같은 경계 값을 유지해요. 반복 범위 밖이나 기존 infinityDomain이 포함된 곡선은 명시적 베이크를 요구하고 `sampledCurves`와 FPS로 근사를 알려줘요. 결과 밖의 infinity는 constant로 정리해요. 리타게팅의 구간 베이크도 이 함수를 사용해 경계에서 원래 곡선을 단순 선형으로 계산하지 않아요. 표본 사이 근사를 정확한 원곡선 보존으로 표현하지 않아요.

구간 경계나 베이크의 마지막 표본이 실제 플레이어의 Float32 시간에서 이웃 키와 겹치면 게시 전에 거절해요. 키를 몰래 옮기거나 제거하지 않으며 시작·끝 또는 FPS를 조정해야 해요.
