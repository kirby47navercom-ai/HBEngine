# 203 — 잠금 장면 문맥·환경 프리팹 제작

장면 인스턴스에서 열면 잠금 문맥, Alt로 열면 격리 모드를 사용한다. 로컬 프리팹 데이터는 유지하고 미리보기 래퍼가 부모 회전·비균일 크기를 포함한 인스턴스 월드 위치에 맞춘다. 배경에서 원래 인스턴스/멤버/붙인 자식을 제외하고 계층/선택 대상에도 넣지 않는다. 문맥의 루트 Transform은 잠그고 자식은 편집한다.

격리 모드에서 장면 편집 환경을 선택하고 배경 표시/숨김으로 자원을 배치·해제한다. 배경은 명시 새로고침하는 스냅샷이며 미리보기 조명을 쓴다. prefab.stage.view/get은 같은 보기 함수를 호출하고 보기 자체는 에셋 revision을 바꾸지 않는다.

실제 편집창에서 인스턴스 열기, 잠금, 자식 편집·Undo·저장, 원본 장면 보존, 명시 동기화 후 실제 게임 재생을 확인했다. 최초 보기 복원과 인스턴스 열기가 겹치던 순서 문제도 고쳤다. [Unity 프리팹 편집](https://docs.unity3d.com/6000.0/Documentation/Manual/EditingInPrefabMode.html)125–224와 대조했다. 회색/오버라이드 표시·스냅/조명 일치·중첩 Apply 목적지는 잔여로 유지한다.
