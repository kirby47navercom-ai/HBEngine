# 쿼터니언 범위 밖 회전

Sequence의 회전 트랙에서 쿼터니언 보간을 켜면 이전·이후 범위에 유지, 각속도 유지, 반복, 회전 누적, 왕복을 선택할 수 있어요. `preInfinity`/`postInfinity`의 저장 값은 기존 공통 값 `constant`/`linear`/`cycle`/`cycleOffset`/`oscillate`예요. 이산 변수·표시 값은 종전처럼 유지·반복·왕복만 허용해요.

`linear`는 처음/마지막 구간의 두 자세 사이 최단 회전축과 각속도를 구해, 경계 자세부터 같은 속도로 계속 회전해요. Euler XYZ의 각 성분을 더하거나 직선 보간하지 않아요. 경계 구간이 step/constant이거나 길이가 0이면 그 경계 값을 유지해요. 마지막 키가 step/constant일 때도 이후 각속도는 0이에요. 한 키·빈 트랙과 내부 키/정확한 끝점·기존 반복/왕복은 기존 의미를 유지해요.

`cycleOffset`는 내부 시간만 반복시킨 뒤 `D = Q끝 × inverse(Q시작)`의 누적 회전을 왼쪽에 적용해요. 즉 `Q결과 = D^반복횟수 × Q내부시간`이에요. 곱셈 순서는 중간 자세의 회전축이 달라도 반복 경계에서 연속하도록 정해요. 이전 구간은 음수 횟수를 사용해 역방향으로 누적해요. 끝점 델타는 최단 회전을 쓰며 0→360도처럼 키 자세에 담기지 않은 회전 횟수를 복구하는 기능은 아니에요.

계산은 준비된 쿼터니언 배열과 샘플러당 지연 생성한 스크래치 객체 한 개를 사용해요. 반복 횟수만큼 루프를 돌거나 키·배열·캐시를 늘리지 않아요. 출력은 기존처럼 XYZ Euler 각도 사본이므로 값이 ±180도 부근에서 바뀔 수 있어도 실제 자세는 연속이에요. 이벤트·클립·부모/생성 참조의 시계와 수명은 다시 매핑하지 않아요.

사람은 트랙 속성에서 설정하고 AI는 `sequence.curve.edit`에 `expectedRevision`, `preInfinity`/`postInfinity`, `dryRun`을 사용해요. 기존 Undo/Redo/저장과 같은 JSON을 사용하며 C++ `hb::LevelSequence::Play/Pause/Seek`와 BP가 동일 샘플러를 실행해요. 새 ABI나 별도 회전 포맷은 없어요.

[Three.js Quaternion 문서](https://threejs.org/docs/pages/Quaternion.html)의 정규화, 역회전과 곱셈/앞곱 계약을 대조했어요. 누적 회전의 곱셈 순서·경계 정책·지수 계산은 HB의 명시적 계약이며 Unreal 또는 Unity 내부 구현과 동일하다고 주장하지 않아요. 회전 전체에 대한 가중 Bézier/접선 편집, 기록되지 않은 다회전 winding 추정, 구간 타임워프는 이 기능의 범위가 아니에요.
