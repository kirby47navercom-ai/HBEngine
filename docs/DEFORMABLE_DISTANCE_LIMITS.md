# 천·로프의 이동 반경과 최대 거리

Cloth의 격자·3D 로프와 Rope2D의 **입자 이동 반경** 및 **입자 최대 거리**에서 입자 번호와 거리를 입력하고 지정해요. 장면과 블루프린트 컴포넌트의 기존 속성·Undo·검증·저장 경로를 함께 사용해요.

- `motionLimits: [{index,radius}]`: 작성한 입자의 로컬 시작점을 현재 오브젝트 계층으로 옮긴 위치가 중심이에요. 반경은 월드 미터이며 0은 그 위치로 제한해요.
- `distanceTethers: [{index,anchor,distance}]`: 두 입자가 떨어질 수 있는 최대 월드 거리예요. 두 입자가 움직일 수 있으면 실제 질량의 역수에 따라 양쪽을 보정해요. 역순으로 같은 쌍을 중복 지정할 수 없어요.
- `distanceIterations`: 한 고정 물리 단계의 보정 반복 횟수이며 기본 4예요. 충돌하는 설정이나 수렴하지 않은 제약은 `gameplayDebug.cloth/rope.distanceLimits.maxError`에서 마지막 잔여 거리로 확인해요.
- `pinWeights: [{index,weight}]`: 작성한 시작점으로 돌아가려는 부분 고정 가중치예요. 0은 자유 이동, 1은 시작점 추종이며 위치와 속도를 함께 혼합해요. 60Hz에서 작성 가중치를 그대로 적용하고 다른 고정 시간 간격에서는 `1-(1-weight)^(dt*60)`을 사용해요. 오브젝트가 이동하면 기준점의 속도도 따라가요. 거리 보정 반복 횟수와 무관하게 한 물리 단계에 한 번 적용해요.

이는 Rapier soft-body 계산 뒤, 표시 프레임·접촉 조회 전에 수행하는 엔진의 위치 투영 제약이에요. 분리 방향의 상대 속도만 제거하고 접선 속도는 유지해요. Rapier 내부의 접촉·반력 연립 해법을 추가한 것은 아니며, 투영으로 바뀐 위치의 접촉은 다음 물리 단계에서 풀려요. 강체에 연결되거나 완전히 고정된 입자는 이동하지 않아요. 서로 맞지 않는 제한을 작성하면 잔여 오차가 남을 수 있어요.

부분 고정 가중치는 번호로 지정하거나 **부분 고정 칠하기**를 펼쳐 브러시 반경·강도·가중치·감쇠로 칠해요. 기존 질량 브러시의 연속 드래그·키보드·한 획 한 Undo 처리를 공유하며, 0으로 칠하면 가중치를 지워요. 드래그 중에는 표시만 바뀌고 버튼을 놓을 때 기존 컴포넌트 검증·저장 경로로 반영해요. Escape·포인터 취소·포커스 이탈은 쓰기 없이 취소하고, 소유 컴포넌트가 바뀐 획은 거부해요. 화면에는 입자별 DOM 대신 최대 네 색상의 SVG 경로를 사용해요.

규칙적인 천 격자·로프는 [고정점에서 생성](CLOTH_TETHER_GENERATION.md)으로 최대 거리 연결을 만들 수 있어요. 현재 월드 크기를 반영한 표면 연결 경로를 사용하고 기존 배열·Undo·AI 문서 편집 흐름에 넣어요.

실행 중 이 속성들을 편집해도 물리 바디·세대·속도·실행 중 고정·강체 연결·소성 휴지 상태를 다시 만들지 않아요. 토폴로지를 줄이면 범위를 벗어난 행을 기존 컴포넌트 편집 경로에서 제거해요. C++는 기존 `hb::Components::SetText`의 JSON 속성, BP는 기존 `componentSetJson`을 사용해요. 배열이 비어 있고 자동 연결도 꺼져 있으면 제약 객체나 입자 투영 순회를 만들지 않아요. 실행 중 고정점 변경을 따라가는 [자동 거리 연결](DEFORMABLE_AUTO_TETHERS.md)은 별도 설정으로 켜요. 부분 고정은 작성한 위치·속도 구동이며 물리 스프링·접촉 반력 연립 계산을 대신한다고 표시하지 않아요. `distanceLimits.pinError`는 거리 보정까지 끝낸 실제 기준점 오차예요.
