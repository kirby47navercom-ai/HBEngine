# 124 — 공유 교차 정점·기존 주소 계약

동일한 로컬 기하를 쓰는 인스턴스의 교차 정점을 GPU atlas에서 공유한다. 공유가 이득인 경우만 사용하고, 단일 인스턴스·공유 불가능한 기하·오히려 커지는 작은 기하는 기존 포장을 유지한다. BLAS는 기존처럼 공유하고 TLAS의 역변환으로 광선을 로컬 공간으로 옮겨 교차한다. 방향을 다시 정규화하지 않아 광선의 거리 매개변수를 유지한다. 음수·비균일 배율도 대조한다.

모델 로더가 복제한 서로 다른 geometry ID도 정점/인덱스 내용으로 공유 후보를 찾는다. 후보의 실제 로컬 정점을 다시 대조해 해시 충돌로 다른 모양이 합쳐지지 않게 한다. 버전이 바뀌면 후보 키를 갱신하고, 인스턴스의 이전 BLAS 참조를 유지해 정점 수정도 기존 refit 경로를 사용한다. interleaved buffer의 버전 변경도 대조한다.

교차 기록은 기존6개 float4의 논리 주소를 유지하면서 물리 저장을5개로 줄인다. 공유 정점/변환 참조·물리 속성·법선·색·발광을 저장하고 정점은 필요한 때 월드 공간으로 복원한다. 공용 atlas 로더가 이후 머테리얼·텍스처·UV·발광·광자·모션 주소를 물리 위치로 옮긴다. 논리 주소를 사용하는 기존 SDK·노드·에셋을 다시 작성할 필요가 없다. CPU의 현재 월드 삼각형과 기존 포즈 캐시는 유지하며 GPU 전체 메모리를 모든 인스턴스에서 같은 비율로 줄였다고 주장하지 않는다.

5,376개 교차 삼각형이168개 로컬 삼각형을 공유한 CPU 대조에서 최대 위치 오차5.40×10⁻⁸, 음수/비균일 배율·정적 재사용·이동 행·광자/모션 위치·단일 인스턴스 fallback을 확인했다. 비교 장면의 전체 atlas는1,179,648→1,114,112바이트다. 인스턴스당 머테리얼/UV/법선 등은 남는다. 큰 중간 prefix를 추가 복제하지 않고 기존 typed array 안에서 압축한다. 새 텍스처·자동 GPU 읽기·의존성·오브젝트 개수 제한은 없다.

주소/개수/논리 용량 검사는 네이티브 프레임 입력 시점에 실행한다. 포인터가 잘못된 공유 정점은 셰이더에서도 거부한다. 기존 변경 행 전송과 성공/실패 프레임 소유권을 유지한다. `renderer.rayGeometry`는 공유 여부·전체/로컬 삼각형 수·atlas 크기·포즈 행렬 크기·변경 행을 읽기 전용 수치로 제공한다. 사람·C++·블루프린트·AI는 기존 MeshRenderer/Transform/머테리얼 계약을 사용하고 계산된 atlas를 직접 편집하지 않는다.

수치/머테리얼 주소 로더와 정점 복원 로더를 나누어 일반 값 읽기에 역변환 계산을 넣지 않는다. 실제 실행에서 발견한 첫 DirectX 프레임 지연, 모델 복제 공유 누락, 볼륨 합성에서 빠진 곡면 옵션, TSL 분기 반환 타입 오류를 기록하고 수정한다. 최종 CPU·native·세 실행 경로의 결과는 `docs/research/RENDERING_124.json`에 묶는다.

본문 대조는 [PBRT4 Applying Transformations](https://www.pbr-book.org/4ed/Geometry_and_Transformations/Applying_Transformations)의 점/벡터/법선·광선 구역이다. 연결 오류 경계·API 전부를 읽었다고 계산하지 않는다. 실제 compute·세 렌더러·설치 결과는 기계 기록에서 해당 gate가 통과한 뒤 확인한다.
