# 반전 크기와 구형 반사 제작

액터의 각 scale 축은 음수와 양수를 지원한다. 절댓값은 기존과 같은 0.01~10000이며 C++ float로 왕복한 0.01의 표현값도 경계값으로 허용한다. 0·비유한값은 저장·생성·실행에 사용할 수 없다. 좌우 반전은 `[-1,1,1]`, 앞뒤 반전은 `[1,1,-1]`이다. 위치·회전은 크기를 지정할 때 변경하지 않는다.

- 씬·프리팹 복제·행렬 변환·기즈모·다중 선택 속성은 부호를 보존한다. 행렬을 TRS로 분해할 때 부호가 다른 축과 회전으로 옮겨질 수 있으며 같은 변환인지 행렬로 비교한다. 회전된 비균일 부모에서 발생하는 shear의 완전한 보존은 별도 과제다.
- `Scene::SetScale`, `Scene::SetTransform`과 같은 블루프린트 노드에 같은 범위를 적용한다. 유효하지 않은 값은 기존 상태를 덮어쓰기 전에 거부한다. 사용자 C++의 직접 필드 쓰기도 실행기 출력 검증을 거친다.
- 풀 재사용·생성·런타임 저장·물리 스냅샷·네트워크 복제에서 반전을 허용한다. 시퀀스와 네트워크의 축 보간이 0을 지나면 가장 가까운 허용 크기로 제한한다. 반전 사이를 보간하면 방향 전환은 불연속이다.
- 물리 형상 크기는 절댓값, 로컬 콜라이더 중심의 오프셋은 부호를 사용한다. DirectX의 면 판정·법선·그림자 래스터 상태는 월드 반전을 반영한다. 네이티브 인스턴스 한 묶음 안에 서로 다른 winding이 있으면 픽셀 단계에서 면을 판정한다. 일반 양수 인스턴스는 기존 하드웨어 컬링을 유지한다. 인스턴스 레코드는 144바이트 그대로다. 브라우저의 음수 InstancedMesh까지 지원한다는 의미는 아니다.

구형 ReflectionProbe의 `volumeRadius`는 월드 단위 반경이어서 액터의 크기·부모의 비균일 크기로 늘어나지 않는다. 영역 중심 offset과 captureOffset은 소유 액터의 변환을 따른다. `ReflectionProbes::SetSphere`는 모양과 반경을 한 번에 지정한다. 상세 계약은 [SPHERE_REFLECTION_PROBES.md](SPHERE_REFLECTION_PROBES.md)에 있다.
