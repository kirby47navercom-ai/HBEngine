# 큰 타일맵의 획 편집

사람용 브러시·지우기·사각형·채우기는 한 번의 포인터 획을 `TileBrushSession`으로 준비해요. 화면에는 준비 중인 타일을 표시하고 실제 문서·dirty·Undo는 획 종료나 저장의 `flush()`에서 한 번만 반영해요. 기존 레이어·셀 좌표·브러시 결과·자동 타일 규칙과 일반 v1 JSON 저장은 유지해요. 사각형의 취소와 브러시의 유효한 접두 획 저장 규칙도 유지해요. 다른 문서 데이터로 교체되면 진행 중인 획을 폐기하고 새 데이터를 보존해요.

한 점 편집은 기존 일반 배열 경로를 사용해요. 두 번째 실제 변경부터 활성 레이어를 한 번만 별도 복사/고정해 런타임 청크 저장을 재사용해요. 원본 문서·셀·레이어 메타데이터를 고정하거나 바꾸지 않아요. 이후 지역 변경은 해당 청크/자동 타일 이웃만 수정하고 가상 뷰포트는 공간 그룹과 셀 수를 읽어요. 중간 전체 타일 배열 공개와 정렬을 반복하지 않아요. 마지막에 정렬된 보통의 가변 JSON 배열로 바꿔 한 Undo로 게시해요. 바뀌지 않은 셀/다른 레이어의 저작 참조도 유지해요.

첫 일반 변경, 내부 레이어 복사/고정, 마지막 전체 공개·정렬·검증은 여전히 O(N)이에요. 색인/삭제 구멍 압축도 주기적으로 O(N)이에요. 전체 맵을 명시적으로 표시하면 전체 배열 공개/렌더 비용이 들어요. 일반 속성 편집의 문서 전체 복사와 디스크 청크 형식을 없앤 변경은 아니에요. 새 오브젝트/맵 개수 제한·워커·상시 타이머를 추가하지 않아요.

AI는 `tilemap.stroke`로 여러 구간을 한 번에 편집해요. `path`, `expectedRevision`, `layerId`, `segments:[{tool,from:[x,y],to?:[x,y],index?:number}]`를 지정해요. tool은 brush/erase/rectangle/fill이고 index -1은 제거예요. 모든 구간 형식을 먼저 확인하고 16구간마다 양보해요. 준비 중에는 문서/소유자 identity만 확인하고, 게시 전에 기존 공용 CAS가 전체 revision을 다시 확인해요. 활성 문서가 바뀌더라도 처음 문서 경로를 고정해 다른 문서를 덮어쓰지 않아요. 오류/폐기 시 준비된 접두 구간도 문서에 게시하지 않아요. `dryRun` 기본 응답은 요약이고 전체 제안 데이터는 `includeData:true`예요.

새 파일 포맷 없이 저장 후 기존 BP/C++ 타일 서비스·렌더/충돌 로더가 읽어요. `node tools/check-tile-brush-2473.mjs`는 이전 Git 구현과의 독립 대조, 65536셀/64지점의 중간 배열 공개, 실제 편집기 paint/finish/flush와 가상 drawMap 호출, 외부 문서 교체, AI 공용 CAS, 저장 후 런타임 로딩을 확인해요. 구조적 작업량의 근거이며 새 실제 창/GPU·FPS·OS 메모리 수치는 아니에요.
