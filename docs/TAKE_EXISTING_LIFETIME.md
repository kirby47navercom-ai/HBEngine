# 기존 대상의 수명 녹화

Take 녹화 설정에서 **기존 대상 수명·표시 복제**를 켜면 선택한 기존 액터의 시작 시 존재 여부, 풀 비활성화·재활성화, 삭제·재생성까지 기록해요. 기본값은 꺼짐이며 기존 프리셋의 동작은 유지해요. **새 오브젝트 생성·삭제**는 녹화 시작 뒤 발견한 대상만 기록하는 기존 옵션이고, 두 옵션을 함께 사용할 수 있어요. 새 대상 필터는 자동 발견에 적용하며 명시적으로 선택한 기존 대상은 해당 필터로 제외하지 않아요.

기존 대상 수명은 원본을 파괴하는 대신 고유 ID를 가진 표시용 복사본으로 재생해요. 복사본에는 시각 컴포넌트만 넣고 스크립트·물리·게임플레이 컴포넌트를 다시 실행하지 않아요. 원본의 표시는 시퀀스가 제어하는 동안 숨기고, 정지하면 원래 값으로 복원해요. 다른 시퀀스가 표시를 제어하면 기존 우선순위와 하위 소유자 재개 규칙을 적용해요. 원본이 같은 ID의 다른 액터로 교체되면 이전 소유자가 그 새 원본을 숨기거나 복원하지 않아요.

같은 ID에 새 액터가 들어오거나 종류·시각 에셋이 바뀌면 해당 생성 키에 시각 템플릿을 보관해요. 앞으로·뒤로 탐색하면 그 시점의 템플릿으로 소유 복사본만 교체해요. 기존 대상 복사본의 시각 컴포넌트 구성도 자동 기록해서, 메시·스프라이트 변경을 따라가요. 선택한 부모·자식은 복사본 ID로 연결하고 선택하지 않은 외부 부모는 월드 변환으로 캡처해요. 초기 템플릿뿐 아니라 이후 템플릿의 부모 순환도 검증해요.

AI는 `runtime.take.start`에 `includeLifetime:true`와 명시 `targets` 또는 기존 Take 소스 설정을 사용해요. UI·프리셋·문서 Undo/Redo·`sequence.take.apply`·`schema.gameplay.takeLifetime`을 공유해요. 저장된 시퀀스는 기존 Blueprint/C++ LevelSequence Play/Seek/Stop으로 실행하며 별도 녹화 프리셋 파일을 게임에 요구하지 않아요.

형식은 기존 `spawn` 트랙에 선택적인 `sourceLifetime:boolean`을 추가해요. `true`인 키에는 선택적으로 `object` 템플릿을 넣을 수 있고, ID는 트랙 대상과 같아야 해요. 모든 템플릿은 시각 전용·자료형·크기·부모 관계를 검증해요. 스크립트·물리 주입, 거짓 키의 템플릿, 중복 논리 대상은 거절해요. 새 필드가 없는 기존 시퀀스는 기존 방식으로 재생해요. 새 형식은 갱신된 엔진에서 사용하세요.

생성 키는 재생 시작 때 정렬·준비하고 시간 탐색은 이진 탐색해요. 풀 비활성 구간에는 불필요한 시각 스냅샷을 만들지 않아요. 사라지거나 교체된 소유 복사본의 채널은 버려서 반복 재생 동안 오래된 액터의 제어 기록이 쌓이지 않게 해요. 새 타이머·작업자·GPU 리소스를 추가하지 않아요. 활성 녹화 대상별 메타데이터와 실제 키/시각 스냅샷 비용은 있어요.

범위: 원본의 게임 시뮬레이션을 정지하거나 임의 게임 상태를 되돌리는 기능은 아니에요. 복사 대상으로 선택한 액터의 BP/C++ 변수 채널은 기록하지 않으며 위젯·컴포넌트 수명 복제는 지원하지 않아요. 고급 Attachment·socket·constraint·임의 게임플레이 rollback은 별도 범위예요.

현재 C++ 생성 API는 한 콜백에서 비풀 액터를 Destroy한 뒤 같은 명시 ID로 즉시 Spawn하면 충돌로 거절해요. 삭제 완료 뒤 Spawn하는 흐름은 사용 가능해요. 연속 활성 ID교체를 녹화하는 VM 동작과 이 C++ API 제한을 구분하며, 원자적 ID교체·네이티브 인스턴스 세대 처리는 별도 잔여로 기록해요.

소유자는 `take-lifetime.js`, `take-recorder.js`, `sequence-spawn.js`, `sequence-spawn-program.js`, 공용 `SequenceChannels`예요. WORK1939와 USER_INSTALL1941에 제작·실행 근거를 기록해요.
