# 시퀀스 구간의 곡선 가중치

하위 시퀀스 구간의 **가중치 곡선**에서 기존 선형·계단 외에 자동·클램프 자동·수동/분리 탄젠트 보간을 선택해요. 기존 스칼라 Hermite·가중 Bézier 계산기를 공유해요. 곡선 핸들에서 이전·다음 기울기, 시간 핸들과 값 핸들을 편집하고 미리보기는 실제 Bézier 경로를 그려요. 목록은 기존 32키 페이지를 유지해요. 보간 선택창의 전체 선택지는 해당 입력에 포커스가 갈 때 채워서 다른 행의 반복 HTML을 줄여요. 이 과정은 문서나 Undo를 바꾸지 않아요.

키 값과 유효한 곡선 제어점 값은 모두 0~1이어야 해요. 시간 핸들은 기존 단조 시간 검증을 거쳐 역방향으로 접히는 곡선을 거부해요. 클램프 자동은 이웃 키에서 제한한 기울기를 쓰며, 단위 범위를 벗어나는 자동/수동 제어점은 편집을 반영하기 전에 알려줘요. 이 제한으로 실제 가중치도 단위 범위에 머물러요.

키 추가와 앞부분 자르기는 기존 de Casteljau 분할을 사용해 원래 곡선을 보존해요. 이웃이 바뀌기 전에 자동 기울기를 명시 값으로 고정하므로 정확한 키 시각에서 자르거나 이전 구간을 제거해도 남은 곡선이 달라지지 않아요. 선형·계단 파일은 기존 간단한 키 표현을 유지해요. 평가는 기존 약한 참조 준비와 이진 탐색을 사용하며 매 프레임 전체 키를 복사하거나 정렬하지 않아요.

기존 구간 배수·부모 시각·자식 시각 매핑과 정규화 혼합·소유권 복구 규칙을 공유해요. 일반 문서 편집·키 예산·Undo·AI 스키마를 사용하고 새 SDK 함수는 필요 없어요. 오디오 `volumeCurve`는 현재 음량 예약 경로에 맞는 선형·계단 검증과 입력을 유지해요. 구간의 곡선 가중치와 표본 단위의 곡선 AudioParam 예약을 같은 기능으로 표시하지 않아요.
