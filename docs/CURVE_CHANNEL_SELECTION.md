# 키별 채널 선택

시퀀스와 블루프린트 타임라인에서 Ctrl/Command를 누르고 키의 X·Y·Z·색상 점을 골라요. 같은 벡터 키의 서로 다른 축과 다른 트랙의 축을 함께 선택할 수 있어요. 다시 누른 축만 선택에서 빠져요. 범위 드래그와 전체 선택은 표시된 채널을 대상으로 하며, 채널을 숨기면 해당 축의 선택도 해제해요. 키·채널 개수와 선택 강조를 함께 표시해요.

값 드래그는 각 축의 보기 변환을 역으로 적용해요. 정규화·쌓기 보기에서 서로 다른 원래 범위도 유지해요. 시간 이동은 한 벡터 키에 한 번만 적용해요. 숫자 값·탄젠트·가중치와 평탄화·정렬·부드럽게·반전·변환·주파수 필터는 선택한 키의 선택한 축을 수정해요. 여러 축을 순서대로 다시 변환하지 않고 같은 원본에서 계산해 한 번의 Undo로 반영해요. 선택 맞춤도 선택한 축만 사용해요.

현재 벡터 키의 시간·보간 방식·존재 여부는 채널이 공유해요. 시간 편집·보간·삭제·잘라내기·복사/붙여넣기는 키 레코드 전체를 대상으로 해요. 베이크·축약·Euler 필터도 기존 전체 채널 도구예요. 일부 축의 가중치 해제는 해당 성분을 기본값 1/3로 되돌리고 나머지 가중치는 유지해요. 독립 채널별 시간·보간·키 삭제를 제공한다고 표시하지 않아요.

AI는 `schema.curveChannelSelection`을 읽고 `sequence.curve.tool`에 다음과 같이 전달해요.

```json
{
  "path": "Assets/Sequence.hbsequence.json",
  "expectedRevision": "현재 문서 revision",
  "operation": "transform",
  "valueOffset": 2,
  "selections": [
    {"track": "PositionA", "index": 0, "channels": [0, 2]},
    {"track": "PositionB", "index": 3, "channels": [1]}
  ]
}
```

인덱스는 현재 원본 키 배열의 위치예요. `selections`는 `track`·`tracks`·`indices`·`channel` 선택과 함께 쓰지 않아요. 중복 키 행·중복 축·잘못된 대상·범위·전체 문서 검증 실패는 모든 수정을 거절해요. `dryRun`·revision·Undo·저장은 기존 문서 트랜잭션을 사용해요. 저장 형식과 런타임 샘플러·C++ Play/Seek 계약은 그대로 사용해요.

이 구현은 기존 UE Curve Editor 읽기 근거를 재사용해요. HB의 공유 벡터 키와 선택 JSON은 자체 계약이며, Unreal의 독립 채널 저장 형식과 같다고 주장하지 않아요. 추가 워커·게임 프레임 작업·GPU 자원·영구 캐시는 없어요. 편집 중 선택 Map과 선택한 트랙의 임시 후보만 사용해요.
