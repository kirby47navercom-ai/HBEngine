# 설치 버전 누적 방지

193부터 이전 설치본을 사용하는 게임·빌드가 있으면 새 버전 폴더를 만들거나 바로가기를 바꾸기 전에 갱신을 보류해요. 사용이 끝나면 다시 설치해 Versions 하나를 유지해요. 복사 중 새 사용이 시작돼도 이번 임시 설치를 제거해요. 업데이트를 검증하고 바로가기·프로젝트 연결을 전환한 뒤 이전 설치 사본을 자동 정리해요. 현재 설치본과 실행 중인 버전만 보존하며, 사용자 프로젝트가 들어 있는 버전은 자동 삭제하지 않아요. 버전을 백업한다는 이유로 전체 설치본을 계속 쌓지 않아요.

수정된 파일과 설치 명세 밖의 파일은 `HBEngine/PreservedChanges/버전/`에 따로 보존하고 SHA256을 확인해요. 설치 파일·컴파일 캐시 전체를 보존용 사본으로 복제하지 않아요. `Maintenance/latest-cleanup.json` 하나에 마지막 정리 결과를 기록하며 임시 계획 파일은 작업 뒤에 삭제해요. 복사 실패 시 이번 설치의 임시 폴더도 제거해요. 삭제 직전에 절대 경로·설치 명세·링크·실행 프로세스를 다시 확인해요.

2026-10-13 실제 폴더에서 오래된 설치본 5개, 논리 용량 903,274,158바이트를 정리했어요. 당시 현재 설치본 `2229fcf1ad625a5b` 하나를 남겼고, 수정된 빌드 도구 3개와 별도 라이선스 파일 총 45,313바이트를 따로 보존했어요. 원본 게임·세이브·SDK·사용자 설정은 정리 대상이 아니에요.

격리 검사에서 현재·실행 중인 버전과 사용자 프로젝트의 보존, 수정 파일 보존, 다음 설치 후 이전 사본 삭제, 경로 범위 거부와 단일 정리 기록을 확인해요. 실행 중인 이전 창은 강제로 종료하지 않아서 다음 정리 시점까지 그 버전이 추가로 남을 수 있어요.


193의 구조화 결과: deferred:true/reason:running-install/active:[{pid,version,name}]. PID는 상태 확인용이며 종료 허가가 아니에요. 마지막 확인 뒤 실행이 시작되는 경쟁에서는 삭제 보호를 우선하고 후속 정리를 수행해요. [검사](ENGINE_WORK_193.md).
