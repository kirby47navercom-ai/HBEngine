# 검사 산출물과 캐시 정리

2026-10-13에 엔진 저장소와 HBEngine의 AppData·임시 폴더·설치본을 확인했어요. 소스 자체보다 반복 검사 패키지와 WebView2 프로필, C++ 캐시가 대부분을 차지했어요.

| 대상 | 정리한 파일 크기 |
| --- | ---: |
| 저장소의 검사 패키지·프로필·오래된 C++ 캐시 | 125,636,007,166바이트 |
| 예전 설치본의 미등록 C++ 캐시·임시 Android 검사 가상기기 | 18,722,108,621바이트 |
| 합계 | 약 134.4GiB |

`native/build`는 처음 약 130.1GiB에서 정리 후 약 13.5GiB로 줄었어요. 검사를 실행하는 동안 일시적으로 늘어날 수 있어요. 이 수치는 파일의 논리적 크기예요. C 드라이브의 실제 여유 공간과 파일 수, 정리 대상은 별도 영수증에 기록해요.

검사 결과·실패 기록·스크린샷·재현용 프로젝트·원본 소스는 남겨요. 지운 패키지의 `game.hbpack.json`과 빌드 보고서는 SHA와 함께 보관해요. 원본 Auric_Loop, 현재 설치본과 직전 설치본, 게임 저장 데이터, Android SDK/NDK, 조사 원문은 지우지 않았어요. 예전 설치본 8개는 등록 파일 13,834개를 대조했고 모두 원래 해시와 일치해요.

검사 전용 경로만 정리하며, 실행 중인 프로세스가 사용하는 대상과 링크 경로는 제외해요. Windows에서는 삭제 직전에 절대 경로·폴더 종류·프로젝트 표식을 확인한 뒤 `Remove-Item -LiteralPath`로 지워요. 새 GPU·DirectX 검사는 종료 시 정리하고, 검사 프로젝트를 생성한 Node 프로세스도 종료 직전에 같은 정리를 실행해요. 정상 사용자 프로젝트 생성에는 적용하지 않아요.

기존 검사 잔여물을 정리하려면 저장소에서 `npm run clean:test-cache`를 실행해요. 오래된 공유 C++ 캐시는 최신 32개를 유지하며 사용 중인 대상은 추가로 보존해요. 정리 결과는 `native/build/cache-prune-*/result.json`에 남아요. 관련 안전 검사는 `npm run test:artifact-storage`예요.

남은 13.5GiB에는 조사 원문, 재현용 프로젝트, 캡처와 보고서, 유지한 빌드 캐시가 있어요. 개인 앱의 일반 캐시나 사용자 게임 저장 데이터까지 일괄 삭제하지 않아요. 이번 정리는 엔진 실행 메모리나 게임 FPS를 측정한 결과가 아니에요.
