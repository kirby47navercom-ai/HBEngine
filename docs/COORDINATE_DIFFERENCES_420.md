# 머테리얼 좌표 변화량

현재와 이전 프레임의 레이 머테리얼 그래프는 좌표의 변화량을 별도로 전달해요. 큰 월드 위치나 오프셋에 작은 값을 더했다가 빼면서 텍스처 밉 선택이 사라지는 문제를 막아요. 기본 머테리얼 값·UV 보간·IR·샘플러 설정은 유지해요.

더하기·빼기·벡터 조합·채널·형 변환은 변화량을 직접 전달해요. 곱셈은 `a·Δb + b·Δa + Δa·Δb`를 사용해 두 입력이 함께 바뀌는 항까지 유지해요. 타일링·패너·보간·내적·외적도 같은 원리를 사용해요. 월드 위치의 변화량은 큰 위치에 합산하지 않고 레이 폭으로부터 전달해요.

실제 GL·WebGPU·DirectX에서 큰 오프셋 그래프와 월드 위치로 만든 UV의 넓은 밉·좁은 밉을 대조했어요. 공유 수식의 20개 연산·333조건에는 일반 범위, 큰 값, 곱의 교차항을 분리하는 정확한 유리수 조건이 들어 있어요. 이전 포즈 17조건과 48종 샘플러 설정의 기존 값도 별도로 대조해요.

추가 GPU 타깃·텍스처·uniform·운영 중 readback은 없어요. AI가 조회하는 `engineSchema().raySurfaceHistory.uvFootprint`에도 같은 비용·안정 연산·근사·잔여 한계가 있어요.

비선형 연산은 아직 이동한 입력의 결과 차이를 계산하는 fallback을 사용해요. 큰 점에서 다시 계산하는 스무스 노멀, 표현할 수 없을 정도로 큰 작성 UV·시간의 정밀도도 별도 작업이에요. 텍스처가 생성한 좌표의 변화량은 0으로 근사하고 레이 폭 안의 시선 방향은 고정해요. 이 검사를 일반 래스터의 모든 큰 좌표 문제나 초기 컴파일 속도 개선으로 해석하지 않아요.
