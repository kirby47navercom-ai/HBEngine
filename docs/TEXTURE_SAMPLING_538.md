# 텍스처 밉 샘플링

텍스처 샘플 노드를 선택하고 속성의 **밉 모드**를 바꾸면 필요한 입력 핀이 표시돼요. 2D·배열·볼륨·큐브 샘플이 같은 설정을 사용해요.

| 모드 | 입력 | 동작 |
|---|---|---|
| 자동 | 기존 UV 또는 방향 | 렌더러가 화면 미분 또는 광선 원뿔로 밉을 정해요. |
| LOD | LOD | 0이 가장 큰 원본 밉이에요. 샘플러에 따라 소수 LOD를 보간해요. |
| 바이어스 | Bias | 계산한 LOD에 바이어스를 더한 뒤 유효 범위로 제한해요. 음수는 더 선명하게, 양수는 더 낮은 해상도로 조절해요. |
| DDX / DDY | DDX·DDY | 직접 지정한 좌표 변화량으로 밉을 계산해요. 배열의 레이어 번호는 미분하지 않아요. |

기본 모드는 기존 2D·배열·볼륨의 자동, 큐브의 LOD를 유지해요. DDX/DDY는 2D·배열에서 Vector2, 볼륨·큐브에서 Vector3예요. 다른 모드로 바꿔 숨겨진 입력 값과 연결은 문서에 남으며 Undo·Redo로 복원할 수 있어요.

모드는 GLSL·WebGPU·DirectX의 일반 머테리얼과 광선 머테리얼에 연결돼요. 광선 경로에서는 현재 입력과 커밋한 이전 프레임 입력을 각각 평가해요. 기존 0–11 샘플러 플래그는 유지하고 새 모드는 64–111을 사용해요. 엔진의 `engine.schema.textureSampling`에서 모드·기본값·입력·호환 규칙을 조회할 수 있어요.

LOD나 Bias 핀에 스칼라 파라미터를 연결하면 기존 C++ 편의 함수로 바꿀 수 있어요. 노드에서 파라미터 이름을 `MipBias`로 정했다면 다음 호출을 사용해요.

```cpp
hb::Materials::SetFloat(target, "MipBias", 1.0f);
```

AI도 같은 머테리얼 JSON의 `mipMode`와 `inputValues`, `graph.edges`, 파라미터를 편집해요. 사람이 편집한 문서와 별도 형식으로 갈라지지 않아요. 바이어스는 DirectX 지원 범위인 -16–15.99로 제한해요.

WebGPU의 RGBA8 볼륨 밉은 업로드할 때 컴퓨트 셰이더로 생성해요. 홀수 크기와 깊이 축을 포함하고, sRGB는 선형 값으로 평균낸 뒤 저장해요. 임시 밉 텍스처는 제출 후 파괴하며 유휴 프레임에서 재생성하지 않아요. `gpuVolumeMipState(renderer)`는 업로드·디스패치·임시 핸들의 생성/파괴 수를 조회해요. 명시적인 큐브 방향은 환경 조명 회전과 분리해요.

CPU 라이트맵 베이크도 명시 LOD·DDX/DDY와 가져온 2D 밉을 사용해요. 베이크 한 번의 밉 캐시는 32MiB 또는 그보다 큰 한 텍스처 체인으로 제한하고, 프레임 렌더링에 상주하지 않아요. CPU의 점 샘플에는 암묵적인 화면 미분이 없으므로 자동·바이어스는 레벨 0을 사용해요. 베이크에서 직접 밉을 선택하려면 LOD나 DDX/DDY를 지정해요. 기본 UV·큐브 방향과 스칼라→벡터 입력은 GPU 경로와 같은 규칙을 사용해요.

광선 원뿔의 유한 변화량은 하드웨어의 인접 픽셀 미분과 동일한 계산은 아니에요. 텍스처 값의 sub-ULP 변화·불연속·큐브 면 경계를 완전히 적분하는 필터로 확장한 것은 아니에요. HDR·압축·사용자 정의 배열/볼륨 밉 가져오기와 스트리밍도 별도 작업으로 유지해요.
