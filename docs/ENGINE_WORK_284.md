# 284 · 이전 노멀 Time 호출의 필드별 특화

- GLSL/HLSL의 이전 노멀 Time 분기를 base-normal 필드 의존성으로 특화해요. 무관한 발광/코팅 Time은 제외하고 legacy unscoped 프로그램은 보수적으로 유지해요. 키·IR·이전 절대 시각·현재/이전 골든 노멀은 보존해요.
- 실제 숨김 GL/GPU 및 HLSL 장치의 노멀 오차는 최대5.9258e-8이에요. 별도 작은 정적 노멀/발광 Time 표본의 한 순서 GL 링크는3252.5→163.7ms였어요.

범위와 한계:

- 작은 표본의 한 순서 링크 수치이며 Complex141·전체 FPS·동일 부하 양방향 벤치마크가 아니에요.
- 189의 예전 강제 Time 검사 보조기를 새 필드 분기 기준으로 수정했어요. 제품 검증이나 골든 픽셀을 완화하지 않았어요.
