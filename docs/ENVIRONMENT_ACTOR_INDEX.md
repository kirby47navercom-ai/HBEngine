# EQS 액터 생성기의 공간 검색

`EnvironmentActorIndex`는 공용 `engineOperations`의 `eqsRun`에서 사용해요. 블루프린트와 C++ 명령 재생도 같은 경로예요. 기존 EQS 파일·API·반환값은 그대로예요.

- XY는 깊이를 제외한 두 축, 기본 XZ 질의는 기존처럼 높이까지 포함한 세 축으로 검색해요.
- 64단위 셀로 넓은 후보를 찾고 기존의 정확한 반경·projection·test·점수 계산을 그대로 수행해요. 셀 경계와 음수 좌표에서도 반경 밖 액터를 결과에 넣지 않아요.
- 후보를 원래 월드 순서로 정렬한 뒤 검사해서 projection/trace 순서, 동점 순위와 진단 표본 ID를 보존해요.
- 매 질의 직전에 현재 객체·부모 변환·활성화·순서를 동기화해요. 같은 프레임의 직접 위치 변경, 부모 이동, 풀 반환, 같은 ID의 새 객체도 다음 질의에서 반영해요. 실패한 부모 변환은 부분 인덱스를 공개하지 않아요.
- 바뀐 위치의 셀만 고쳐요. 넓은 반경은 비어 있는 거대한 좌표 범위를 순회하지 않고 점유 셀을 살펴봐요. 액터 수 제한을 추가하지 않아요.
- `gameplayDebug.eqsDiagnostic.actorSearch`에는 대상 수·점유 셀·살핀 셀·좁힌 후보 수와 검색 방식만 복사해요. `inspect()`와 조회 결과를 바꿔도 내부 인덱스는 바뀌지 않아요.

현재 장면 객체는 배열과 변환을 직접 바꿀 수 있으므로 안전한 동기화에는 여전히 O(N) 순회가 필요해요. 후보 검사 감소를 전체 프레임 속도 향상으로 계산하지 않아요. 자동 재질의·GPU 검색·실제 창 성능은 별도예요. 실행 서비스 종료 때 인덱스 참조도 비워요.
