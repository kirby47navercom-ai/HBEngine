## 프리팹 제작과 실행

콘텐츠의 프리팹을 배치하면 원본의 로컬 ID와 월드 ID 대응, 해석한 원본 기준값, 의존 파일과 revision을 장면에 저장한다. 원본·부모 변형·중첩 원본을 편집하면 열린 장면의 연결 인스턴스를 갱신한다. 기준값/인스턴스/새 원본의 세 방향 비교로 수정하지 않은 값은 상속하고, 각자 수정한 값은 보존한다. 위치·회전·외부 부모는 배치 상태로 유지한다. 크기와 변환 값은 축별로 비교한다.

속성 창의 프리팹 구역에서 원본 열기, 동기화, 모두 복원, 연결 해제, 속성별 적용·복원을 사용한다. 컴포넌트 ID는 배열 순서 대신 안정 ID로 찾는다. 충돌에는 원본/인스턴스 값을 표시하며 반복 동기화만으로 미해결 충돌을 지우지 않는다. 실행 진단·타일 충돌 같은 임시 값은 사용자 수정으로 표시하지 않는다. 원본의 오브젝트/컴포넌트 추가·삭제도 병합하며, 삭제될 내부 오브젝트에 외부 자식이 붙어 있으면 먼저 부모를 바꾸도록 거부한다.

적용은 원본과 장면을 기존 원자적 파일 편집으로 처리한다. Undo하면 원본도 돌아가고 각 인스턴스의 독립 수정은 유지한다. 원본 갱신에서 생긴 파생 장면 변경을 별도 가짜 Undo 단계로 쌓지 않는다. 복사·붙여넣기와 추가 레벨 재배치에서도 내부 참조와 컴포넌트 ID를 보존한다. 이름 중복 방지를 위한 복사본 이름 변경은 이름 오버라이드로 남는다.

Play 준비에서 같은 병합을 수행한다. 장면이 저장된 뒤 원본이 바뀌어도 최신 원본과 배치 수정을 합친 실행 사본을 사용한다. C++/블루프린트의 타입 있는 액터 참조는 바인딩 메타데이터를 준비한 뒤 월드 ID로 재배치한다. 임의 문자열을 참조처럼 바꾸지 않는다. 이전의 연결 정보 없는 복사형 프리팹은 자동으로 새 형식으로 추정하지 않는다.

## 2D 타일맵

TilemapRenderer에 청크/개별 정렬/레이어 묶음 모드를 둔다. 기본 직교 맵은 32×32 공간 청크로 렌더 기하를 분리한다. 변경한 셀과 자동 타일 이웃이 속한 청크만 다시 만들고 다른 기하·재질·아틀라스를 재사용한다. 레이어 숨김은 기하와 충돌을 재생성하지 않는다. 정점의 실제 미술 경계에서 bounding box/sphere를 계산해 큰 타일이 화면 가장자리에서 잘리는 것을 막는다.

등각 맵은 공간 사각형 청크가 겹친 그림의 그리기 순서를 깨지 않도록 대각 순서의 연속 띠를 묶는다. 개별 모드는 각 타일과 다른 스프라이트의 깊이 정렬에 사용하고, 레이어 묶음은 기존 동작을 유지한다. 모든 모드를 같은 성능이라고 계산하지 않는다.

충돌은 충돌 레이어의 점유를 합친 32×32 청크 안에서 사각형으로 병합한다. 직교는 BoxCollider2D, 등각은 투영한 PolygonCollider2D다. 변경한 충돌 청크만 다시 계산하고 나머지 컴포넌트 객체와 ID를 유지한다. 기존 C++ `hb::Tilemaps`와 블루프린트 Set/SetMany/Fill/Clear/ProcessChanges가 같은 경로를 사용한다. 물리 raycast와 시각 자원이 같은 변경을 받는다.

16,384타일의 16청크에서 한 칸을 수정한 실제 D3D11/WebGPU 실행과 편집기에서 1개 기하만 바뀌고 15개 ID가 유지됐다. D3D11 지정 카메라에서는 4개가 draw에 제출됐다. 이는 전체 대규모 월드·모든 카메라 성능의 보장이 아니다. 변경 시 셀 배열의 인덱싱/검증·물리 동기화에 남은 비용도 있고, 청크 충돌은 경계 사이까지 최대로 병합하지 않는다.
