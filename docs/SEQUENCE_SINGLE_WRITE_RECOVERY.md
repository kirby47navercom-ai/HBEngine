# 시퀀스 단일 필드 쓰기 복원

`SequenceChannels.write`도 setter가 실패하면 이전 소유 표본·표시값을 복원해요. 새 소유의 실패는 그 임대를 제거하고 아래 소유자나 공통 원래 값을 드러내요. 정규화 혼합·사용자 resolver도 기존 배치 복원 경로를 공유해요. apply와 복원 모두 실패하면 원래 원인을 포함한 `AggregateError`를 전달해요. `undefined`·null·0·false 같은 거절 이유도 오류로 보존하고 다른 필드 정리는 계속 시도해요.

정상 동기 쓰기는 계속 호출 안에서 반영하며 일반 override는 O(1)이에요. 기존 어댑터/기준값을 재사용하고, 일반 표본은 작은 값과 세대 번호만 저장해요. 실패한 경우에만 복원 계획을 만들어요. 비동기 setter는 세 번째 인자 `current()`를 게시 직전에 확인해야 해요. 같은 소유자의 더 최신 표본·다른 소유자의 표시값·대상 퇴역을 오래된 실패가 되돌리지 않도록 표본 세대와 필드 세대를 함께 검사해요.

보장은 관리하는 필드 상태에 한정돼요. 임의 외부 부작용·협조하지 않는 setter·controls/release 자체의 전체 롤백을 뜻하지 않아요. 배치 쓰기의 보장은 [기존 시퀀스 배치 복원 계약](SEQUENCE_BATCH_ROLLBACK.md)과 함께 적용해요.
