# 지면과 골반 보정

Full Body IK의 **지면과 골반**에서 사용할 발 목표를 선택해요. 여러 발을 같은 입력 포즈에서 검사하고, 가장 낮은 지지 위치에 맞춰 공유 골반을 한 번 이동한 뒤 기존 IK가 발과 관절을 풀어요. 기본은 꺼져 있고 기존 그래프의 동작과 비용을 유지해요.

켜면 루트 동작은 위치 유지(fixed)로 맞춰져요. 다른 루트 동작을 직접 선택하면 이 보정은 꺼져요. 최대 내림·올림은 월드 미터이고, 보정 가중치·발 목표 가중치·뼈 위치 강성·제외 뼈·최종 Alpha를 적용해요. 골반을 고정한 뼈 설정이 있으면 발 목표만 지면에 맞추고 골반 이동은 막아요. 지면이 없는 발이 있으면 골반을 올리지 않고, 지지 결과가 하나도 없으면 기존 목표를 유지해요.

발 목표마다 기존 2D XY 또는 3D 충돌 질의 한 번을 사용해요. 마스크·트리거 제외·소유자 제외·경사 한도를 공유해요. 캐릭터 월드 변환을 거쳐 보정하고 2D 깊이는 유지해요. 별도 물리 월드·워커·강체 반력 계산은 추가하지 않아요. 다리 길이와 기존 관절·방향·늘이기 제한은 원래 Full Body IK가 처리해요.

부드러운 전환은 그래프 시간 기준 지수 감쇠예요. 이전 결과를 실제 골격에 누적하지 않고 매번 입력 포즈에 더해요. 분기별 이력은 격리되며 비활성·Alpha 0·지면 없음·시간 역행·평가 간격 초과·분기 재진입·해제 때 초기화해요. Bool 파라미터로 켜고 끌 수 있고, 기존 AnimationGraph::SetBool과 동일한 실행 경로를 사용해요.

에디터는 목표별 체크 상자와 수치 입력을 제공해요. 목표 ID 이름 변경·삭제는 지지 목록도 함께 바꾸며 마지막 지지 발을 끄는 실수는 반영 전에 거부해요. 기존 한 번의 Undo·검증·저장·AI document.patch 계약을 사용해요. JSON은 fullBodyIK.properties.groundPelvis이고, hb schema --local --section groundPelvis로 계약을 읽을 수 있어요.

이는 발 지지와 골반의 운동학적 보정이에요. 보행을 예측하거나 접촉 힘·강체 반작용을 풀지 않으며 임의 리그의 체형 보정·발바닥 형상·보행 위상은 별도 기능이에요. 실제 창·기기 품질을 검사했다는 뜻도 아니에요.
