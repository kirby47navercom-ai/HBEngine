# 이전 프레임 평가·대형 2D 제작·저장 ID 복구

## 제작·실행 연결

- 경로 필터의 노멀 프로그램은 저장된 이전 삼각형·정점 법선·시각·카메라에서 평가한다. 월드 위치만 바꾸고 현재 UV를 사용하는 혼합 경로를 제거했다. 이전 카메라의 픽셀 콘과 이전 경로 거리를 사용해 노멀 텍스처의 밉 폭도 다시 계산한다.
- 강체의 비균일 크기 변경에서는 정점별 법선을 복원·정규화한 다음 보간한다. 모프·스키닝은 이미 저장한 이전 정점 법선을 사용한다. 새 이력 이미지·유니폼·프레임 읽기·지속 포즈 캐시는 추가하지 않았다.
- 기존 머테리얼 IR 키·필드 마스크·전송 버전·네이티브 상수 버퍼를 유지한다. 새 월드 의존 노멀의 음수 프레임 포인터는 24비트 정수 주소를 그대로 보존하고 구형 필터에서는 이력 거부로 처리된다. 기존 `-2` 비지원 표식도 거부한다.
- 이전 표면의 다른 월드/시점 필드와 투명 매질 분기까지 재생하는 기능은 별도 잔여다. 아직 추적하지 않는 다른 월드/시점 필드는 이력을 보수적으로 거부한다.

## 2D 맵

- 폭·높이의 256 제한을 제거했다. 양의 안전 정수이며 곱도 안전 정수인 좌표 범위를 검증한다. 저장 데이터는 기존 버전 1의 점유 셀 배열이어서 구형 소형 맵을 변환하지 않는다. 맵 전체 면적에 비례하는 배열을 생성하지 않는다.
- 대형 편집 화면은 보이는 구역만 그린다. 휠 확대의 포인터 위치, 가운데 버튼 이동, 전체 맞춤, 정확한 셀 이동을 지원한다. 충돌 직사각형도 점유 행을 따라 합친다.
- C++ `hb::Tilemaps::BoxFill`, `FloodFill`, `SetTiles`도 같은 희소 편집 경로를 사용한다. 묶음 좌표 키의 32비트 곱셈 오버플로를 제거했다. 게임 제작자는 기존 함수를 그대로 호출한다.
- 한 번의 동기 편집에는 262,144셀 작업 예산을 둔다. 초과 작업은 해당 호출의 변경을 게시하기 전에 거부한다. 전체 맵/오브젝트 수 제한이 아니다. 긴 드래그는 화면 구간별 호출로 처리되고 Undo는 한 스트로크로 묶인다.
- 자동 생성 타일 충돌 중심은 물리 질의의 기존 `1e6` 좌표 범위를 사용한다. 일반 제작 컴포넌트의 검증 범위는 유지한다. C++의 기존 `Vec2`는 float이므로 모든 안전 정수 좌표의 단위 정밀도를 보장하는 API는 아니다. 큰 월드의 원점 이동·정밀도는 별도 잔여다.
- 디스크의 청크 저장, 변경 시 전체 타일 배열 복사, 아주 큰 점유 맵의 렌더·충돌 총비용과 장시간 성능은 계속 다룰 항목이다.

AI와 사람은 같은 문서와 편집기를 사용한다. 에셋 변경은 기존 `document.patch`의 revision·검증·Undo 경로를 사용하고, 보기만 바꿀 때는 다음 명령을 사용한다.

```json
{"method":"document.open","params":{"path":"Assets/TM_Map.hbtilemap.json"}}
{"method":"tilemap.view","params":{"path":"Assets/TM_Map.hbtilemap.json","settings":{"cell":[900000,800000],"zoom":1.5}}}
```

`tilemap.view`는 문서 revision을 바꾸지 않는다. `cell`, `pan`, `zoom`, `overview`를 검증하고 현재 구역·확대·캔버스 픽셀 수를 반환한다. 전체 편집 규약은 `engineSchema().tilemapEditing`에 있다.

## 파일·인덱스 사이의 중단

일반 Assets/Source/Settings 텍스트 저장·에셋 생성과 루트의 일반 텍스트 파일에는 작은 `Saved/WriteIntents` 기록을 먼저 저장한다. 내용 파일의 원자 교체가 게시 시점이며, 파일은 교체됐으나 인덱스 쓰기 전에 종료됐으면 재열기/다음 저장에서 같은 ID로 인덱스를 완료한다. 게시 전 중단이면 원본과 기존 ID를 보존하고 소유한 임시 파일을 정리한다.

에셋 본문을 이 기록에 복사하지 않는다. 성공한 기록은 즉시 제거한다. 외부 변경이나 다른 ID를 발견하면 파일·인덱스를 덮어쓰지 않고 충돌 기록을 보존한다. 저장 중 flush 구간의 외부 변경도 다시 확인한다. Windows의 기존 파일과 아직 없는 파일 모두 실제 부모 경로의 대소문자를 사용한다.

기존 여러 파일 저장의 롤백/Undo 트랜잭션과는 구분된다. 일반 저장 실패 뒤 이미 게시된 내용을 원래 내용으로 되돌린다는 보장이 아니다. 특수 내부 폴더·바이너리 스트림 가져오기·이름 변경의 공동 복구, 실제 전원 차단과 모든 파일시스템의 내구성은 별도 잔여다.

## 재현 검사

- `npm run test:previous-frame`: 실제 WebGL/WebGPU/D3D 이전 패킷 대조와 카메라 콘 검사.
- `npm run test:sparse-tilemap`: 100만×100만 좌표 맵의 희소 작업과 실제 편집기 우클릭·Undo·이동·C++/블루프린트.
- `npm run test:asset-write-recovery`: 실제 소유 프로세스 종료, 디스크/권한 오류, ID 복원과 외부 변경 보존.

결과 경로와 SHA는 `research/ENGINE_WORK_318.json`에 기록한다. Android 검사는 새 C++ 소비자의 ARM64 NDK 구문 검사이며 실물 기기 실행이나 새 APK 설치 검사로 계산하지 않는다. 초기 컴파일 시간은 한 번의 게임 전환 표본이며 반복 부하 비교나 게임 FPS가 아니다.
