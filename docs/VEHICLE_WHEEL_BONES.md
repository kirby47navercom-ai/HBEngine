# 가져온 차량 모델의 휠 뼈

Raycast Vehicle의 각 휠에서 **골격 휠 표시 → 뼈 이름**을 지정해요. 물리 휠의 조향·회전·서스펜션 결과가 해당 모델 뼈에 적용돼요. 기존 **휠 표시**를 꺼서 기본 원통을 숨겨도 뼈 연결은 작동해요. 지정하지 않은 차량에는 이 표시기와 골격 검색·이력이 생기지 않아요.

가져온 모델에서 이름이 유일한 뼈를 사용해요. 같은 뼈를 두 휠에 연결하거나 연결한 휠 뼈끼리 부모·자식이면 반영 전에 거부해요. 뼈의 기본 위치를 서스펜션의 기본 길이에 맞춘 휠 중심으로 준비해요. 조향/회전 로컬 축과 배율을 모델에 맞게 바꿀 수 있어요. 회전은 기본 자세에 조향 후 구름 회전을 곱하며 프레임마다 누적하지 않아요. 서스펜션 길이 차이는 월드 거리로 계산해 뼈 부모의 역변환으로 옮겨요.

활성 물리 프레임이 있을 때만 지정한 뼈를 제어해요. 중지·프레임 제거·컴포넌트 해제·장면 해제 때 마지막으로 쓴 위치/회전과 여전히 같은 값만 복원해요. 그 사이 다른 작업이 쓴 채널은 보존해요. 다시 켜면 현재 포즈를 기준으로 잡아요. 실행 중 같은 뼈 채널을 다른 애니메이션이 쓰면 명시한 휠 표시가 우선하며, 이는 일반 레이어 혼합기가 아니에요.

visual 메타데이터만 바꾸면 Rapier 차량 컨트롤러를 다시 만들거나 잠든 차체를 깨우지 않아요. 실제 반지름·접점·마찰 같은 물리 설정 변경은 원래대로 적용해요. 기본 원통 휠도 기존 변환 공식을 유지하면서 프레임별 임시 벡터/쿼터니언/행렬과 진단 배열을 재사용해요. 골격 이름 검색은 모델 준비 때 한 번이며 매 프레임 전체 골격을 순회하지 않아요.

저장 위치는 RaycastVehicle.wheels[].visual이에요. 기존 컴포넌트 검증·휠 입력·Undo·블루프린트 컴포넌트 편집·AI 문서 수정/저장 계약을 사용해요. hb schema --local --section vehicleWheelBones에서 필드와 수명 계약을 조회해요. 새 네이티브 호출 형식이나 SDK 복제는 없어요.

타이어 표면 변형·차체 전체 애니메이션/IK·손상과 예측은 별도 기능이에요. 소스의 실제 Three 골격·Rapier 연결 검사가 실제 창의 픽셀이나 전체 게임 FPS 검증을 대신하지는 않아요.
