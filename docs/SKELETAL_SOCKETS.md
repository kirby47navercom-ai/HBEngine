# 골격 소켓과 일반 부착

부모 캐릭터에 `SkeletalSocket` 컴포넌트를 추가하고 `socketName`, `bone`, 로컬 `position/rotation/scale`을 지정해요. 같은 이름의 활성 소켓이 여러 개면 사용 시 거절해요. 소켓은 저장되는 일반 컴포넌트여서 기존 Inspector·문서 CAS/Undo·프리팹·공용 C++ 컴포넌트 속성 명령을 사용해요.

무기·장식 오브젝트를 캐릭터의 자식으로 놓고 `SkeletalAttachment`를 추가해요. `anchor`는 `bone` 또는 `socket`, `anchorName`은 뼈·소켓 이름이에요. 부착 컴포넌트의 TRS가 기준점에 대한 오프셋이며, 활성 동안 자식 Transform을 구동해요. 비활성화하면 마지막 포즈를 유지해요. 실행 초기화와 풀 획득 이벤트 전에 적용하고, 매 프레임 애니메이션·물리·시퀀스 적용 뒤 최신 포즈를 표시해요. 중첩 부착은 부모부터 평가해요.

구동 대상은 실제 Three 골격의 이름 있는 Bone이에요. 다른 액터의 자식 모델에 있는 뼈는 찾지 않아요. 누락·중복 뼈/소켓, 부모 순환, 특이·전단 행렬은 근사 TRS로 바꾸지 않고 오류를 기록해요. 실패 시 마지막 유효 포즈를 유지하며, 수리하면 다음 프레임에 재시도해요. 소유자·부착 액터 교체/회수 시 이전 바인딩을 재사용하지 않아요.

등록된 부착 액터만 프레임에 평가해요. 뼈 참조와 조상 연결은 캐시하고 실제 포즈 행렬을 다시 읽어요. 메시·이름·조상 연결이 바뀌면 다시 바인딩해요. 최초/재바인딩의 골격 검사, 기존 VM의 ID 조회 비용과 행렬 계산은 남아 있어요. FPS·힙·GPU 성능을 측정했다는 뜻은 아니에요. 시작·생성·풀·레벨 수명과 시퀀스 컴포넌트 복원은 연결됐으며, 외부 코드가 수명 경로 없이 직접 추가한 새 컴포넌트의 자동 감지는 계약 밖이에요.

충돌은 다음 물리 동기화 경계에서 새 변환을 받는 기존 흐름을 사용해요. 같은 프레임의 물리 제약/충돌 해법, 동적 강체와의 결합, 전용 시퀀스 부착 트랙·블렌드/보상, SpriteRig의 별도 2D 본 모델은 이 구현의 검증 범위가 아니에요.

## Gameplay Cue v3

기존 v1/v2 문서는 유지해요. v2 에셋 편집기의 **뼈·소켓 지원으로 변환**은 한 번의 Undo로 v3 필드를 추가해요. v1은 기존 VFX 변환 뒤 이 단계를 사용해요. AI는 `upgradeGameplayCueAnchors`와 일반 에셋 문서 편집 계약을 사용해요.

| 필드 | 값 |
| --- | --- |
| `vfxAnchor` | `owner`, `bone`, `socket` |
| `vfxAnchorName` | 뼈·소켓 이름. owner에서는 사용하지 않음 |
| `vfxPosition/Rotation/Scale` | 기준점 뒤에 적용하는 로컬 오프셋 |
| `vfxAttach` | true면 추적, false면 방출 시 월드 변환 한 번 저장 |
| `emitTarget` | 자식 액터 이름의 상대 경로 배열. `[]`는 소유자 |

`emitTarget:["Rig","Smoke"]`는 소유자 아래 Rig의 자식 Smoke에 있는 기존 ParticleSystem을 방출해요. 활성 경로 이름은 각 단계에서 고유해야 하고, v3 대상 액터에는 활성 ParticleSystem 하나가 필요해요. 여러 이미터는 여러 자식 액터와 여러 경로로 만들어요. v1/v2는 기존 첫 활성 이미터 선택을 유지해요. 한 액터에 ParticleSystem 컴포넌트 여러 개를 독립 렌더링하는 지원은 추가하지 않았어요.

비동기 준비 중 경로·소유자·컴포넌트가 바뀌거나 회수되면 방출을 취소해요. Cue 실패는 이미 확정된 게임플레이 값을 되돌리지 않아요. 일반 부착을 먼저 갱신한 뒤 Cue 부착을 갱신해요. 독립 프리팹의 원래 루트 TRS·바인딩·풀·채널·정지·게임시각 수명은 기존 경로를 유지해요.

검증: `tools/check-gameplay-cue-anchors-2638.mjs` 20개, `tools/check-skeletal-attachments-2647.mjs` 10개. 실제 공용 VM·native 명령 재생·Three 애니메이션/계층·소유 DOM·4대상 content 검사예요. 새 C++ 바이너리, GPU/GUI, 실기기, 설치 검증은 수행하지 않았어요.
