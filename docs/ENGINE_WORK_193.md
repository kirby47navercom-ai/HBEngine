# 193 — 사용 중인 설치본을 보존하며 버전 누적 전에 갱신 보류

다른 게임의 Android 빌드가 이전 설치본 Node를 사용하는 동안192 설치가 정리를 보류해 Versions가2개가 됐었다. 빌드는 중단하지 않았고, 바로가기·프로젝트 연결을 기존 설치로 되돌린 뒤 이번 새 설치174880763바이트만 검증된 설치 정리기로 제거해 Versions1을 복구했다. 새 배포본은 작업 공간에 유지했다.

설치기는 이제 새 버전 폴더/바로가기 전환 전에 기존 버전을 참조하는 실행 파일·명령행을 확인한다. 다른 버전이 사용 중이면 deferred:true, reason:running-install, active:[{pid,version,name}]를 반환한다. 같은 번들의 검증/재사용은 가능하다. 복사 중 새 사용이 시작되는 경우도 다시 확인해 이번 임시 설치만 제거한다. 실행 중인 게임·빌드·사용자 프로필은 중단하거나 검사에 사용하지 않는다.

격리한 가짜 배포 자료와 실제 자식 프로세스로 최초 사용/같은 버전/새 버전 보류/복사 중 시작/임시 폴더 제거/사용 종료 후 정상 교체/Versions1을 검증했다. 기존 수정 파일·프로젝트·실행본 보호·복사 실패/범위/생성 캐시 정리도 통과했다. 임시 설치 루트는 검증한 OS 임시 경로에서 제거했고 보고서만 보존했다. [근거](research/ENGINE_WORK_193.json).

마지막 확인 뒤 다른 프로그램이 실행되는 모든 경쟁을 원천 봉쇄했다는 의미는 아니다. 삭제 직전 보호도 유지하며, 실제로 쓰는 버전을 강제로 지우지 않는다. 상시 갱신 서비스·백업 런타임·새 의존성을 추가하지 않는다.
