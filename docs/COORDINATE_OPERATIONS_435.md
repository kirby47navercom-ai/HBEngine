# 나눗셈·거리·회전·반사 좌표의 밉 폭

나눗셈은 분모의 epsilon 경계 통과까지 포함해 변화량을 직접 계산해요. 거리에는 길이 항등식, UV 회전에는 각도 변화와 회전 중심의 변화, 반사에는 단위 노멀의 변화와 곱 교차항을 사용해요. 눈 UV는 시선 분모·깊이·마스크 경계의 변화량을 함께 전달해요. 기존 기본값·그래프·IR·샘플러 형식은 유지해요.

실제 GL·WebGPU·DirectX의 33개 연산·573조건에서 독립 수학 기준을 대조해요. 큰 입력과 epsilon 경계, 0이 아닌 작은 반사 노멀도 포함해요. 다섯 머테리얼 그래프를 별도로 컴파일해 현재·이전 포즈의 넓은 밉과 좁은 밉을 비교해요. DirectX는 현재·이전 패킷을 각각 바인딩해 실행해요.

DirectX의 큰 순회는 기존 반복문 정책을 유지해요. 벡터 성분을 쓰는 네 번의 작은 반복만 펼쳐, FXC에서 동적 벡터 쓰기와 강제 반복 속성이 충돌하던 컴파일 오류를 해결해요. WebGPU 눈 UV 변화량은 스칼라 중간값을 변수로 보존해 불필요한 표현식 확장을 줄여요. 초기 컴파일 전체가 해결됐다는 뜻은 아니에요.

추가 GPU 자원·uniform·운영 readback은 없어요. AI 불변 `uvFootprint` 계약에도 같은 안정 연산을 공개해요. 거듭제곱·노이즈·Fresnel 등 나머지 비선형 fallback, 표현 불가능한 작성 UV·시간과 극단적인 중간 범위는 남아 있어요. 전역 곡면·참여 매질·렌더링 원장의 다른 항목도 별도예요.

후속 거듭제곱·지수·로그·Smoothstep·노멀·Fresnel·그라디언트 변화량과 남은 제한은 [비선형 좌표445](NONLINEAR_COORDINATES_445.md)에 이어서 기록해요.
