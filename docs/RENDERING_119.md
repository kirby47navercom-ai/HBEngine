# 119 — 움직이는 장면의 시간 재투영·이차 렌즈 필터

공간 필터 이후의 표시 이력은 이전 삼각형 좌표와 이전 카메라 행렬로 재투영한다. 같은 화면 좌표의 색을 바로 섞던 경로를 대체한다. 월드 삼각형의 안정적인 sourceID로 변형 전 정점을 대응시키고 현재 충돌점의 무게중심 좌표로 이전 점을 복원한다. 이동·스킨·모프·인스턴스가 같은 경로를 사용한다. 삼각형 순서가 바뀌어도 이전 정점을 현재 GPU 순서로 다시 포장한다.

원본 Monte Carlo 누적은 카메라·포즈 변경 때 계속 초기화한다. 표시 필터만 움직임을 따라 재사용한다. 머테리얼·광원·환경·위상·렌즈·해상도 변경, 카메라 컷·수동 이력 버전·장면 교체·실패는 표시 이력을 거부한다. 이전 UV 범위, 표면 종류, 예상 이전 깊이, 법선을 확인하고 현재 3×3 색 범위로 이전 색을 제한한다. 정적인 이전 정점의 최초 유효화만으로 원본 샘플을 잃지 않는다. 성공한 프레임 뒤에만 정점 이력을 확정한다.

이차 경로의 가상 이전 점은 반사 평면을 역순으로 접고, 굴절 경계에서는 상대 굴절률의 국소 가상 깊이를 사용한다. 현재 가상 점의 투영 오차를 함께 빼서 정적 장면에서 UV가 떠돌지 않도록 한다. 이 굴절 재투영은 국소 근사이며 곡면·비스듬한 경계·큰 움직임에서 오차가 남을 수 있다. 실제 창의 재투영 판정 증거는 기본 확산 표면의 카메라·오브젝트 이동이고, 스킨·모프·인스턴스 대응은 CPU 포장 증거이다. 이차 시간 이력 전체를 실기기로 검증했다고 해석하지 않는다.

렌즈 필터는 픽셀 X/Y 광선 두 개와 조리개 X/Y 광선 두 개를 중심 광선과 함께 전달한다. 각 경계의 접평면 교차, 해당 위치의 법선, 반사·Snell 굴절, 중첩 매질의 상대 IOR와 전반사를 사용한다. 최종 표면에서 픽셀 광선의 위치 변화가 이루는 2×2 Gram 계를 풀어 조리개 변화를 픽셀 반경으로 바꾼다. 따라서 첫 표면 깊이만으로 이차 초점을 대신하지 않는다. 반경은 기존 5×5 공간 필터의 간격·밝기·반경 일치 가중치에 적용한다. 반경 상한32픽셀·기존1–4단계는 유지한다. 접선에 가까운 교차와 광선 사이 전반사 분기 변경은 보수적으로 거부하고, 특이한 미분계는 반경0으로 처리한다.

사람과 AI는 기존 PostProcessVolume의 `pathTracingDenoiseTemporal`·`pathTracingDenoiseLens`·`pathTracingDOF`·`focusDistance`를 사용한다. C++ `hb::Components::SetFloat`/`SetBool`, 블루프린트의 공용 컴포넌트 속성 함수, 상세 속성 UI와 `engineSchema()`가 같은 값을 편집한다. Claude도 `document.get`의 revision과 오브젝트 ID `test`를 넣은 `document.patch`/`files.apply`로 편집한다. 새 AI 전용 설정은 없다. 내부 패킷 `pathFilter.w`는 이전 정점 블록 주소이고 공개 에셋 속성이 아니다. 네이티브에서 유한값·정수 주소·블록 범위를 렌더 시작 시 검증한다.

추가 조명 적분·일상 GPU 읽기·의존성은 없다. 시간 필터가 켜지면 이전 정점48바이트/삼각형과 기존 표시 이력24바이트/픽셀을 사용한다. 시간 또는 물리 렌즈 필터가 필요할 때만 보조 가이드8바이트/픽셀을 만든다. 끄거나 뷰포트를 폐기하면 해제한다. 바뀐 데이터 행만 기존 부분 전송 경로에 전달한다. 픽셀·조리개 미분은 국소 접평면 근사이고 거친 간접 경로·배경·불완전 가이드는 계속 원본을 사용한다.

검증 도구: `tools/check-rendering-119.mjs`, `native/tests/scene-rendering-119.hpp`, `tools/rendering-119-fixture.mjs`. 기존118 원본 복원·자원 수명·네이티브 오류 검증과 기존 렌더링 회귀도 함께 사용한다. 높은 동적 범위 샘플의8비트 출력 클리핑을 피하도록119 검사 장면은 HDRI 밝기0.01을 사용하고 기존 분산·평균·원본 복원 판정값은 유지한다. 실행 결과와 설치 파일 대조는 [구현 기록](research/RENDERING_119.json), [설치 기록](research/USER_INSTALL_119.json)을 따른다.

참고한 본문 범위는 [PBRT의 접평면·반사/굴절 광선 미분](https://pbr-book.org/3ed-2018/Texture/Sampling_and_Antialiasing) 자체10.1.1·10.1.3, [NRD의 PSR 가상 위치·법선·모션 계약](https://github.com/NVIDIA-RTX/NRD/blob/master/README.md) 자체PSR 단락이다. 자체 유한차분/가이드 구현이며 PBRT·NRD 코드를 복사하거나 NRD를 통합한 결과는 아니다. 연결된 API 전체·전체 Unreal/Unity 문서·휴대폰 실기기·게임 전체 FPS 검증을 완료로 계산하지 않는다.
