# 보폭 보정

Two Bone IK의 **보폭 보정**에서 사용을 켜고 입력 포즈 또는 IK 목표를 선택해요. 배율은 `scale × Float 파라미터`이며 최소·최대 배율 안에서 움직여요. C++는 기존 `hb::AnimationGraph::SetFloat`, 블루프린트는 기존 Float 설정 노드를 사용해요. `strideWarp`를 생략하거나 끈 기존 그래프는 그대로 동작해요.

컴포넌트 공간의 입력 루트 뼈를 기준으로 발의 수평 변위를 바꿔요. 수평면 전체 모드는 위쪽 축에 수직인 변위를 모두 조절하고, 진행 축 모드는 위쪽 축에 투영한 진행 성분만 바꿔서 옆걸음과 높이를 보존해요. 축은 정규화하며 진행 축과 위쪽 축이 평행한 설정은 거부해요.

순서는 원래 포즈/목표 → 보폭 → 기존 위치 가중치 → 작성한 발 고정 → 지면 투영 → 기존 IK 길이·관절·Alpha 제약이에요. 발 고정이 활성일 때 고정점이 우선하고, 고정을 풀면 작성한 해제 시간에 따라 보폭 목표로 돌아가요. 지면의 입력 포즈 광선은 보폭을 바꾼 발 위치에서 시작해요. 도달할 수 없는 목표에서는 기존 팔다리 길이와 제한을 유지하고 잔여 오차를 표시해요.

`strideWarp: {enabled, parameter, scale, minScale, maxScale, source, mode, upAxis, forwardAxis}`를 기존 그래프 JSON/문서 revision/Undo/저장 경로로 편집해요. Float 이름 변경도 중첩 참조에 반영해요. 자동 속도 추정·보행 접촉 단계·골반 최적화와는 별개인 작성식 보정이에요. C++ API 자체를 새로 추가하지 않아요.
