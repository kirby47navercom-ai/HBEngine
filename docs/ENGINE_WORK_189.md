# 189 — 비시간 그래프의 이전 Time 계산 준비 제외

광선 프로그램에 Time opcode가 없으면 이전 노멀 함수가 이전 시간용 노멀 계산 호출을 만들지 않는다. WebGPU는 실제 프로그램에서 파생한 hasTime으로 노드를 특화하고, 공용 GLSL/HLSL은 기존 HB_RAY_OP_2 비트로 같은 구역을 제외한다. 기존 opcode 키/공용 프로그램/버퍼를 사용하며 새 변형 캐시·이미지·읽기·타이머·의존성을 추가하지 않는다. Time 그래프는187의 절대 이전 시간과 기존 실패/되감기 무효화를 유지한다.

수정 전 정적 WebGPU 이전 노멀 소스는48004B였고, 같은 Time 계산을 강제로 남긴 검사 변형도48004B다. 특화한 정적 버전은47860B로 이전 시간 호출144B가 빠진다. 이는 최종 드라이버 IR 크기나 FPS가 아니다. 실제 D3D Compute·GL·GPU의 부호 있는 노멀 픽셀은 약5.93e-8 이내로 일치하고 장시간 Time 표본도 유지한다.

단일 정적 노멀 그래프의 전체 GL path/guide/filter 링크를 실제 드라이버에서 두 순서로 대조했다. Time 예외를 강제로 남긴 검사 변형→정적 버전은2732.8→2244.4ms, 순서를 뒤집은 별도 창에서는 정적2095.0ms/검사 변형2584.1ms였다. 두 경우6개 프로그램을 유지하고 독립 링크를 동시에 제출했다. 주요 변화는 보조 가이드다. 같은 정적 패킷의 D3D 프로브 컴파일은 정적214.84ms/검사 변형316.50ms였다. 이는 작은 공용 함수/가이드의 측정이며, 기존 공유 기하·계층을 포함한 Complex141의7.9초/7.4초 기록이나 전체 게임 FPS와 혼동하지 않는다.

CPU 소스 특화·기존141/157/전체 GPU 공용 생성 회귀, 실제3백엔드 픽셀·두 순서 GL 링크, 새 Win32 바이너리의 실제 DirectX 패키징 게임을 검사했다. 새 게임에서 아틀라스 크기와 프로그램 소스/컴파일 수가 프레임 사이에 유지되고 오류0/종료0이다. [근거](research/ENGINE_WORK_189.json). 설치본의 최종 제작 조작/시간 픽셀과 프로필·파일 명세 검증은 별도 설치 영수증에 연결한다.
