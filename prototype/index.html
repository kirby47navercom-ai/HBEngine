도움말

    
그래프 제작
빈 곳 우클릭으로 한글·영어 노드를 검색해요. RMB/MMB 드래그로 이동, 휠로 확대, Ctrl+휠로 100% 이상 확대해요. Ctrl/Shift 다중 선택, C 주석, F2 이름, F9 중단점, Ctrl C/V/D/X 복사·붙여넣기·복제·잘라내기, Ctrl Z/Y 실행 취소·다시 실행을 지원해요. B/D/S/G/F/M/N/O/P를 누른 채 클릭하면 기본 제어 노드를 만들어요.

    
함수·C++·실행
선택 노드를 함수·매크로로 묶고 두 번 클릭해 내부를 편집해요. 오른쪽에서 핀 기본값·시그니처·변수·컴포넌트·클래스를 수정해요. C++은 외부 IDE에서 작성하고 편집기에서 빌드해요. 공개 함수/속성/이벤트가 노드로 연결돼요. 선택 객체 또는 자동 실행으로 지정한 객체에 BP를 실행해요. Stop은 편집 상태를 복원해요.

    
디버그·Timeline
검증/디버그 창에서 연결·중단점·관찰 값을 확인해요. 중단점에서 실행 버튼은 계속, BP 실행 버튼은 Step이에요. Timeline을 두 번 클릭해 트랙·키·시간·값·보간·접선을 편집해요. Shift 클릭/Enter 키 추가, Delete 삭제, RMB/MMB 이동, 휠 시간 확대, Ctrl+휠 값 확대, Space 재생, A 전체/F 선택 초점이에요.

    
Project·창 배치
실제 폴더에서 파일명·타입·내용을 검색해요. Ctrl/Shift로 여러 파일을 고르고 선택 열기로 각각 열어요. F2 이름 변경, Backspace 상위 폴더예요. 외부 파일/폴더를 어디든 놓으면 현재 폴더로 즉시 가져와요. 탭 드래그나 우클릭으로 창을 분할하고, 창 메뉴에서 추가 뷰포트·배치 초기화를 선택해요.

    
노드 연결과 배치
이벤트 제목의 삼각형이 실행 출력이에요. 변수를 실행 핀에 놓으면 Set, 데이터 입력에 놓으면 Get이 연결돼요. Ctrl 드래그는 Get, Alt 드래그는 Set이며 빈 곳에 놓으면 선택 메뉴가 열려요. 호환 자료형은 실제 변환 노드를 삽입해요. 양쪽 핀에서 드래그 검색, Alt 클릭 연결 해제, 데이터 선 더블클릭으로 Reroute, 노드 우클릭에서 정렬·간격 조절을 지원해요.
뷰포트·머테리얼
Q 선택, W/E/R 이동·회전·크기, Space 도구 순환, Ctrl Space 작업창 확대예요. 스냅 간격과 월드/로컬을 툴바에서 선택해요. 선택한 콜라이더의 경계가 보이고 충돌 버튼은 전체 경계를 표시해요. 오브젝트 메뉴의 검색·분류 창에서 클릭 또는 뷰포트 드래그로 배치해요. 머테리얼 그래프 템플릿은 현재 그래프를 교체하며 Ctrl Z로 복원할 수 있어요.
저장
Ctrl S는 장면과 BP를 Project 파일과 브라우저 복구 저장소에 저장해요. C++와 열린 텍스트는 각 저장 버튼을 사용해요. BP JSON 내보내기/불러오기는 함수·매크로·변수·C++ 원문·Timeline을 포함해요. 애니메이션·머테리얼 그래프도 개별 에셋으로 저장해요.

    
충돌 형상 편집
Polygon/Edge 2D는 점 드래그·좌표 입력으로 편집해요. 선분 클릭은 점 추가, Ctrl 클릭은 점 삭제, Shift 드래그는 선분 이동, Delete는 선택 점 삭제예요. 우클릭/휠 버튼 드래그로 이동하고 휠로 확대해요. 형상 창의 Ctrl Z/Shift Z와 버튼으로 초안을 복구하며 적용/취소 전에는 원본을 바꾸지 않아요. Mesh Collider의 메시에서 생성은 원본 모델 또는 장면 렌더 메시를 저장된 로컬 형상으로 만들어요.

    
지원 범위
블루프린트 기본 노드 473개, 공통 C++ API 289개, 머테리얼 노드 54개예요. 사용자 코드 빌드는 헤더/구현 한 쌍을 지원해요. C++ 이벤트는 호출 종료 후 BP에 전달해요. 모델은 OBJ/GLTF/GLB/FBX, 영상·오디오는 브라우저 코덱을 사용해요. 미지원 파일도 원본을 보존해요. 현재 렌더러는 Three.js/WebGL이며 네이티브 호스트는 Win32/WebView2예요. 물리는 Rapier 2D/3D이며 정확한 기본 형상·볼록/삼각형 메시·2D 다각형/선분, 강체·관절·CCD·질의를 지원해요. 세부 실행 계약은 프로젝트의 물리·제작 문서에서 확인할 수 있어요.
