머테리얼 / 노드

상단 탭으로 작업을 바꾸세요. 표면 설정은 미리보기에 반영되고, 노드 핀을 클릭하거나 드래그해 연결할 수 있어요. 블루프린트는 Ctrl+휠로 확대하고 Ctrl/Shift로 여러 노드를 선택해 묶으세요.

저장 범위

오브젝트·표면·맵 환경·블루프린트는 이 브라우저에 저장돼요. 함수·매크로 내부 그래프도 저장되고 JSON으로 내보낼 수 있어요. 가져온 파일·머테리얼 노드 배치·애니메이션 키는 세션 미리보기예요.
