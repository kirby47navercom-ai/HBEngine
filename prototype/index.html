블루프린트

우클릭·휠 버튼 드래그로 이동, 휠로 확대, Ctrl+휠로 100% 이상 확대해요. C 주석, Home 선택에 초점, F2 이름/주석 편집, F9 중단점, PageUp/Down 그래프 이동을 지원해요. 주석 모서리를 드래그하면 크기를 바꿔요. 오른쪽에서 입력값·변수·컴포넌트·클래스 기본값을 편집해요.

C++와 블루프린트

C++ 탭에서 HB_CLASS·HB_PROPERTY·HB_FUNCTION 공개 헤더 선언을 편집하고 노드를 등록해요. 부모 클래스를 선택해 블루프린트로 확장하면 상속 기본값과 재정의 이벤트를 편집할 수 있어요. 지원하지 않는 타입·함수 본문은 등록 오류로 표시해요. 공통 수학·벡터·시간·타이머·변환 API 68개는 실제 C++ 구현이며 헤더에서 노드 정보를 생성해요. 선택 노드의 값 계산/미리보기 호출은 브라우저 JS로 계산해요. 임의 사용자 C++의 빌드·실행은 아직 없어요.

통신·시간·검증

디스패처·인터페이스의 시그니처를 만든 뒤 우클릭 검색으로 호출·바인딩·이벤트·메시지 노드를 추가해요. Timeline의 키는 시간 오름차순 JSON이고 Float/Vector/Color 값을 스크럽할 수 있어요. Ctrl C/V/D/X 복사·붙여넣기·복제·잘라내기, Ctrl Y 다시 실행, Ctrl F 검색, F7 편집 데이터 검증을 지원해요. 디버그 목록은 중단점·핀 관찰 위치를 보여주며 공통 API 출력은 마지막 계산 값을 표시해요. 전체 런타임 실시간 디버거는 아직 없어요.

기능 범위

노드·컴포넌트·Construction은 편집 데이터예요. 공통 API의 데이터 계산과 장면 변환은 미리보기 호출로 확인할 수 있어요. 게임 시간과 타이머는 상단 실행 중 진행하며 완료는 콘솔에 보여요. 전체 이벤트 그래프·물리·생명주기는 아직 자동 실행하지 않아요. 모델·영상은 가져오기 목록만 준비하고 실제 변환은 하지 않아요. 머테리얼 그래프의 셰이더 컴파일과 편집기에서 임의 C++ 프로젝트를 빌드하는 기능은 아직 없어요.

장면 편집

오브젝트를 선택하고 Inspector에서 위치·회전·크기를 바꾸세요. 드래그로 장면을 돌릴 수 있어요.

머테리얼 / 노드

상단 탭으로 작업을 바꾸세요. 표면 설정은 미리보기에 반영되고, 노드 핀을 클릭하거나 드래그해 연결할 수 있어요. 블루프린트는 Ctrl+휠로 확대하고 Ctrl/Shift로 여러 노드를 선택해 묶으세요.

저장 범위

오브젝트·표면·맵 환경·블루프린트는 이 브라우저에 저장돼요. C++ 등록·상속 기본값·디스패처·인터페이스·타임라인과 함수·매크로 내부 그래프도 저장되고 JSON으로 내보낼 수 있어요. 가져온 파일·머테리얼 노드 배치·애니메이션 키는 세션 미리보기예요.
